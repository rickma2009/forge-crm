# 制造业数字员工原型

这是隔离的交互原型，用于验证制造业数字员工的工作台、任务、人工确认、员工目录和场景边界。原型不连接真实邮件、飞书、模型或业务 API，所有状态只保存在当前页面内存中，刷新后恢复。

## 启动与关闭

```bash
bash prototypes/digital-employee/start.sh
bash prototypes/digital-employee/stop.sh
```

独立地址：`http://127.0.0.1:5175`。主应用运行在 `http://localhost:5173` 时，可从顶部“数字员工”机器人图标进入嵌入预览。

## 演示路径

1. 在工作台查看待处理、待确认、高风险和各业务域异常。
2. 打开“客户 RFQ”“SMT 换线”“批次追溯”或“集中差评”等任务，查看触发、交付物、证据、分析和人工控制点。
3. 在场景中心查看 12 项电子制造高频场景；进入场景卡查看目标、执行流程、证据、交付物、控制点和衡量指标。
4. 从场景卡或列表进入“启用评估”，勾选数据、规则、样本、验收等准备项；准备度达到 80% 后才可提交影子运行申请。
5. 在外部信号查看授权电商评论、物流、供应商风险、材料行情和汇率信号，并跳转关联任务。
6. 在待确认中心审阅报价、外部邮件、质量隔离和正式业务动作；确认或驳回会更新内存状态。
7. 在数字员工页面配置岗位目标、数据范围、运行级别、低置信度阈值、工具权限和人工接管人。
8. 在任务中心发起新任务；在任务详情查看证据索引；新增或修改规则与系统连接，并模拟导出审计记录。

## 原型边界

- 没有持久化、真实权限、后端接口、模型调用和外部发送。
- “确认执行”只改变原型状态，不发送邮件、不创建单据、不修改库存或生产计划。
- 预测维护、视觉质检和排程优化仅作为场景入口，不模拟算法结果。
- 正式实现须另行完成需求、权限、数据、接口、安全、并发、幂等和审计设计。
