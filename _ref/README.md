# 参考资产区

本目录只存放在建项目、历史项目和外部案例的只读快照，不构成 `sdd-forge` 的规范。

## gf_scm

`gf_scm` 当前仍在建设和演进：

- 不是最佳实践或金标准案例；
- 可能同时包含新旧技术栈和迁移中的设计；
- 可能包含特定企业环境、业务域和部署平台约束；
- 其中的 `.specify/`、模板、AGENTS、Java 遗留内容和业务代码不得直接用于新项目。

新项目应以 `../_methodology/` 为唯一方法论和模板来源。需要使用 `gf_scm` 的经验时，遵循 `../_methodology/02-参考资产复用指南.md`，先抽象、去业务化并验证。
