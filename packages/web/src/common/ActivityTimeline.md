# ActivityTimeline（本项目候选公共组件）

适用：详情内按发生时间展示的过程记录。当前采用：客户、商机详情的活动时间轴。

组件输入 `items`、`expanded`、`onExpand`、`renderDetail`；调用方提供稳定来源键和已授权的展示记录。组件只负责列表语义、时间列、类型/状态、摘要、展开内容及窄屏布局，不请求业务接口，不管理权限、编辑或附件。

统一样式：沿用详情Tab；左侧时间、右侧内容，时间轴线和节点保持轻量；系统事件明确只读，作废保留标识。展开区用间距区分内容，不再套外层卡片。窄屏改为单列，标题按钮可键盘操作。发生时间与录入时间分别展示。

业务接入参照 `showcase/ActivityPanel.tsx`：类型筛选刷新快照、游标加载更多、按来源键去重、忽略旧请求；权限/游标失效时清空旧数据。来源跳转遵守对象权限。编辑采用公共弹窗焦点/关闭约定，未保存提示；附件只在保存后使用公共AttachmentPanel。

接口排序、数据范围、作者权限、幂等及审计由服务端负责。未来计划使用待办，不以未来时间新增活动。验证见[交付记录](../../../../docs/testing/activity-timeline-p3.md)。目前是同一项目两个对象采用，无跨项目成熟度证明。
