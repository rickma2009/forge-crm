# 规格

BUS-WFE-01 为后续销售订单闭环提供真实引擎、可重放命令和不可变定义。

- REQ-WFE-01 受限销售模板：开始→经理→金额条件→可选二级负责人→财务→等待业务动作结果→结束。金额人民币字符串定点，超过阈值走高分支，完整图保留低分支和汇合。
- REQ-WFE-02 发布/启动/同意/退回/拒绝/转交/业务结果全部带requestId；同键同载荷重放同响应，异载荷409；并发不重复。
- REQ-WFE-03 实例固定定义版本和布局，状态/节点历史从Flowable读取；退回/拒绝终结本轮，转交需受信门面已授权，禁止申请人自审。
- NFR-WFE-01 内部服务只绑定本机并要求强服务令牌，所有命令带租户和应用，实例跨作用域不可见；无任意XML、表达式、HTTP或脚本入口。
- NFR-WFE-02 业务等待节点不得自动成功；失败保持等待，后续成功才完成；回调需要匹配实例及等待执行ID。

AC-WFE-01 编译图及99999.99/100000/100000.01边界验证。
AC-WFE-02 重复与异载荷命令、并发命令验证。
AC-WFE-03 发布新版本不改变旧实例，任务动作和历史验证。
AC-WFE-04 跨作用域、非承办人、自审、错误令牌拒绝。
AC-WFE-05 故障结果等待、重试成功与过期回调拒绝。
