# 使用、数据责任与恢复

## 使用顺序

1. 在数据字典维护有效的产品线和单位，产品须启用并关联有效字典项。
2. 在产品页维护销售定价；标准价和阶梯价按版本保留，阶梯连续覆盖数量区间。
3. 报价管理新建报价，或从客户/商机进入；添加商品、数量、折扣、成交价并保存草稿。修改数量不覆盖手工成交价；重新取价需确认差异。
4. 提交前确认引用和价格版本；提交后商业内容冻结，内部登记接受或拒绝。复制生成新草稿，不修改原报价。
5. 已接受的关联报价可由授权人员明确回写商机预签金额；不是自动同步。导出 PDF 不含内部备注和建议价。

新权限通过 `packages/server/scripts/init-quotation.ts` 幂等增量初始化；不得用全量 seed 重置现有环境。角色仍需明确授予报价及价格操作权限。中文 PDF 需要服务端可执行的 Chrome/Chromium，可通过 QUOTATION_CHROME_BIN 指定；当前浏览器启动式导出较慢，不作为生产并发容量结论。

## 数据责任登记

六表均为允许的 sd_ 销售交易层，不新增 sys_ 平台表。DDL 快照见 docs/database/quotation-20260923。

| 物理表 | 唯一写入责任 | 关键范围与关系 |
|---|---|---|
| sd_product_price | quotation / PricingService | 租户、产品、不可变版本；引用 md_product |
| sd_price_tier | quotation / PricingService | 父价格版本；数量区间与金额约束 |
| sd_quotation | quotation / QuotationService | 租户、应用、系统、客户、负责人；可关联同客户商机及源报价 |
| sd_quotation_line | quotation / QuotationService | 稳定行 ID、报价、产品与价格引用、商业快照 |
| sd_quote_event | quotation / QuotationService | 状态审计与作用域内请求幂等记录 |
| sd_opp_amount_event | opportunity / OpportunityAmountService | 商机金额变更来源；由商机责任模块写入 |

Prisma schema 与迁移包含主外键、复合作用域约束、唯一索引和金额检查。报价日期及有效截止日明确，Asia/Shanghai 截止日含当天；过期由受限扫描和 CAS 防重复。无硬删除业务入口；记录与快照保留。PDF 导出另记系统审计。后台过期事件的全零 UUID 表示系统任务，不冒用真实用户。

## 迁移与回退边界

增量迁移：20260923140000_quotation_pricing。现有本地库迁移记录校验和与文件一致；DDL 导出未发现待应用迁移或校验和漂移。测试使用独立 sdd_quote_* 数据库，不用业务库装测试数据。

本次没有证明从零重放全部历史迁移可成功：历史 add_role_tree_fields 早于其依赖 org_unit 创建而失败。独立升级测试库来自当前结构快照，不能将其冒称为从迁移前基线验证升级。当前库增量已应用事实、数据库约束测试与 DDL 对账分别记录，不混为完整迁移演练。

回退优先关闭报价菜单/权限并回退应用对应文件，保留新增表及用户数据；先备份数据库并记录受影响版本。不得直接删除六表或重置数据库。若未来必须物理回退，须独立审批、导出全部关联数据、验证恢复并处理新增引用；本次未执行破坏性回退。商机金额恢复需按审计来源进行显式业务修正，禁止盲目以旧值覆盖后续修改。

## 候选复用总结

可候选复用：金额字符串与定点计算、不可变商业快照、显式状态命令、CAS 与请求幂等、弹窗内错误、独立责任模块维护金额来源。依据为本次契约、数据库和浏览器测试；适合有报价/订单等商业单据的系统。

不可直接复用：CNY 含税口径、客户旧表映射、应用权限码、本人数据范围、系统过期任务标识和本地 Chrome 路径。生产容量、对外签署和组织范围尚未验证。这里只记录候选，不自动晋升 patterns 或宣称最佳实践；不修改方法论规则。
