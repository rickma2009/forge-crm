## ADR-022-CREATE：创建即持久化

使用既有 React/CSS、Nest 服务和 sd_quotation / sd_quotation_line 销售交易聚合，唯一写入者 QuotationService。租户/应用复合外键、UUID 主键、系统单号及当前审计表继续沿用；opportunityId 的空值表示独立报价，非空表示关联，不建重复状态字段。确认创建使用严格判别输入、服务端解析客户、事务锁定商机并读取产品、校验有效价格、一次性保存明细；创建前幂等检查使用原始选择参数，重试不因后来商机变化而重复创建。PATCH 校验不可变客户/商机，其他状态和有效期规则保持。无 DDL、无数据迁移；历史数据不修改，回退应用代码即可。数据库/API 测试验证事务回滚、归属锁定、幂等；UI 验证切换、搜索、错误和合计。沿用当前 Q 单号系统规则，本次不新增编号体系。

本轮 Specification 与 Architecture 因行为及不变量变化重新审查；当前用户“请按下面需求更改”授权此范围的本地实施，不是独立人工评审记录或发布授权。旧定价门禁状态另行保留。

## 2026-09-25 无售价可报价增量（REQSRC-075）

- 数据：`sd_quotation_line.price_id` 从必填外键改为可空外键；保留现有外键和历史数据，不回填、不删除价格版本。迁移仅执行 `DROP NOT NULL`，回退前必须确认不存在空引用，否则不得直接恢复必填。
- 契约：报价行写入契约接受 `priceId: null`；有价格的旧客户端与历史记录保持兼容。无价格时由服务端生成可信的 `suggestedPrice=0.00`、`priceSource=UNPRICED` 快照，不信任客户端伪造来源。
- 服务：产品存在、启用、作用域和权限校验不变；只有 `priceId` 存在时才验证价格版本。商机导入缺价不再汇总为失败原因，保留商机行成交价。
- 页面：明细弹窗无价格时进入可编辑状态而不是报错；成交单价默认 `0.00`。列表明确展示“未配置定价”，所有空价格 ID 访问做空值保护。重新取价无价格时保留成交价并提示。
- 验证：契约、服务创建/保存/提交、前端弹窗和列表均覆盖无售价路径；再执行全量 workspace 与方法论校验。本增量由用户本轮明确要求实施，不虚构新的人工 Gate 记录。

## 2026-09-25 批量产品选择增量（REQSRC-076）

- 公共组件：在 `packages/web/src/common/` 新增受控产品选择弹窗，参数包含 `mode`、异步分页查询和确认回调；组件负责查询、分页、选择保持、单选/多选语义和弹窗错误，调用方负责业务取价及生成明细。
- 产品投影：沿用现有产品列表 API，只增加物料中类/小类名称的只读投影，不新增表、不改变产品身份和权限；旧调用方可忽略新增字段。
- 报价接入：新增行按钮打开多选组件，批量取价成功后原子追加本地草稿行；单行编辑仍复用原弹窗。字段文案改“单价”。该阶段保留折扣百分比的原决策已被 REQSRC-077 废止，现统一使用 0 至 1 的折扣因子。
- 验证：组件覆盖单选、多选、查询、分页、取消、失败保持；报价页覆盖批量有价/无价加入和默认数量 1。REQSRC-076 中“0.90% 折扣结果 991.00”的旧百分比口径已由 REQSRC-077 废止，契约金额测试改为折扣因子口径（1 原价、0.9 九折）。

### 商机最新报价入口（REQSRC-QUO-LATEST-20260924）

REQ-QUO-022 / AC-QUO-022 / TC-QUO-024 / TASK-022-11：删除商机详情的报价单Tab及内嵌列表，替代此前“保留报价Tab入口”的约定。保留商机信息、跟进记录、商机分析记录三个Tab。顶部新增报价单继续保留，不因已有报价而隐藏或禁止；原创建权限、停用和未保存校验不变。已有可查看报价时，在新增旁显示“报价单详情”，无报价不显示，无查看权限不查询/显示。按createdAt倒序、相同时id正序确定最后新增的可见报价，不按updatedAt，不限制只能有一单。初次打开、返回商机或窗口恢复焦点刷新，点击详情时重新查询避免陈旧指向；失败提示并允许重试，不等同无报价。复用列表API sortBy=createdAt、pageSize=1，默认列表排序仍为updatedAt。无表结构变化。

验收：存在/不存在、查看/创建权限独立、已有报价仍可新增、无报价Tab、点击前出现新报价时打开最新、服务端先排序后取1条并保留租户/用户/商机过滤。Specification按用户本次指令更新并授权本地实施，Architecture沿用现有API作用域，不涉及迁移，Release不变。
