# 增量验收：物料产品与引用名称

- 菜单标题为“物料产品管理”，查询区使用公共查询组件。
- 左侧按数据字典展示物料大类、中类、小类，选择节点后过滤右侧列表。
- 新增弹窗中字段文案为“物料”，批次管理使用 Y/N 下拉框。
- 物料编码进入三页签详情；编辑在详情页完成，定价与附件复用公共能力。
- 入库详情中的法人、仓库显示名称，禁止显示 UUID；明细显示物料编码和名称。
- 入库明细库内保存 `item_id` 并受 `md_item(item_id)` 外键约束，存量数据回填后不存在空 `item_id`。
- TC-14：从物料编码进入 `/showcase/items/{itemId}` 时，门户以 `/showcase/items` 校验页面权限并渲染详情，不返回菜单未登记 404。
- TC-15：物料详情同时展示“物料基本信息、物料定价、附件”三个页签；浏览和编辑复用该详情地址。
- TC-024-18：读取物料列表和详情时，接口返回稳定字典编码与关联显示名；更改字典项名称后，页面展示新名称，物料编码不变。
- TC-024-19：新建/修改允许空字段；无效、停用、跨系统编码拒绝；更新其他字段时保留既有停用编码；存量物料没有被推断回填。
- TC-024-20：两字典值按指定编码/排序初始化；重复初始化无变化；管理员修改名称或停用值后再次初始化仍保留人工配置，仅缺失值补齐。
- TC-024-21：升级前已有系统视图与个人视图保留原列配置，并自动追加来源/生命周期列；新建默认视图包含两列。
- TC-024-25（REQ-024-21 / AC-024-21）：物料创建、查询和入库引用接受 `001.002.0035090`；英文逗号、中文逗号、空格、小写字母和其他标点被接口及数据库拒绝。恢复演示数据后，514 条导入物料均使用来源点号编码，24 个 BOM、803 条明细、130 条替代料关系数量不变且无孤儿。
- TC-024-26（REQ-024-22 / AC-024-22）：新建表单不允许输入编码，必须选择有效大类和中类；同一中类按全部历史编码最大七位流水加一，不同中类独立计数。并发提交生成不同编码；分类缺失、父子关系错误、字典编码格式错误和流水耗尽均拒绝且不新增记录。
- TC-024-27（REQ-024-23 / AC-024-23）：一次性处理前后分别统计类型和状态；处理后产品、物料启用数为0，半成品状态分布、BOM表头/明细/替代料数量与孤儿数不变，并存在审计记录和可恢复备份。
