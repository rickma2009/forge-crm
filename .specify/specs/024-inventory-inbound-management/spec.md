# Specification：库存与入库管理

状态：APPROVED（用户已授权全部后续门禁按推荐方案执行）

## 功能需求

- REQ-024-01：系统维护租户内唯一且不可改码的统一物项，产品和物料用 `item_type` 区分。
- REQ-024-02：系统维护法人及其管理组织归属，维护法人所属仓库。
- REQ-024-03：系统创建草稿入库单，按INBOUND规则自动生成单号（默认 `IByyyyMMdd#####`），一单一仓、一次整体过账。
- REQ-024-04：草稿允许维护表头和多条明细，非草稿只读；作废保留审计。
- REQ-024-05：过账在单事务内改变状态、原子累计余额、逐行生成流水和事件；重复请求幂等。
- REQ-024-06：已过账单只允许整单冲销一次；冲销生成反向流水，余额不足拒绝。
- REQ-024-07：库存明细只读并支持筛选、分页、汇总/批次视图、视图配置和导出。
- REQ-024-08：旧 `md_product` 及产品定价、报价、商机商品引用迁移到 `md_item.item_code`，迁移前后无孤儿数据。
- REQ-024-09：页面和动作由角色权限控制；admin 全权限，viewer 只读。
- REQ-024-10：“物料产品管理”使用左侧物料大/中/小类级联树和右侧列表；`md_item` 保存三级分类引用，列表及详情显示分类名称。
- REQ-024-11：新增物料使用弹窗，批次管理使用 Y/N 下拉框；浏览和编辑进入“物料基本信息 / 物料定价 / 附件”三页签详情，不再通过编辑弹窗浏览。
- REQ-024-12：入库单、入库明细及其他引用主数据的页面只显示业务编码和名称，不显示 UUID；API 必须批量解析引用名称。
- REQ-024-18：物料来源与生命周期分别使用 `item_source`、`item_lifecycle` 字典；物料记录保存稳定字典项编码，列表/详情按当前字典关联显示值。来源编码依次为 `PURCHASED`、`SELF_MANUFACTURED`、`OUTSOURCED_PROCESSING`；阶段编码依次为 `INITIAL`、`SAMPLE`、`TRIAL_PRODUCTION`、`SMALL_BATCH`、`MASS_PRODUCTION`、`PHASE_OUT`、`DISCONTINUED`、`VOIDED`。
- REQ-024-19：两字段允许空值，不设置推断性默认值；创建页面留空提示用户选择。服务端拒绝不存在、停用或其他系统字典中的新引用；既有物料保留空值，不进行名称推断回填。更新其他字段时，未修改的既有停用编码应允许保留。
- REQ-024-20：关键展示中的可变字典/主数据引用保存稳定引用键并按权限和作用域解析最新名称；仅业务保证不可变的文本允许名称快照。历史快照须与当前名称分开。
- REQ-024-21：物料编码允许大写字母、数字、英文句点`.`、`-`、`_`，最长32字符；逗号、空格、小写字母及其他标点无效。该规则仅用于 `md_item.item_code` 及其业务引用字段，不放宽法人、仓库、原因、工厂和字典项编码。编码在租户内唯一且创建后不可修改。
- REQ-024-22：物料产品新建编码由服务端按“启用的大类编码.启用的中类编码.该中类最大七位流水+1”生成；前端不提交编码。流水按租户和中类隔离，停用历史记录参与最大值计算，并通过数据库事务锁防止并发重号。大类、中类为必填且须保持父子关系，分类编码必须为 `三位数字` 和 `大类.三位数字`，流水耗尽时拒绝新建。
- REQ-024-23：执行一次性数据处理，将当前既有 `PRODUCT`、`MATERIAL` 全部停用并递增版本，保留 `SEMI_FINISHED`、BOM及所有历史引用。

## 2026-10-05 新增需求（已确认）

来源：`.specify/sources/REQSRC-102-item-source-lifecycle-and-reference-codes-20261005/source.md`。

物料来源字典 `item_source` 提供“外购、自制、委外加工”；物料生命周期阶段字典 `item_lifecycle` 提供“初始、样品、试产、小批量、批量、即将退市、已退市、已作废”。物料记录保存各字典项稳定编码，列表及详情关联当前字典显示值。

关键页面、列表、表单回显和导出中的可变字典/主数据引用保存稳定编码或 ID，并受控解析当前值/名称；仅业务保证初始化后不可变的文本可保存名称快照（如员工姓名）。部门等可变关系保存稳定引用并按当前名称展示。历史快照与当前名称用途分离。

用户已确认增量方案：字段可空且不做默认回填；既有记录保持空，稳定编码和停用项编辑行为按 REQ-024-19。迁移仅新增可空字段，不改变历史快照。字典通过幂等专项初始化补齐，既有人工名称与状态不覆盖。

## 状态机

```text
DRAFT --post--> POSTED --reverse--> REVERSED
  |
  +--void--> VOIDED
```

其他转换一律返回409。

## API

- `GET/POST/PATCH /api/systems/:systemCode/legal-entities`
- `GET/POST/PATCH /api/systems/:systemCode/warehouses`
- `GET/POST/PATCH /api/systems/:systemCode/items`
- `GET/POST /api/systems/:systemCode/inbound-orders`
- `GET/PATCH /api/systems/:systemCode/inbound-orders/:id`
- `POST /api/systems/:systemCode/inbound-orders/:id/post`
- `POST /api/systems/:systemCode/inbound-orders/:id/reverse`
- `POST /api/systems/:systemCode/inbound-orders/:id/void`
- `GET /api/systems/:systemCode/inventory-balances`

写接口必须使用 CSRF、角色动作权限、版本号；post/reverse 还要求 `requestKey`。

## 失败行为

- 无权限：403；对象不存在：404；版本或状态冲突、重复业务键：409；输入或主数据不合法：400。
- 数据库或流水写入失败时不得留下部分余额或已过账状态。
- 相同 requestKey 和相同载荷回放原结果；相同 requestKey 不同载荷返回409。

## 页面规格

物料产品、法人、仓库、入库单、库存明细均使用 `UI-QUERY-01` 统一查询区。编码或单号为详情入口，操作列只使用有提示和 aria-label 的图标。物料产品左侧为数据字典驱动的三级分类树，右侧为列表；物料详情为三页签。入库详情顶部展示返回、单号和状态，Tab 为基本信息和入库明细；草稿行用弹窗维护。引用字段保存 ID，但页面显示引用对象名称。

REQ-024-16：物料详情动态地址 `/showcase/items/{itemId}` 的页面授权必须映射到已登记的物料产品菜单 `/showcase/items`；`itemId` 只决定加载哪条记录，不参与菜单资源匹配。浏览与编辑复用该动态地址和同一个三页签详情组件，页签为“物料基本信息、物料定价、附件”。

AC-024-18：物料来源与生命周期字典在初始化后含规定的稳定编码和中文值；编码存入物料列，详情/列表/导出显示当前字典名称，字典名称调整后无需改写物料编码即可显示新名称。

AC-024-19：空字段可保存；不存在、停用、跨系统新引用被服务端拒绝；历史物料保持空值；原有停用值未被修改时可保存其他物料字段。

AC-024-20：初始化可重复执行且不覆盖管理员已改名称、停用状态或其他既有值；仅补缺少的字典及项。

AC-024-21：创建物料及提交入库明细时，`001.002.0035090` 可通过接口和数据库约束，包含英文或中文逗号的编码被拒绝；本批 Excel 演示数据恢复点号后，514 条物料、24 个 BOM、803 条 BOM 明细和130条替代料关系数量不变且无孤儿。来源：`.specify/sources/REQSRC-104-item-code-dot-20261005/source.md`。

AC-024-22：中类 `004.028` 已有最大流水 `0000122` 时，新建返回 `004.028.0000123`；无历史时返回 `0000001`。两个并发新增不得取得相同编码。缺少大类/中类、父子关系错误、非三位数字分类编码或流水超过七位时返回明确错误。

AC-024-23：处理后 `PRODUCT`、`MATERIAL` 的启用数均为0，原停用记录保持停用；`SEMI_FINISHED` 状态不变，BOM表头、明细、替代料数量及引用关系不变。来源：`.specify/sources/REQSRC-105-item-code-generation-disable-existing-20261005/source.md`。

AC-024-16：管理员从物料编码进入详情时不出现“页面未找到”；三个页签均可见。具有更新权限时可在详情页进入编辑态；不具有更新权限时保持只读。未知静态页面仍返回门户 404，详情记录本身不存在时由业务接口返回对象不存在状态。

## 2026-10-03 库存查询页面（当前有效）

`/showcase/inventory-balances` 为“当前库存”：同一行筛选法人、仓库、物料编码和名称、三级分类；服务端按物料编码和币别汇总余额，数量及金额来自 `scm_inventory_balance`，不同币别不混算。物料编码驱动下方法人、仓库、批次余额表；未选物料时不查询、不显示明细。两表均分页，导出当前筛选范围的汇总或所选物料明细。

`/showcase/inventory-transactions` 为“库存事务明细”：事务类型、单号、物料编码和名称、起止日期同一行筛选，独立分页；展示事务时间及末列单据行号。来源单据行号使用 `scm_inventory_txn.line_no`，入库与销售出库过账已有写入，不新增迁移。两页只读，沿用原库存查看权限，新当前库存页单独授权导出。原“库存明细”余额加流水混排页面已被上述两个页面替代。来源：`REQSRC-089`。

查询动作的实现验收补充（2026-10-03）：两个页面再次提交相同条件、或在条件已空时重置，都必须重新请求当前数据。输入草稿仍不自动请求；显式提交的刷新意图与筛选值分开维护。当前库存重新查询仍清空下方所选明细，非法期间不得请求。此为既有查询行为的缺陷修正，不增加库存计算、权限或数据结构。
