# 规格：商机核心工作区

- `BUS-022`：建立客户—商机—商品闭环。
- `REQ-1801`：商机列表支持关键词、客户、模板、阶段、负责人和状态查询。
- `REQ-1802`：新增弹窗保存后直接进入三 Tab 详情。
- `REQ-1803`：商机引用现有客户、联系人、用户；联系人必须属于客户。
- `REQ-1804`：商机信息维护多个商品行，金额按数量×单价计算。
- `REQ-1805`：商机详情工作区 Tab 固定显示“商机详情”，商品信息区域直接提供新增、修改、删除商品行操作。
- `AC-1801`：新建后进入详情，默认模板/阶段正确。
- `AC-1802`：商品停用不可新选，历史快照可读。
- `AC-1803`：越权或版本冲突写入被拒绝。
- `AC-1804`：拥有更新权限的用户可在详情商品区域逐行新增、修改、删除；无更新权限时操作不可用，变更通过商机版本和原子更新保存。
