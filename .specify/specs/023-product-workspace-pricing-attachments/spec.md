# 切片 023：产品工作区、有效期定价与通用附件

## 用户故事

- `US-023-001`：产品维护人员可从列表新增产品，并在稳定详情工作区查看、编辑产品而不依赖列表弹窗。
- `US-023-002`：价格维护人员可配置带有效期的标准或阶梯价格，报价按业务日期获得唯一且可追溯的建议价。
- `US-023-003`：获授权人员可在产品详情使用统一附件组件管理产品文件，该组件以后能以参数方式接入其他业务对象。
- `US-023-004`：产品管理员只能删除完全未被业务与附件引用的产品，任何并发或直接 API 均不能绕过校验。

## 行为契约

### 产品删除

1. 用户发起删除并确认；客户端可显示预检查结果。
2. 服务端校验产品版本和删除权限，在事务中统计全部受控引用。
3. 任一引用大于零，返回 `409 PRODUCT_REFERENCED` 及不含敏感明细的 `{opportunities, quotations, prices, attachments}` 计数。
4. 全部为零才删除；外键约束作为并发安全的最后防线。

### 有效价格

对于报价日期 `D`，候选价格满足 `effectiveDate <= D` 且 `expiresDate IS NULL OR expiresDate >= D`。候选必须恰好一条；零条或多条均拒绝自动取价。阶梯按 `lowerQty <= quantity < upperQty` 匹配，末段上界为空。

### 通用附件

组件最小参数为 `ownerType`、`ownerId`、`capabilities`；服务端不信任 `capabilities`，仍基于当前会话和归属对象授权。上传返回附件元数据；下载只通过附件 ID 的鉴权端点；编辑只允许说明和手工版本，不允许通过改元数据替换文件正文。

## 错误与边界

- 价格日期区间、同产品币别重叠、阶梯断档/重叠、负价或非法精度：整次保存失败且不产生半版本。
- 报价日期修改后必须重新解析建议价；已人工覆盖成交价不得被静默替换。
- 文件过大、类型不允许、路径穿越、空文件、重复提交或物理写入失败：就近提示，不产生可见孤立附件。
- 归属对象不存在、已删除、跨租户/应用或无权访问：附件 API 默认拒绝。
- 删除与上传、报价引用或调价并发时，最终数据库状态不得出现孤立记录或被删除产品的新引用。
