# 切片 023 Architecture Gate 评审材料

## 结论建议

建议批准 [Architecture Plan](plan.md)。方案在不重建产品身份、不改写历史报价的前提下，解决有效日期定价、产品安全删除和附件复用问题。

## 关键决策

- `md_product` 仍由产品模块唯一写入，`sd_product_price` 仍由销售定价模块唯一写入。
- 有效期用数据库排他约束和服务事务双重保证，取价业务日期为报价日期。
- 通用附件使用 `sys_attachment`，多态归属以受控 registry 补偿不能建立通用外键的限制。
- 文件系统与数据库无法形成真正分布式事务，因此使用临时文件、原子 rename、删除状态机和可重试清理，而不虚构原子性。
- 产品删除在串行化事务内统计引用，并由 `RESTRICT` 外键兜底。

## 数据治理登记

| 项目 | 结论 |
|---|---|
| 数据层级 | `md_product` 主数据；`sd_*` 销售交易/配置；`sys_attachment` 平台公共元数据 |
| 唯一责任模块 | product / quotation / attachment |
| 租户与应用范围 | 产品和价格按租户；附件按租户+应用；报价按租户+应用 |
| 主外键 | 价格和商机/报价产品引用 `md_product`；附件 owner 由 registry 验证 |
| 状态与有效期 | 价格状态+日期区间；附件删除状态机 |
| 删除与审计 | 产品物理删除仅限零引用；历史价格和报价 RESTRICT；关键操作写审计 |
| 迁移恢复 | 旧价格回填、约束后置、数据库+文件联合备份、一致性扫描 |
| 数据库测试 | 回填、约束、引用竞态、跨租户和回滚前置条件 |

`sys_attachment` 使用已批准公共前缀；全部新增标识符采用小写 snake_case 且不超过 32 个字符。

## 风险与处置

- 存量多个价格版本没有有效期：只激活最新版本，旧版本保留给历史报价引用。
- 文件删除部分失败：保留失败状态并允许重试，不返回虚假成功。
- 多态 owner 无数据库 FK：只允许登记类型，归属服务校验和一致性测试兜底。
- 日期边界与时区：数据库使用 `DATE`，前后端传 `YYYY-MM-DD`，不以 UTC 时间戳推导报价日期。
