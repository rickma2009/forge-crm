# 功能规格：我的收藏

> 功能编号：042-personal-favorites

## 用户故事

- US-042-01：业务用户在可用列表快速收藏/取消收藏记录。
- US-042-02：业务用户从任意工作区统一查看自己的收藏、打开记录或确认取消收藏。

## 数据显示与引用边界

持久化 `target_type` 与 `target_id` 稳定身份，不存对象名称。客户、产品、物料、商机、报价和销售订单名称/编号均会变化或属引用展示值，收藏列表批量关联对应权威业务表当前值；引用缺失/无权时显示不可用，不展示内部 ID。收藏时间为关系创建时间，取消即物理删除该个人关系，无历史保留要求。

## 默认交互

- 行操作：未收藏显示“收藏”，已收藏显示“取消收藏”；点击后更新服务端状态并保留列表上下文。
- 顶栏：图标始终位于会话工具栏，在系统切换后加载目标系统下的收藏。
- 收藏列表：默认按收藏时间倒序；对象值是详情链接，仅当目标存在且当前读取授权允许时为可点击链接。
- 取消：统一确认对话框；取消弹框不改状态，确认后移除该行；失败保留行并提示错误。
- 空态、加载态、失败态必须可识别；失败时允许重试。
