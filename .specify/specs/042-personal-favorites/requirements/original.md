# 原始需求与当前态增量

原始输入已不可改写归档：`../../sources/REQSRC-108-personal-favorites-20261006/source.md`。

系统支持用户对客户、产品、物料产品、商机、报价单、销售订单记录收藏。收藏关系集中持久化，顶部工具栏图标打开按收藏时间倒序的列表；列表展示序号、时间、对象类型和当前对象名称/编号，并在取消前确认。客户、物料产品、商机等列表提供行操作收藏。不增加独立收藏权限，仍由既有业务授权和数据范围保护记录读取。详细当前态见 `../../requirements/017-personal-favorites/requirement.md`。
