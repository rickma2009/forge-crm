# 测试用例：我的收藏

## 测试策略

覆盖唯一性/作用域、跨类型显示名称的批量解析、复合隔离、授权及数据范围拒绝、收藏/取消 API、顶部列表、行操作和取消确认。

| ID | 类型 | 关联 AC | Given | When | Then | 优先级 |
|---|---|---|---|---|---|---|
| TC-042-01 | service/database | AC-042-01 | 当前用户可读一个支持类型记录 | 重复提交收藏 | 仅一条关系，重复操作返回幂等成功 | P0 |
| TC-042-02 | service/database | AC-042-02 | 两用户或两个系统有相同目标 ID | 分别读取/取消 | 只可见并操作自己的当前作用域收藏 | P0 |
| TC-042-03 | service | AC-042-03 | 每种收藏类型有一个目标记录 | 读取收藏列表 | 名称/单号映射正确，按时间倒序，非逐收藏 N+1 查询 | P0 |
| TC-042-04 | service/security | AC-042-04 | 目标记录当前用户不可见或无查看权限 | 添加或读取收藏 | 添加拒绝；已有收藏名称不泄露并提供不可用占位 | P0 |
| TC-042-05 | API | AC-042-05 | 有效会话与 CSRF | 收藏、重复收藏、列表、取消 | 状态正确、取消范围限定当前用户与当前系统 | P0 |
| TC-042-06 | web | AC-042-06 | 登录后可进入任意门户页面 | 点击全局收藏图标 | 列表显示序号、时间、对象类型、对象值和默认倒序 | P0 |
| TC-042-07 | web | AC-042-07 | 可见客户/产品/物料/商机/报价/订单列表 | 收藏或取消一行记录 | 相应图标和状态正确；不因编辑权限隐藏 | P0 |
| TC-042-08 | web | AC-042-08 | 列表中有收藏 | 点击列表取消 | 先出现确认；取消时不变，确认后移除并更新来源行 | P0 |
| TC-042-09 | browser | AC-042-09 | 已登录且有多类型收藏 | 访问收藏列表、打开记录、取消 | 详情路由正确、对话框确认可访问、键盘焦点正常 | P1 |
