# 澄清与实施决策

来源为用户明确需求 `.specify/sources/REQSRC-108-personal-favorites-20261006/source.md`，并结合用户此前“按建议继续开发”的持续授权。本切片按建议覆盖客户、产品、物料产品、商机、报价单和销售订单。

- 收藏按钮不新增单独权限；服务端仍检查目标对象既有查看权限和客户数据策略，防止收藏接口绕过业务读取边界。
- 保存对象类型及记录 UUID，不复制对象名称；列表展示时按固定 resolver 读取当前名称/单号。
- 收藏按当前登录用户、租户和应用隔离，重复收藏幂等；取消收藏须确认。
- 暂不限制收藏数量，不为多态 `target_id` 添加不正确的单表外键；目标有效性由服务端白名单与作用域查询确认。
- 当前实现授权不代表生产发布授权。数据库真实迁移和浏览器验收受本机环境限制，详见 `review.md`。
