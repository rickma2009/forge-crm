# 实施自审

> 性质：AI 自审，不冒充独立评审或 Release Gate。

- 组织表属于 `org_` 企业共享主数据，唯一责任模块为 organization；未放入 `sys_` 或 CRM 业务域。
- 同租户父级由复合外键和服务解析双重约束，循环由服务事务内完整父链校验。
- depth 为读取派生值，没有成为可漂移的持久事实。
- 组织编码不可修改，写操作使用版本号并与白名单审计同事务。
- 页面复用企业查询卡片、表格、弹窗和全局字体，没有引入第二套视觉体系。
- 员工、岗位、负责人、标签和数据权限没有被虚构进首片。
- `pnpm verify`、数据库 migration、连续两次 Seed 和 DB integration 38/38 已通过；带身份浏览器视觉复核和独立评审尚未完成，因此没有 Release 结论。
