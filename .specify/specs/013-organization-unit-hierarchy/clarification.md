# 澄清与批准决策

- 组织为租户级企业共享主数据，物理表使用 `org_`，不使用应用域前缀。
- 首片只实现单父级组织树：公司、事业部、部门、团队；层级动态计算。
- 组织编码租户内唯一且创建后不可修改；有效期使用 `[effective_at, expires_at)`。
- 服务端阻止跨租户父级、自引用和循环；所有写入带乐观锁与审计。
- 负责人依赖尚未落地的员工与负责人时态关系，本切片不伪造单值负责人字段。
- 页面位于系统管理，由角色权限控制；admin 的系统管理员角色拥有查看和维护权限。
- 访问管理三页查询区采用场景清单的查询卡片、栅格和按钮组结构。
- 依据用户直接实施请求及既有连续授权，本切片 Business、Specification、Architecture 采用推荐决策继续本地实现；Release 不自动批准。
