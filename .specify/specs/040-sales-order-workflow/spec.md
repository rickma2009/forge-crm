# 规格

BUS-SWF-01 真实销售订单审核通过Flowable完成，业务状态与引擎结果可恢复。
REQ-SWF-01 配置受权限控制，发布不可变版本和申请部门负责人规则，完整图可查看。
REQ-SWF-02 提交与申请/启动命令同事务；一订单仅一活跃轮次，路由字段快照，审批中不可修改；旧审核禁绕过。
REQ-SWF-03 真实待办/已办/发起分页，参与者限定读取；操作校验权限、承办人、任务版本，转交资格与意见。
REQ-SWF-04 业务审核和执行收件标记同事务，启动/结果超时同键重试，错误可授权重试。
REQ-SWF-05 真实审批中心和订单底部区域共用固定版本完整图与历史；通知未读可见。
NFR-SWF-01 租户应用隔离、CSRF、RBAC及有效用户任职；缺负责人失败关闭。

AC-SWF-01 发布与缺人阻止。AC-SWF-02 提交原子性和审核禁绕过。AC-SWF-03 审批角色与转交冲突。AC-SWF-04 故障恢复不重复生效。AC-SWF-05 真实列表/图/消息。AC-SWF-06 跨作用域与越权不可见。
