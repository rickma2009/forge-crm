# 验收用例

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| COMP-TC-01 | 进入模板库，展开插件组件 | 二级节点为组件名，点击显示对应详情 |
| COMP-TC-02 | 按编码、名称搜索，复制接入示例并返回 | 仅匹配组件，复制文本正确，返回保持分类 |
| COMP-TC-03 | 查看效果图与应用案例 | 图片来自真实页面，来源和实际页面链接一致 |
| COMP-TC-04 | 重复执行组件登记脚本 | 组件无重复，42 个模板仍可查询 |
| COMP-TC-05 | 组件没有可用截图或说明字段 | 页面明确留空或省略该段，不误称已截图 |
