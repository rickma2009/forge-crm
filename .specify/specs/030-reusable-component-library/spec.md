# 可复用插件组件目录规格

状态：已实施并验证；来源 [REQSRC-087](../../sources/REQSRC-087-reusable-component-library-20261003/source.md)。

- `COMP-REQ-01`：交互模板库现有两级树增加一级“插件组件”，其二级节点直接以组件名称显示。原模板编码、分类、链接和查询不受影响。
- `COMP-REQ-02`：只登记仓库已有可复用公共组件或明确标注业务域边界的组件；每条有稳定编码、用途、源码路径、接入示例、适用边界及实际应用页面。
- `COMP-REQ-03`：复用现有详情结构，但组件不适用的说明段可为空或不显示；不能把组件描述成一整个页面模板。
- `COMP-REQ-04`：效果预览采用系统实际运行页面的局部截图，并记录来源页面、路由、日期、截图区域。无法真实截图的组件明确留空，不用示意图替代。
- `COMP-REQ-05`：目录数据从版本化源登记到现有数据库资产表，由现有 API 提供；种子重复执行幂等，旧模板和历史资源不被删除。

## 验收

- `COMP-AC-01`：打开交互模板库可见“插件组件”及组件名称；点击后只显示对应组件详情，搜索、返回和链接参数可用。
- `COMP-AC-02`：详情展示源码入口、可复制接入示例、使用边界和真实应用案例；无关空段不占空间。
- `COMP-AC-03`：截图为实际页面内容，有来源说明和实际页面链接。
- `COMP-AC-04`：种子多次执行不重复建档，原 42 个页面模板完整保留。

## 实施与验证记录

- 登记 15 个 `CMP-*` 公共组件，源码入口、最小接入示例、使用边界、关联页面及真实截图统一维护在 `_methodology/components/index.json`。
- 原有 42 个 `TPL-*` 页面模板继续保留；演示库查询同时读取两种编码，旧的仅模板筛选仍可使用。
- 定向契约、服务端登记及查询、前端目录及详情测试通过；Web 与 Server 类型检查通过；运行页面验证了组件直达链接、源码和预览图片。
