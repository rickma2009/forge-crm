# 公共页签操作增量

来源：../../sources/REQSRC-038-common-route-tabs-20260921/source.md。用户明确要求读取 supply 并在当前工程实现公共方法；沿用既有 React、Hash 路由和权限边界，无新技术或业务域决策。此增量的本地实现以本次请求授权推进，不修改其他切片或发布 Gate。

## Spec / 验收

- REQ-TAB-01 / AC-TAB-01：每个已打开页签可右键打开菜单，提供刷新当前、关闭当前、关闭其他、关闭右侧、关闭全部、在新窗口打开。
- REQ-TAB-02 / AC-TAB-02：当前指右键目标。固定首页不可关闭；批量关闭保留固定页签。关闭当前激活页优先右邻、再左邻；关闭非激活页不切换；关闭其他激活目标；关闭右侧仅在激活页被移除时切换目标；关闭全部回首页。
- REQ-TAB-03 / AC-TAB-03：刷新目标后显示目标并重新挂载其内容；不重载整个浏览器。新窗口使用目标完整 Hash 地址并隔离 opener。
- REQ-TAB-04 / AC-TAB-04：菜单在可视区内显示，外部点击、Esc、滚动或导航后关闭；键盘 Shift+F10 可打开，上下/Home/End 导航菜单，禁用无效操作。
- REQ-TAB-05 / AC-TAB-05：通用代码不依赖 CRM、菜单注册表、后端或项目路径；授权仍由外壳校验，未授权地址不因菜单绕过权限。

## Testcases / Plan / Tasks

TC-TAB-01：纯函数验证所有关闭方式、固定页保护、无效目标、刷新版本及不变性。
TC-TAB-02：组件验证右键目标、禁用状态、键盘/外部关闭、打开地址。
TC-TAB-03：外壳集成验证刷新内容、关闭后的 Hash/激活同步及已有权限回归。

TASK-TAB-01：只读参考归档，记录差异；TASK-TAB-02：实现 framework-independent 状态函数 + React hook + 公共组件；TASK-TAB-03：外壳接入及验证；TASK-TAB-04：复用指南和实际证据。

技术计划：新增 common/route-tabs，纯函数返回新页签和导航目标；React hook 对接外部路由；组件通过 Portal 展示菜单；外壳仅传授权路由、首页和 Hash URL 适配，内容 key 使用 path + refreshKey。

边界：保留既有切换时页面卸载行为，不引入 KeepAlive、持久化、拖拽、supply 专用路由归并或未保存表单拦截。未来含编辑草稿场景需先补关闭/刷新保护策略。参考不是已验证最佳实践。
