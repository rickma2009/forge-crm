# 实施方案

系统平台numbering模块唯一管理sys_code_rule/sys_code_counter/sys_code_issue。规则应用作用域；计数器租户对象命名空间；发号含应用、规则版本及请求标识。同作用域组合外键、UUID、timestamptz、CHECK、唯一约束、审计与删除限制。Prisma增量迁移，不改历史迁移或业务编码。初始化create默认、update空保持人工配置。

数据库原子advisory事务锁覆盖取号及配置编辑；发号用独立短事务提交，业务事务失败保留账本，允许断号。首次/变格式扫描真实已存编码与已发账本的精确格式最大流水，后续用持久计数，候选号再次查重。无SQL标识来自用户。服务端接口不接受任意取号日期，便于验证周期。

先规格/失败路径，后持久化/服务/API/页面/对象接入，最后临时库并发/幂等/权限/真实新增与浏览器。已有本地库使用新迁移；空库历史迁移问题独立记录，测试基线+实际本包DDL。回滚应用前停用新写入，保留规则及发号账本，后续前滚修复；禁止删除账本或回收号码。
