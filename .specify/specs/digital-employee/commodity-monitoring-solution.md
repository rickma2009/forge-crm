# 大宗商品监控数字化员工方案

## 目标与范围

在“数字员工 → 财务 → 大宗商品监控”每月获取铜、铝、金、银的免费公开月度基准价和 USD/CNY 汇率，保存美元价格及按该月份最近可用汇率换算的人民币价格。首次采集回补最近 12 个可用月份；之后按持久化的成功获取进度续取。不请求日级商品行情，不自动交易或修改报价、BOM、采购订单。

## 页面结构

| Tab | 能力 |
|---|---|
| 接口设置 | 展示免费公开的 World Bank Pink Sheet 月度商品数据与 Frankfurter USD/CNY 汇率；配置时区和每月采集时间，提供连通检查、历史回补/增量同步、最近运行及上次成功时间。无需外部 API Key。 |
| 监控商品 | 维护启用商品、来源代码、市场基准和报价单位；预置铜、铝、金、银。数据频率固定为月度。 |
| 获取列表 | 默认按月份倒序展示商品、月度美元基准价、USD/CNY 月内最近可用汇率及生效日期、人民币换算价、单位、来源、获取时间和状态；支持商品、月份和币种筛选。 |
| 价格走势图 | 选择商品和美元/人民币，展示真实月度数据点；不提供日/周视图。不同报价单位不混合比较。 |

## 采集与进度规则

1. 首次启用商品时回补最近 12 个可用月份，之后每月获取最新文件。历史文件若包含更早数据可以作为首次回补来源，但界面默认展示最近一年。
2. 每月计划按配置时区运行（建议 `Asia/Shanghai`）。商品源为世界银行月度 Pink Sheet；USD/CNY 来源 Frankfurter 无需 Key。人民币换算使用该月份最新可用汇率并保存其实际日期。
3. 保存每个商品上次成功月份及独立的汇率日进度、成功时间。后续下载月度工作簿并按月份幂等 upsert，允许重跑最近月份以容忍来源修订。
4. 对应范围成功持久化后才推进进度。失败时保留旧进度并记录错误、允许重试；部分商品成功时只推进成功商品进度，不能因其他商品失败而跳过数据。
5. 每次运行保存开始/结束时间、触发类型、请求日期范围、成功/失败数量和错误摘要。每条行情另存实际获取时间。“最近运行时间”不能替代“上次成功获取时间”。
6. 行情快照保存美元原价、当日汇率、人民币换算价及来源原始返回值。重复请求幂等更新当前快照；若来源后续修订历史数据，当前快照会更新并刷新最近获取时间，不保留逐版本历史。
7. 缺失行情或汇率时标记待补齐/失败，不使用 0 或未标记汇率。商品月度价不是该月逐日成交价，也不是交易所官方结算价。

## 数据源决策与边界

- 商品价格采用世界银行 Commodity Price Data (Pink Sheet) 官方公开月度工作簿，包含铜（美元/公吨）、铝（美元/公吨）、金（美元/金衡盎司）、银（美元/金衡盎司）。工作簿是月度基准数据，不提供日行情；需从官方目录解析当前文件链接，因为文件版本路径会更新。[官方数据目录](https://thedocs.worldbank.org/en/doc/5d903e848db1d1b83e0ec8f744e55570-0350012021/)
- USD/CNY 使用 Frankfurter v2 官方无 Key 查询，保留每日汇率记录；将该月最后一个有效汇率用于月价格换算，并存实际汇率日期。[API 文档](https://frankfurter.dev/)
- 服务端仅允许访问固定的 World Bank 与 Frankfurter HTTPS 域名。World Bank 月度商品指标不代表逐日成交或可执行采购价；页面需展示来源、统计周期和单位。

## 待定口径与实施边界

- 世界银行数据为免费公开的月度基准价，不能替代 LME、COMEX 或 SHFE 官方结算价、现货成交价或采购执行价。
- 月度工作簿的版本路径会变化，服务端每次采集从官方商品目录定位 XLSX；若目录结构或文件格式变化，检查/采集应明确失败并保留进度。
- 周末或节假日没有每日汇率时，使用该月结束日前最近一个已发布的 USD/CNY 汇率，并保存实际生效日期。
- 持久化使用月度行情快照、日汇率快照、每商品游标和运行记录。旧日行情保留在数据库，但界面只展示 `WORLD_BANK_PINK_SHEET` 月度数据。

## 验收要点

- 四个 Tab 展示月度免费来源能力；接口检查验证世界银行目录、XLSX 与 Frankfurter 汇率，无需 Key。
- 首次回补最近 12 个可用月份，重复回补幂等；没有的月份不补造价格。
- 每商品月份和汇率分别保存成功进度；失败不推进失败范围，部分成功只推进已落库商品。
- 月度 USD 价格按月份结束日之前最近可用 USD/CNY 汇率换算，并保存汇率、生效日期、美元值、人民币值及单位。
- 走势图只使用真实月度点，提供美元/人民币切换，不显示日/周粒度。
- 目录、文件解析、汇率不可用及来源更新均有明确状态和重试路径。
