# 验收用例

1. 登录后可从纯机器人图标进入数字员工，页面不依赖 5175 原型服务。
2. 任务列表可按关键字、领域、状态查询并分页；业务编号为详情入口。
3. 场景卡可查看，评估不足 80 分不能启用，达到门槛可保存评估状态。
4. 数字员工配置保存后刷新仍存在；无管理权限不能修改。
5. 外部邮箱选择 IMAP/SMTP 时要求主机、端口、TLS 与账号；Graph/Gmail 要求租户或客户端信息；密钥不回显。
6. 未配置加密密钥时提交邮箱密码/客户端密钥失败关闭；无凭据的连接保持等待配置。
7. 顶部最后一个入口只显示“我的”图标，点击仍能查看当前账号并退出。
8. IMAP 连接测试使用已加密凭据执行真实认证，成功后状态为已连接；密钥和授权码不出现在响应或日志中。
9. 首次只读同步可生成分类待办，立即再次同步时新增数为 0；同步不发送、删除、归档或标记邮件已读。
10. 工作台的待处理任务默认每页 20 行，“任务”列宽于其他普通字段列。
11. 邮件自动化计划可保存启停、分钟间隔、星期、生效时段、批量数和重试次数；到期后自动产生计划运行记录。
12. 邮件规则可按发件人、主题、正文或分类匹配，并生成待办、已处理结果、回复草稿或待删除动作。
13. 回复规则没有模板时契约拒绝保存；自动发送默认关闭且空白名单时不能发送。
14. 待确认的回复或删除动作经人工确认后升级为待执行；重复确认复用同一个动作，不重复发送或删除。
15. 自动回复拦截 no-reply、黑名单和非白名单域名，并执行分钟与小时发送上限。
16. 邮件删除只移动到配置的回收站文件夹；页面与数据库均保留处理结果、处理时间和执行记录。
17. 动作失败按运行计划中的重试次数退避重试；达到上限后标记失败，不无限重试。

## 分类导航与场景工作区验收

- `TC-DE-NAV-01`（`AC-DE-NAV-01`）：登录后左侧层级为“数字员工 → 公共/营销/供应链/研发/财务/生产与质量 → 具体场景”；未授权场景不显示，直接访问拒绝。
- `TC-DE-NAV-02`（`AC-DE-NAV-02`）：点击顶部机器人图标仍进入 `/showcase/digital-employee`，核对工作台的默认视图和内容不变。
- `TC-DE-NAV-03`（`AC-DE-NAV-03`）：邮件连接正常时首 Tab 展示服务端真实待处理邮件；未连接时为等待配置；后续 Tab 提供运行计划、规则、模板及接口状态，凭据不回显。
- `TC-DE-NAV-04`（`AC-DE-NAV-04`）：信息获取页面只显示真实授权来源数据；未接入/采集失败时显示等待配置或无数据，不呈现虚构记录、指标或分析结论。
- `TC-DE-NAV-05`（`AC-DE-NAV-05`）：打开多个场景路由并切换内容 Tab，确认全局路由页签和页面内 Tab 各自保留正确状态。
- `TC-DE-NAV-06`（`AC-DE-NAV-05`）：未接入的场景显示连接器等待配置，不触发外部读写或正式业务动作。
- `TC-DE-NAV-07`（`AC-DE-NAV-06`）：执行数字员工菜单定向回填并刷新当前系统，确认侧栏默认展示已授权的二级分类和三级场景；受限角色不显示无权场景。

- `TC-DE-NAV-08`（`AC-DE-NAV-07`）：检查菜单仅出现九个新名称和“邮件处理”，RFQ、SMT、序列号追溯菜单不可见；底层场景记录保留。
- `TC-DE-NAV-09`（`AC-DE-NAV-08`）：打开“邮件处理”，已连接时默认选中待处理邮件 Tab；无已连接邮箱时呈现等待配置说明。

- `TC-DE-NAV-10`（`AC-DE-NAV-09`）：逐一检查邮件处理、信息获取和其他数字员工独立场景页面无返回按钮；从工作台集成进入邮件中心时仍有返回集成入口。

- `TC-DE-NAV-11`（`AC-DE-NAV-10`）：检查运行计划、规则/模板弹窗、邮箱接口展示的表单控件尺寸、边框、字体、焦点态、主次按钮及窄屏布局；确认规则和模板仍能正常编辑保存。
- `TC-DE-MAIL-ACTION-01`：邮件任务执行关注、分派、领取、标签、开始、备注、暂挂、等待回复、恢复、完成、忽略和重新打开后，服务端持久化对应状态并写入时间线。
- `TC-DE-MAIL-ACTION-02`：操作接口返回新的邮件中心快照及数据库工作区版本；页面不发起第二次读取即可立即更新行状态、指标、关注选中态和可用操作。
- `TC-DE-MAIL-ACTION-03`：必填说明或关联业务单据缺失、版本冲突及非法状态迁移时，弹窗保持打开并显示错误；不得关闭弹窗或显示成功提示。

## 舆情监控数字员工验收

- `TC-DE-OPINION-01`：信息同时包含 `MAXHUB` 与至少一个投诉、质量、售后、安全、交付或合规风险词时才命中；命中排除词或缺少任一侧条件时不入库。
- `TC-DE-OPINION-02`：页面只提供“手工监测”，用户选择来源、时间范围、AI 摘要和预览后触发；系统没有计划频率、自动启用或后台调度入口。
- `TC-DE-OPINION-03`：GDELT、RSS/Atom、NewsAPI、通用 REST 与文件导入统一生成来源可追溯的原始信息；配置型 URL 必须使用 HTTPS 且不能指向本机或内网。
- `TC-DE-OPINION-04`：规则分析不依赖 AI；AI 摘要失败时保留规则结果并记录失败状态，整次运行继续处理其他数据。
- `TC-DE-OPINION-05`：重要和紧急事件生成内部任务，页面可分派、关注、备注、暂挂和完成；不得自动向外部平台发布或回复。
- `TC-DE-OPINION-06`：事件只能按状态机执行可用动作；关闭、无关和误报要求填写说明，终态可重新打开，非法跨状态动作由服务端拒绝。
- `TC-DE-OPINION-07`：工作区包含概览、舆情事件、原始信息、任务闭环、主题与词库、信息源、处置策略和运行记录；事件和原始信息支持 CSV 导出并统一分页。
- `TC-DE-OPINION-08`：首次进入初始化 1 个 MAXHUB 主题、20 条原始信息、8 个聚合事件、6 个任务和 5 次运行，刷新后不重复生成。
- `TC-DE-OPINION-09`：点击事件编码后摘要、命中词、来源和声量显示在独立详情区且不覆盖相邻列；事件标题/原始内容/来源列宽符合全局规范，来源与状态显示名称，声量显示“×条”；确认、开始、观察、关闭、无关、误报和重开图标彼此可区分。

## 大宗商品监控验收

- `TC-DE-MARKET-01`：财务分类的大宗商品监控包含接口设置、监控商品、获取列表、价格走势图四个 Tab；未配置有效来源时显示等待配置。
- `TC-DE-MARKET-02`：初始商品包含铜、铝、金、银；页面声明月度基准价和实际单位，不呈现日线覆盖或日/周价格。
- `TC-DE-MARKET-03`：历史回补最近 12 个可用月份；重复回补不重复插入；月度源中没有的月份不生成虚假价格，下载或解析失败显示运行错误。
- `TC-DE-MARKET-04`：首次回补后保存各商品及汇率各自的上次成功日期/时间；后续同步依据持久化进度续取。
- `TC-DE-MARKET-05`：部分商品成功时仅推进成功商品游标；失败或未持久化范围不推进；重试可补齐且不产生重复记录。
- `TC-DE-MARKET-06`：每条月行情可核对月份、美元月度基准价、USD/CNY 汇率及生效日期、人民币值、单位、来源和获取时间；缺汇率时不得误标成功或使用未标记汇率。
- `TC-DE-MARKET-07`：获取列表按行情日期倒序，支持商品、日期、币种筛选，并能区分最近运行时间和上次成功获取时间。
- `TC-DE-MARKET-08`：走势图只展示月度序列并支持美元/人民币；不通过复制月度值伪造日/周趋势。
- `TC-DE-MARKET-09`：无需外部 API Key；行情快照保留来源原始返回值和最近获取时间，重复获取幂等更新。
