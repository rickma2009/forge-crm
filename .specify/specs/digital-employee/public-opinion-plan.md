# MAXHUB 舆情监控数字员工实施方案

## 目标与验收

用户在舆情监控工作区点击“立即监测”，系统从所选授权来源获取数据，按 `MAXHUB AND 风险词组` 清洗匹配、幂等去重、解释性评分、可选 AI 摘要和事件聚合。重要/紧急事件生成闭环任务。页面即时展示运行阶段、事件、证据、任务和错误；不启用定时监控。

## 数据架构 Gate

| 表 | 层级与责任 | 关键不变量与生命周期 |
|---|---|---|
| `int_de_op_topic` | 集成配置；数字员工模块唯一写入 | 应用内主题编码唯一；品牌固定 MAXHUB；乐观锁 |
| `int_de_op_source` | 集成配置；数字员工模块唯一写入 | 应用内来源编码唯一；密钥 AES-GCM 加密且不回显；停用保留历史 |
| `int_de_op_run` | 集成运行状态 | 同主题仅一个活动运行；保存阶段、计数、错误和发起人；长期留痕 |
| `int_de_op_item` | 授权外部观察事实 | 来源+外部ID唯一；内容指纹辅助去重；默认180天保留；来源可追溯 |
| `int_de_op_event` | 由观察事实聚合的集成事件 | 应用内事件编码唯一；状态机、风险分0–100、乐观锁；不物理删除 |

全部记录带租户和应用作用域，服务查询显式限定作用域。外键限制跨表误删；来源、主题、运行、事件列表建立作用域索引。迁移采用前滚 SQL；失败恢复为保留旧应用版本并回滚新服务，新增表不影响既有业务表。密钥、完整请求头和外部正文不写审计日志。

## 状态与权限

事件状态：待研判 → 已确认 → 处理中 → 持续观察 → 已关闭；也可标记无关或误报，终态可重新打开。关闭、无关、误报必须填写说明。权限为查看、执行、管理；来源凭据只允许管理者修改。

## 连接与失败策略

适配器统一输出 externalId、title、summary、content、sourceName、sourceUrl、author、publishedAt、language、country。只允许无凭据 HTTPS 外部地址，拒绝本机与内网地址。单来源失败形成部分成功；失败运行可手工重试。AI失败时保留规则结果，不阻断采集。

## 可复用与专属边界

可复用：手工连接器执行、幂等采集、阶段运行记录、事件聚合、任务闭环、凭据保护。业务专属：MAXHUB词库、风险分类、评分权重和处置SLA，不能直接晋升为跨项目默认标准。
