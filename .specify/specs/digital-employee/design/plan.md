# 实现计划与数据边界

- `sys_de_workspace`：租户+应用唯一的数字员工编排配置快照，保存员工、场景、任务和规则；由 digital-employee 模块唯一写入。采用 JSON 是为了让场景配置版本整体一致，本切片不承担大规模任务分析查询。
- `int_de_connection`：一条外部系统连接一行，保存非敏感配置、连接状态和加密凭据；凭据使用服务端 AES-256-GCM 密钥，API 永不回显。
- `int_de_mail_automation`：每个邮件连接一份运行计划与安全配置，保存间隔、生效窗口、批量数、重试次数、发送限流、白名单、黑名单和回收站目录。
- `int_de_mail_rule` / `int_de_mail_template`：规则与回复模板分开版本化；规则只引用模板编码，保存时校验回复动作必须选择模板。
- `int_de_mail_message`：以“连接 + IMAP UID”唯一持久化邮件处理状态和结果，不保存邮件密码，也不在列表保存完整正文。
- `int_de_mail_action`：回复与移入回收站使用全局幂等键；待确认动作经人工批准后原地升级为待执行，不新建重复动作。
- `int_de_mail_run`：保存手动和计划运行的读取数、新增数、动作数、开始结束时间与错误，用于运行追踪。
- 删除策略：工作区不删除；连接软停用。邮件“删除”只移动至邮箱回收站，不执行永久删除。所有配置写操作通过乐观版本和审计日志。
- 恢复：数据库迁移可回滚新增表；连接凭据必须随加密密钥一起备份，密钥丢失只能重新配置。
- 外部调用采用适配器边界；无适配器或配置不完整时失败关闭为等待配置。
- `imap-mail.adapter.ts` 按 UID 增量拉取配置批量数；普通同步不改变邮件标记，只有已批准或已满足延迟规则的删除动作才以写模式移动邮件。凭据只在调用时解密，不写日志。
- 邮件任务以 `mail:<connection>:<uid>` 作为去重证据，规则分类会在后续同步时重算已导入任务，不重复建待办。
- `smtp-mail.adapter.ts` 只接收动作队列已批准的负载；自动回复同时要求总开关、域名白名单、地址黑名单、no-reply 规则和速率限制全部通过。
- 进程内调度器每 30 秒领取一个到期计划和一个到期动作，数据库条件更新与 `FOR UPDATE SKIP LOCKED` 防止多实例重复领取；失败按计划中的次数退避重试。

## 大宗商品监控架构决策（2026-10-08）

用户已要求实施。本切片由 digital-employee 集成模块独占管理外部行情快照，不作为 CRM 产品报价或交易所权威行情服务；外部来源授权由组织侧核验，不影响本地适配器开发。

| 项目 | 候选决策 / 待定事项 |
|---|---|
| 数据层级与责任 | 外部行情及汇率副本由 `digital-employee` 业务模块唯一写入，数据层为 `int_` 集成；不是共享主数据，不供其他领域绕过 API 直读/写。若后续多个业务域需要行情，再另立共享数据责任决策。 |
| 持久化实体 | `int_de_market_config` 来源与调度；`int_de_market_item` 商品映射；`int_de_market_price` 双币种月行情快照（OHLC 不适用字段为空）；`int_de_market_fx` USD/CNY 日汇率；`int_de_market_cursor` 每商品及 FX 进度；`int_de_market_run` 运行记录。已加入数据库表注册。 |
| 作用域/唯一键 | 各表携带 `tenant_id`、`application_id`。商品映射按应用+商品编码唯一；行情按应用+商品+来源+市场日期唯一；汇率按应用+来源+币种对+生效日期唯一；同步游标按应用+游标编码唯一。价格到商品与汇率快照的复合外键约束同租户/应用。 |
| 进度与原子性 | 月度商品游标编码为 `WORLD_BANK_<item_code>`，汇率游标为 `FX`，独立记录 `cursor_date` 和 `last_success_at`。每商品月份成功持久化后在同一事务推进游标和商品上次成功信息；失败保留旧游标。重取最近月份容忍来源修订，唯一键 upsert 幂等。 |
| 来源修订 | 按同一来源/商品/市场日期幂等 upsert，保留当前行情原始返回行、最近获取时间和汇率快照引用；不提供逐版本审计，旧值被来源更正时由新快照替换。 |
| 状态/保留 | Config 使用 `enabled`、`is_running` 和错误/最近运行状态；Run 使用 RUNNING/SUCCEEDED/PARTIAL/FAILED。停用商品不删除快照；外键限制删除商品/汇率被引用的数据。配置停用不删除历史。 |
| 查询/索引 | 获取列表按应用过滤后按市场日期倒序；趋势按应用、商品、市场日期读取。已登记列表、日行情、FX 日期和运行记录索引。 |
| 来源与安全 | 无外部 Key。商品源目录固定为 `www.worldbank.org/en/research/commodity-markets`，下载链接必须为 HTTPS `thedocs.worldbank.org`；汇率仅请求 `api.frankfurter.dev`，阻断任意 URL 请求，旧凭据字段清空。 |
| 回补/恢复 | 首次从最新可用月份向前 11 个月；后续从各商品月份游标回退一月，并重新获取近 12 个月 USD/CNY 日汇率。恢复后可以重跑并幂等 upsert；迁移回滚只允许在确认无保留数据后移除新表。 |
| Gate 验证 | 模型、作用域键、索引、迁移和恢复已落在 Prisma/SQL；待通过 PostgreSQL migration/集成验证和端到端页面检查。组织仍需核验供应商生产数据许可、配额与成本；这项限制不影响开发态及用户配置后的技术连通性。 |

具体业务交互和增量规则见 [`commodity-monitoring-solution.md`](../commodity-monitoring-solution.md)。
