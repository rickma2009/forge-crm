# P1规格

BUS-WFP-01：验证配置、发起、待办、审批和动作恢复的连贯交互。

|需求|验收|
|---|---|
|REQ-WFP-01 流程列表、可编辑配置、条件阈值/人员规则、模拟、版本发布|AC-WFP-01 保存发布影响新申请，已有实例保留版本；无效配置阻止发布|
|REQ-WFP-02 发起报销/请假/报价/订单/付款/事件，角色待办、通知、流程图及历史|AC-WFP-02 8万/12万分支、HR、并行与当前节点来自相同模拟模型|
|REQ-WFP-03 同意、退回重提、拒绝、转交、抄送及事件动作失败/重试|AC-WFP-03 已处理不能再操作，原责任人转交后不可操作，重提保留历史，重试只成功执行一次|
|REQ-WFP-04 复用现有详情/页签/查询/视图/网格，分页及本地个人视图|AC-WFP-04 查询重置、分页、视图设置恢复；键盘可操作，无虚假按钮|
|NFR-WFP-01 独立目录、端口及mock，清晰标注模拟并支持重置|AC-WFP-05 无真实API请求；构建和浏览器路径通过，生产模块未改动|

模拟个人视图按角色和列表对象保存在localStorage，默认20条，支持列显示与页大小。纯明细表不提供个人视图。不同角色以演示切换器切换，审批设置仅管理员展示。图节点支持点击与键盘焦点，当前并行节点同时展示。离开未保存配置/申请时确认。
