# 首批阶段交付与复查

日期：2026-10-09。范围：邮件结果详情、商机文字会议多行动、私有 FAQ/SOP 与邮件知识辅助草稿。未扩大到采购、QMS、BI、企业共享知识库或自动 AI 发信。

## 结果与入口

1. 邮件数字员工 → 邮件任务：点击任务标题可看处理结论、备注、负责人、恢复时间、关联业务、SMTP/IMAP动作状态与尝试记录；不同连接的任务不混入。
2. 个人 Agent → 选择商机会话 → 处理方式“商机会议行动”：粘贴文字纪要，生成五类分组与多行动草稿；逐条编辑/确认，执行后填写结果。工作台Agent待办同步要求结果；旧客户端保持兼容。
3. 个人 Agent → 我的知识资料：核查后保存私有 FAQ/SOP；修改新增版本，可设置有效期/停用。会话选择最多5份资料，点击引用查看原版本；失权、停用、过期被拦截。
4. 邮件数字员工 → 知识辅助草稿：选择资料并粘贴必要邮件信息，生成未发送草稿；人工核实后复制到原回复模板入口，仍受原发送策略。生成时引用保留在会话，手工复制后的模板不自动绑定知识版本。

## 三个复查视角

- 需求：首批切片有规格、追溯和测试；未确认草稿不落正式任务，不改商机状态，不建立假售后单。真实基线和条件场景不勾选完成。
- 安全：检查租户/应用/当前账号/业务作用域、分派对象权限、CSRF、工具白名单、源引用、知识停用/过期、邮件连接隔离和无payload的动作摘要。修复工作台按业务对象缓存权限的缺口；再用回归验证。
- 集成：新增兼容 SQL 单独在临时数据库验证，并已部署本地唯一待应用迁移；旧Agent/会话/商机生命周期回归正常。旧取消任务测试用临时持久HTTP监听解决测试socket挂断，不修改业务取消逻辑。

## 实际验证

- 服务端5套针对性单测：17条通过（知识协议、权限缓存、邮件策略、任务状态、模型协议）。
- 工作台3条单测通过。
- 隔离数据库3套集成：10条通过（含旧兼容、多行动幂等、执行结果、私有版本、知识草稿、未知工具拒绝）。
- 前端3套组件测试：5条通过；最终布局调整后的Agent交互2条再验证。
- SQL迁移测试通过：旧任务索引0、不同索引共存、重复/越界拒绝、知识版本唯一及同租户外键；临时数据库自动清理。
- contracts构建、服务端及前端类型检查通过；变更相关git diff --check通过。
- 本地前端HTTP 200；服务端 /api/health/ready 返回数据库与迁移 ready。
- 未运行全量无关测试、真实模型、真实邮件发送/删除或企业业务试点。自动组件验证不等同于真人视觉验收；浏览器连接未提供现成登录会话，因此未宣称已做登录后浏览器端到端验收。

## 可复用与限制

候选复用：多行动消息+索引幂等、不变知识版本、业务对象级权限缓存测试、外部动作成功与业务完成分离。由现有个人待办、会话、DetailTabs/DataGrid/弹窗承载，不建立通用Agent平台。跨项目适用性未验证，暂不晋升公共模板。

私有知识由当前账号负责，不构成公司审核制度。没有真实企业样例，不报告提效率/准确率/单任务成本。采购接口、质量证据、指标口径/业务责任人就绪后，再选择一个有限切片；本阶段完成后停止扩展。
