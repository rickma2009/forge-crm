# 首批场景规格

状态：近期三个代码切片完成，业务试点待验收；L3。

## 业务及需求

BUS-AE-01：把当前邮件与 CRM 助手建议转为来源可追踪、人工可确认、结果可核验的行动，不让模型自行修改正式单据。

- REQ-AE-01：邮件任务详情展示完成结论、处理备注、负责人、恢复时点、关联对象和邮件执行状态。SMTP 接受与业务完成分开；只包含选定邮箱来源任务。
- REQ-AE-02：商机会议模式按事实记录、诉求、问题、推断、缺失信息分组；最多12个行动草稿，编辑后逐条确认，按消息+草稿索引幂等保存；显示执行状态及结果。旧单草稿默认索引0，旧会话兼容。
- REQ-AE-03：当前账号 FAQ/SOP 文本资料管理、人工核查、不可变版本、启停与有效期；显式选择最多5份授权资料。Agent 和邮件辅助草稿展示可点击引用；停用、过期及他人资料不得引用；历史引用标明版本更新。
- REQ-AE-07：本切片复用现有责任/接管、模型限额、审计、邮件运行与动作日志，不制造企业可运行或净提效结论。企业准备度和成本度量待实际样例，不属于已完成范围。
- NFR-AE-01：每次取数、保存及引用复核租户/应用/账号和业务权限；被分派人须能访问对应业务对象；工作台权限缓存按关联对象区分。外部/模型内容不授予工具权限。
- NFR-AE-02：兼容迁移保留旧任务；知识同租户外键及版本唯一，任务索引范围0..11。停用功能可保留数据回退，不执行破坏性降级。

## 验收标准

- AC-AE-01：完成/等待/重开如实显示，结果详情可核查；另一个邮箱的同场景任务不能混入。
- AC-AE-02：两个行动只确认一个时另一个保持草稿；重复确认不重复落库；旧单草稿、归档和会话删除后待办保持兼容。完成结果和版本冲突正确处理。
- AC-AE-03：知识保存需人工核查，编辑新增版本；历史文本不变并提示新版；停用/过期/外国账号均拒绝访问引用。
- AC-AE-04：EMAIL_DRAFT 只生成未发送草稿，无任务或邮件执行副作用；模型请求sendMail等未授权工具失败。无法确定的内容不通过工具猜造。
- AC-AE-05：合法迁移将旧索引补为0，允许同消息不同索引，拒绝重复索引、越界及跨租户知识关联；业务失权不进入工作台统计。

## 契约与入口

个人 Agent messages 新增 mode（CHAT/MEETING/EMAIL_DRAFT）与 knowledgeIds，兼容缺省 CHAT。回复保留 todoDraft/todoSaved，同时增加 todoDrafts/savedActions。确认待办新增 draftIndex，缺省0；任务状态接口可提供 result/version。GET knowledge、GET knowledge/:id、POST knowledge 为私有资料接口。

邮件 center 新增动作结果摘要 actions，默认空数组，不输出执行 payload。邮件页“知识辅助草稿”复用个人 Agent 页面；没有 Agent 权限的账号仍由服务端拒绝访问。

数据设计及恢复见 implementation-design.md。采购、质量、BI按下方本轮覆盖及business-scenes-design.md实施演示切片。
