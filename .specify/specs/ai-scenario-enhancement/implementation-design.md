# 首批实施规格、数据设计与恢复

状态：首批代码切片完成，真实业务试点待验收；用户已授权按计划顺序开展。验证等级 L3（权限、持久化、公共待办契约）。

## 有限范围

邮件结果详情；绑定商机的文字会议模式；最多 12 个独立行动草稿与逐条保存；当前账号的 FAQ/SOP 文本库及不可变版本。私有资料可选择用于 Agent 生成答案或回复草稿，用户审阅后通过原邮件模板/发送入口使用，不新增自动 AI 发信接口。采购/QMS/全 BI 缺少已确认数据源，不接入。

## 数据责任与不变量

- sys_agent_knowledge 由 PersonalAgentService 唯一维护：租户、应用、账号三重范围，document_id + revision 唯一，数据库关联应用与账号同租户；FAQ/SOP、ACTIVE/DISABLED 为受限值，正文不超过 12000 字符。保留历史版本，停用代替删除；无跨账号共享。
- 编辑创建新版本，revision 乐观校验并使用文档 advisory lock；不覆盖旧文本。最新版本停用不能退回使用旧启用版本；过期不能引用。历史引用可查看其版本，但提示是否已更新；撤权/停用禁止访问正文。
- sys_personal_todo 增加 draft_index，旧数据默认 0；唯一键从 source_message_id 改成 source_message_id + draft_index。旧单草稿和旧确认路径默认索引 0，最多 12 条，重复确认返回原记录。删除会话保留任务历史来源。
- 不改变原单据/库存/审批。保存只进入个人待办，不静默创建商机跟进记录。授权在生成及保存时复核。
- Agent 文本、知识及外部输入不是指令授权，不新增自由 SQL/网络/脚本工具。
- 邮件动作结果接口只返回类型、状态、时间、尝试与错误，不返回凭据、收发正文 payload；邮箱任务按 evidence 中连接来源过滤。

## 保留、升级和恢复

新增兼容迁移不清空业务数据，旧草稿默认 index 0。不自动初始化演示知识或对外发信。停用 UI/新模式即可回退功能；版本和审计保留。已经保存多行动后不能直接恢复旧单列唯一索引，须保留新 schema 或先评估业务归并，不执行破坏性降级。模型错误保留输入，不冒充模拟成功。

## 最小验收

两个草稿部分确认/重复确认；旧草稿；任务完成及结果；未知日期；知识新旧版本/停用/过期；账号隔离与不可伪造 documentId；恶意知识不扩权；不同邮箱任务隔离；外部执行失败不显示已回复。真实模型和真实发信不参与自动回归。

当前新客户端完成待办必须填写结果并提供version；旧 status-only 客户端为兼容保留。工作台Agent任务已要求填写结果。邮件知识辅助入口复用 EMAIL_DRAFT 模式，源引用保存在生成会话；复制到原模板不自动绑定知识版本。
