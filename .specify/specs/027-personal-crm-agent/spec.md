# 个人 CRM Web Agent 首版规格与实现

需求来源：`REQSRC-083`（范围及推荐决策）、`REQSRC-084`（开发授权）。详细业务边界见 `docs/ai/personal-crm-agent-plan.md`。

## 验收行为

- 授权账号在独立 Agent 工作台建立通用或客户、商机上下文会话；可搜索、改名、归档、恢复和删除本人会话。
- 服务端按登录账号、应用和租户作用域过滤会话及消息；业务资料逐次检查客户/商机读取权限，回答仅接受已授权来源 ID。
- 模型失败保留用户输入和失败消息；相同 requestId 幂等；消息顺序稳定。
- Agent 只产出待办草稿，确认后生成一条正式待办；可指定负责人和日期，工作台显示本人未完成待办。
- 客户与商机详情可带对象 ID 打开工作台，商机原 Agent 小助手继续可用。

## 数据及服务边界

迁移新增 `sys_agent_conversation`、`sys_agent_message`、`sys_personal_todo`，应用/租户/账号外键及索引见迁移文件。会话删除级联消息，正式待办保留来源消息 ID 的历史值。个人 Agent 服务提供会话、检索、消息与待办接口；我的工作台读取正式待办。前端新页面复用现有认证、菜单权限与顶部 Tab 容器。

## 验证

隔离数据库测试 `scripts/test-agent-integration.mjs` 覆盖会话顺序、账号隔离、草稿确认、幂等、归档/删除和失败恢复，并回归原商机 Agent。前端测试覆盖工作台和主路由。
