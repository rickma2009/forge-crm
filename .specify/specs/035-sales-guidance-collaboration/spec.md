# 规格

- REQ-SGC-01 / AC-SGC-01：P4客户/商机可解释R01—R03建议；客户仅R01且标明当前可见记录。按应用上海自然日判断，有效活动排除备注、评论、系统事件和待办。关闭/停用商机不产生新建议。
- REQ-SGC-02 / AC-SGC-02：建议具有有效/采纳/忽略/稍后/失效状态，7天忽略冷却、定时恢复；条件消失失效。每用户、对象、规则、周期隔离，操作重验条件与版本。采纳同事务创建本人待办及只读事件，幂等；完成需结果，可取消，不自动创建跟进。
- REQ-SGC-03 / AC-SGC-03：P5客户/商机评论与一级回复，纯文本4000字，作者修订撤回留版本，管理隐藏独立授权。根评论撤回保留回复结构。分页稳定，附件草稿先上传后发送，失败重试，过期草稿清理。
- REQ-SGC-04 / AC-SGC-04：提及仅允许同租户应用且有对象/评论读取权限的启用用户，发送重验。评论、提及、outbox同事务；通知幂等投递，编辑仅新增提及通知。本人未读/已读与全部已读，撤权隐藏内容，前台30秒轮询，后台暂停。
- REQ-SGC-05 / AC-SGC-05：P6商机跟进优先级0—100，信息30/来源20/有效活跃20/金额30可解释；缺失与未配置明确说明，金额用币别阈值且定点比较。不是成交概率，关闭后保留历史不新算。
- REQ-SGC-06 / AC-SGC-06：规则草稿/发布/停用，发布内容不可改，单应用一个生效版本；结构化参数不运行脚本。系统评分保留版本、输入hash、计算日期/时间和分项；对象/活动变化定期受控重算，读时校准，应用日切衰减。失败标记待更新并保留上次值。
- REQ-SGC-07 / AC-SGC-07：独立人工覆盖权限、理由、默认30天有效期，系统分继续计算，恢复/到期自动回退留事件，并发版本与幂等保护。
- REQ-SGC-08 / AC-SGC-08：所有接口、附件、通知、提及、分析受源对象与操作权限控制。只给内置系统管理员初始化新增权限，其他角色由管理员配置。沿用公共详情/Tab/附件；新建议、评论、分项组件记录复用边界。
