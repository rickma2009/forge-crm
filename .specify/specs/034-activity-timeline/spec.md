# P3 活动时间轴

来源REQSRC-095，承接已批准REQ-SX-03；本包完成停止，不实施建议、评分和协作。

- REQ-TL-01 / AC-TL-01：客户/商机详情统一时间轴，按发生时间倒序、稳定来源键去重、类型筛选、签名游标及快照上限；同一跟进在两个对象显示同一sourceType/sourceId。
- REQ-TL-02 / AC-TL-02：新增拜访、电话、人工邮件登记、备注和跟进；发生时间不能在未来，执行人为当前用户；客户/商机关联由服务端验证。商机跟进调用既有OpportunityService，不复制活动表；客户跟进存新销售活动。未来计划仍使用已有待办，本包不另建计划事实。
- REQ-TL-03 / AC-TL-03：作者在仍有对象写权限时修改/作废，版本保护、保留修订审计、不硬删；系统事件只读。未新增管理员越权修改入口，管理他人活动需后续独立管理授权。
- REQ-TL-04 / AC-TL-04：适配既有商机阶段、金额事件；从本包开始商机业务状态/启停变更同事务留痕。无真实历史事件不补造。单据自身事务仍在原单据模块查看，不在本包扩展财务单据事件聚合。
- REQ-TL-05 / AC-TL-05：每次读取、修改、附件下载重新检查来源权限；客户沿用菜单及数据策略，商机沿用菜单/应用作用域。客户时间轴无商机view时不显示关联商机事件或活动。
- REQ-TL-06 / AC-TL-06：活动保存后复用附件服务上传/下载，最多10个20MB；只允许来源作者在有效状态操作附件；失败可重试，不在保存前创建孤立文件。
