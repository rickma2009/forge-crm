# Feature Specification: 数据库驱动的数据字典

| 项目 | 内容 |
|---|---|
| Feature ID | `006-database-backed-data-dictionary` |
| 上游功能 | `FR-504` |
| 增量来源 | `REQSRC-026`、`REQSRC-027` |
| 状态 | `approved-under-REQSRC-023-standing-authorization` |

## 功能需求

- `REQ-601`：系统使用 `sys_dictionary` 与 `sys_dictionary_item` 两张业务表分别保存数据字典和字典值。
- `REQ-602`：人工设置、业务可见的数据字典 ID 在同一系统内唯一；内部关联主键不作为页面 ID。
- `REQ-603`：字典允许同系统父级关系，页面以可搜索树展示；收起父级时隐藏全部后代，后代不得被提升为一级；循环或跨系统父级无效。
- `REQ-604`：字典详情显示数据字典 ID、父级、显示序号、描述、当前状态和固定/可维护模式。
- `REQ-605`：字典类别通过初始化维护，页面不提供类别新增、编辑或删除。
- `REQ-606`：可维护且启用的字典支持新增、编辑和启停字典值；是否存在下级不构成限制，字段为值、值描述、当前状态和显示序号。
- `REQ-607`：页面支持 Excel 模板下载、`.xlsx/.xls` 读取、有效行预览、批量导入，以及将当前选中字典的全部值导出为 `.xlsx`。
- `REQ-608`：固定字典、停用字典或无管理权限角色不能写入字典值。
- `REQ-609`：停用值不进入新业务录入选项，但历史值仍可解析；不提供物理删除。
- `REQ-610`：客户类别、状态、行业和等级继续从本地字典读取，不因层级改造改变既有存储值。
- `REQ-611`：左侧树只显示字典描述、状态和层级，不显示数据字典 ID；详情区域继续显示 ID。

## 非功能需求

- `NFR-601`：批量导入最多 1000 行，服务端最终校验；任一行错误时事务内零写入并返回可定位行号。
- `NFR-602`：所有管理写请求继续执行会话、同源 CSRF、角色操作授权、系统隔离和乐观版本控制。
- `NFR-603`：参考系统只提供证据，目标实现不得依赖其外部字典平台、缓存、同步、SQL 导出或组织专属根节点。

## 验收标准

- `AC-504`：admin 可维护本地字典值；viewer 写接口返回 403；停用项不供新录入但历史数据仍可读。
- `AC-508`：客户类别、状态、行业和等级全部来自数据库字典。
- `AC-601`：左侧按父级展示可搜索字典树且不显示 ID；收起父级后所有后代隐藏，右侧展示完整只读字典元数据。
- `AC-602`：页面不存在字典类别新增、编辑、删除和手工改 ID 操作。
- `AC-603`：可维护字典支持弹窗新增/编辑值，字段与 `REQ-606` 一致。
- `AC-604`：Excel 导入支持约定列名、预览与整批提交；错误返回行号且零写入。
- `AC-605`：固定值字典、停用字典和 viewer 均不能写入，服务端独立拒绝绕过 UI 的请求。
- `AC-606`：初始化客户字典、“物料类别→大类→中类→小类”层级和固定“是否”字典，客户页面保持兼容。
- `AC-607`：物料类别及其每一级启用、可维护字典都能新增、编辑、导入字典值，不因存在下级而受限。
- `AC-608`：当前选中字典可导出与导入模板同列结构的 Excel；导出读取已加载的数据库结果，不产生服务端写入。
