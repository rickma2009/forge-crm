# 规格

BUS-WFD-01 管理员能从列表创建、设计、发布和维护绑定业务对象的审批工作流。

REQ-WFD-01 列表查询工作流名称、编码、数据对象和状态，显示编码、名称、数据对象、最新版本、状态、创建人和创建时间。
REQ-WFD-02 新增时必须选择对象目录中的对象；对象保存后不可更换；新草稿包含开始和结束节点。
REQ-WFD-03 草稿支持增加审批节点、排他分支和业务动作，修改名称/审批职责、连接和条件，删除非系统节点。
REQ-WFD-04 条件字段、类型、运算符和值必须匹配对象字段目录；每个排他分支有唯一默认出线，其他出线有条件和稳定顺序。
REQ-WFD-05 发布前校验可达性、结束路径、节点配置、审批职责、业务动作、条件和默认分支；发布版本不可变。
REQ-WFD-06 草稿可删除；有实例或已发布版本不可物理删除。编辑已发布版本创建同工作流的新草稿版本。
NFR-WFD-01 所有操作受租户/应用、菜单动作、CSRF和并发版本控制；引擎只接收服务端编译的安全模型。

AC-WFD-01 列表、新增和详情入口符合系统列表/详情规范。
AC-WFD-02 对象目录阻止未知字段和类型不匹配条件。
AC-WFD-03 节点增改删及分支设计可保存和重新打开。
AC-WFD-04 非法图不能发布，合法图发布后真实销售订单按该图运行。
AC-WFD-05 发布版本不可变，编辑生成新草稿且历史实例不变。
AC-WFD-06 删除、越权、跨作用域和并发冲突失败关闭。
