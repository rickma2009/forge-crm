# 技术计划

工作流配置属于 `sys_` 平台配置域，由 workflow 模块唯一写入。沿用 `sys_wf_config` 作为不可变版本实体，增加工作流编码、名称、对象编码、更新时间和并发版本；同一应用/工作流编码/修订唯一，同一对象仅一个启用发布版本。申请继续通过 config_id 绑定发布快照，删除使用 RESTRICT 和服务校验。

对象目录由服务端注册，首个 `sales_order` 暴露主表稳定字段、类型、运算符和允许的业务动作。设计 JSON 保存节点、边、结构化条件及人员规则；核心身份、状态、版本、对象编码继续为关系列。服务端在保存和发布时校验图与字段目录，编译器只把白名单 AST 转成表达式。

API 提供对象目录、分页列表、新增、详情、草稿更新、从已发布版本派生草稿、删除和发布。写请求需要 workflow-settings manage 和 CSRF；乐观版本冲突返回409。

迁移前滚，不改写20261005170000。现有销售配置若存在，回填为 `sales_order` 工作流版本；未发布主库不生成虚假负责人。回滚方式为停用新版本并保留所有已发布版本和实例，不删除历史。

前端入口先显示标准列表和分页；新增使用弹窗；详情使用 DetailWorkspace，设计图与属性面板共用已发布运行图组件。第一期以表单式节点/边编辑保证业务正确性，不承诺自由拖拽 BPMN 画布。
