## 架构与复用视角

- 依赖方向为 foundation → primitives → components → template → scenarios；边界检查阻止销售订单/BOM 领域词和反向 import 进入核心。
- 表单、行表与单据状态由受控 props、纯规则/reducer 管理；保存通过带 token 的注入式 Adapter，避免重复和过期结果覆盖。
- 可跨项目复用：字段 schema/显隐规则、校验摘要目标协议、行身份与撤销 revision、整数金额、异步结果联合类型、离开保护状态机、Adapter seam、验收清单。
- 不可直接复用：销售订单字段/价税口径、BOM 层级与差异业务、演示数据、3 层/6 行预算、Preview Gateway、Showcase 路由/权限、当前 CSS 外观。
- 旧 `SalesOrderPrototype.tsx` 仅是迁移回滚资产；Registry 已回指当前 `SalesOrderScenario` 与共享模板。

结论：架构与复用边界满足评审条件；候选资产仍留在验证场，不创建独立组件包。
