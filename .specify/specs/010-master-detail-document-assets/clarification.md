# 澄清记录

## 已确认

- 使用双层资产体系：门户面向人，方法论资产面向 AI/工程。
- 使用纵向资产切片，不先铺满全部基础组件。
- 首切片为主从单据、SchemaForm、可编辑行表和状态矩阵。
- 第一场景为销售订单，第二场景为 BOM 适配复核。
- 参考项目只做差量萃取；具体库、业务字段和组织约束不成为通用默认。
- AGENTS 只做短路由；详细 UI 规则进入方法论专题资产。
- 实现前沿用并重新批准现有 TypeScript 企业 Web 路线。

## Specification 默认建议

- Demo 数据确定性且只保留当前浏览器会话。
- 保存、提交、审批等反馈均为场景模拟，不冒充服务端业务状态。
- “只读”允许查看和复制；“禁用”必须提供原因。
- 保存失败保留用户输入；校验失败能定位字段或行。
- 移动端仅支持查看和轻量动作，不承诺复杂批量录入。

## 留给 Architecture Gate

- schema 解释器的数据结构与扩展注册方式；
- 行表状态与表单状态的所有权；
- 场景 Adapter 和企业组件的依赖方向；
- Registry 到两个门户视图的投影机制；
- 是否把运行时 schema 放入 contracts 包。
