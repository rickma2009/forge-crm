REQSRC-052 确认推荐迁移范围：完整工作区及七页签；补齐源未接线按钮；保留 sys_、现有成员/权限历史；不照搬专属规则；限制普通管理员提权。

## 详细规则建议，随本次 Spec 一并评审

| 决策 | 推荐规则 | 原因及影响 |
|---|---|---|
| Q-1501 角色树 | 仅整理，无权限继承 | 显式变更012 REQ-1216的无层级约束；不把父角色当自动授予 |
| Q-1502 编码 | 创建后只读 | 保留012批准规则；与源可编辑表单有意不同，防权限标识漂移 |
| Q-1503 组织授权 | 动态本节点，包含后代显式选择 | 组织调整后不遗留复制出来的个人授权 |
| Q-1504 群组授权 | 当前直接有效成员，不含嵌套组 | 减少循环和隐式扩权；群组事实源必须真实存在，不伪造 |
| Q-1505 新数据规则 | 功能门槛不变，允许并集，匹配拒绝优先 | 原功能并集保持；新数据层只对明确纳管资源生效 |
| Q-1506 管理员 | 保留显式权限保护，不新增普通表单超管开关 | 用户已确认限制提权；不以isSystem等同绕过 |
| Q-1507 源未完成项 | 按目标需求补完整链路，不复制空按钮 | 本次显式确认优先；不将新设计误写为源已有功能 |
| Q-1508 旧管辖范围 | 只读兼容与受控清理，不再新增 | 避免与新策略双重含义 |
| Q-1509 范围与职责 | 不增加仪表盘编辑器或供服业务模块 | 仅登记必要可授权资源并接入真实消费端 |
| Q-1510 原有数据 | 保留ID、编码、关系与历史，不重置现有权限 | 未纳管资源兼容；纳管切换需后续架构与恢复评审 |

## 依赖与未知

新增直接源码证据：`packages/scs-web/src/pages/settings/roles/tabs/UnifiedDataPolicyTab.tsx:1105` 提示空策略数据默认全部可见。这与 Q-1505 建议的“新纳管资源无允许规则默认拒绝”不同，必须作为本轮 Specification 的显式目标安全适配批准，不能声称原样复制。该文件还包含资源目录、字段目录、字典/选项服务翻译、脱敏、高级排除及全量允许入口，已补入需求；仅按字符串检索不能证明全部分支或消费端已验证。

已有候选模式 `_methodology/patterns/record-management-workspace.md` 可复用加载/空态/权限及失败反馈原则，但其列表—详情导航不替代本次明确要求的树与详情布局；本轮不改模式、不晋升资产。

- 013提供组织事实，014提供资源/操作目录；不能复制一套影子目录。
