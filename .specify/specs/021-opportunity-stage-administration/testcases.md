|---|---|---|
| `TC-2101` | `AC-2101` | 页面与 API 权限一致 |

| `TC-2103` | `AC-2103` | 当前模板新增成功，重复编码/非法赢率失败，失败不改变原默认阶段 |
| `TC-2104` | `AC-2104` | 取消无写入；无引用非默认阶段可删除；当前商机和历史分析引用分别拦截 |

# 增量验收：单表商机阶段管理

- 页面不得出现模板树、收起树或展开树控件。
- 表格查询头显示“商机模板”下拉框，默认选择“公共”，并可切换“招投标项目”。
- 新增、修改、删除阶段始终作用于当前下拉框选中的模板。
