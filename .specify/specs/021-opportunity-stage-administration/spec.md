# 规格：商机阶段配置

- `BUS-022`：允许管理员按模板调整销售阶段流程。
- `REQ-2101`：页面查询模板并维护阶段名称、编码、赢率、默认、排序和状态。
- `REQ-2102`：唯一默认阶段、编码不可改、引用后禁止物理删除。
- `AC-2101`：管理员可维护，viewer 只读。
- `AC-2102`：默认阶段和 0—100 赢率由服务端/数据库约束。

## 新增与删除增量（用户已确认）

来源：`.specify/sources/opportunity-stage-crud-increment/source.md`。

- `REQ-2103` / `AC-2103`：在当前模板下弹窗新增阶段，录入编码、名称、整数赢率（0—100）、默认、排序与状态；同模板编码唯一，编码建立后不可修改。
- `REQ-2104` / `AC-2104`：列表提供删除确认；仅无商机及历史分析引用的非默认阶段允许删除。取消不写数据；默认阶段先设置替代项；已引用阶段保留，允许停用。
- `AC-2105`：服务端校验维护权限、应用/租户作用域和并发版本，变更与审计原子提交。新增/修改/删除均返回提交后的模板列表，刷新页面仍可见结果。
