# P2 商机看板

来源：REQSRC-094，承接已批准方案 REQ-SX-02。本包完成即停止。

- REQ-KB-01 / AC-KB-01：表格/看板切换，单模板、稳定阶段顺序；默认启用且初始/跟进中的商机，历史关闭记录只读。实际业务枚举为 VOID/SIGNED/LOST（方案的 CLOSED 对应 VOID）。
- REQ-KB-02 / AC-KB-02：每列全量匹配数量、精确金额和缺失金额数量；币种未定义，明确提示不作币种换算；每列20条按ID稳定加载。
- REQ-KB-03 / AC-KB-03：拖动或键盘操作后确认阶段及必填理由；同模板启用阶段；关闭/停用商机或历史停用阶段不可移动；409不乐观移动，刷新后重试。
- REQ-KB-04 / AC-KB-04：阶段更新和不可变事件同事务，版本保护、请求去重，重复请求不同内容拒绝；详情编辑和分析调用同一校验/事件方法，分析保留原内容。
- REQ-KB-05 / AC-KB-05：个人视图保存模式、模板、卡片字段；旧视图默认表格；不扩大系统字段范围，模板失效回退表格提示。

权限：沿用现有 opportunity-directory.view；看板移动沿用 update，与详情编辑同权限；分析原 analyze 权限不扩大。P2不引入默认自动授权的新按钮资源。行可见性保持现有应用作用域，不声称已有商机行级策略。
