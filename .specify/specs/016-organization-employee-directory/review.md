# Review：016 组织与员工目录

> 结论：`verified-awaiting-release-gate`

## 本次确认

- 组织页面错误来自服务端直接展开 Prisma 行，已改为显式公开 DTO。
- 组织采用左树右基本信息；员工采用标准查询列表和新增/编辑弹窗。
- 员工、雇佣周期、岗位、任职与系统账号职责分离，主职部门和岗位为强制业务不变量。
- 所有初始化员工都是系统用户；除 admin 外，初始化员工只获得受限 viewer 角色。

## 可跨项目复用

- 员工主体与账号分离、账号可选绑定员工，适用于允许非员工账号或员工尚未开通账号的企业系统。
- 组织树只承担稳定归属；岗位与任职独立保存，适用于需要保留调岗历史的系统。
- 列表脱敏、详情按管理权限返回完整值，适用于含个人联系方式的系统管理页面。
- 左树右详情适用于组织、资源等层级主数据；员工等批量对象使用列表，不机械套用树形交互。

## 不可直接复用

- “部件BG”及各事业部/部门、示例岗位、姓名、工号和账号均为本次演示数据。
- viewer 默认角色、密码策略和具体权限码需要由目标项目安全策略确认。
- 本切片只实现主职，不代表已经覆盖兼岗、矩阵组织、跨法人、多合同和复杂复聘业务。
