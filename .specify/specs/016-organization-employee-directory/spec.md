# 规格：组织与员工目录

## 目标

- `BUS-021`：建立组织—岗位—员工—账号一致的公共主数据闭环。
- `US-1601`：管理员通过组织树查看和维护组织基本信息。
- `US-1602`：管理员查询、新增和编辑员工，员工必须有主职部门、岗位和可登录账号。

## 需求

- `REQ-1601`：组织 API 只返回公开契约字段，不泄露租户和审计内部字段。
- `REQ-1602`：组织页面左树右详情，父级收起时后代隐藏，右侧只显示基本信息。
- `REQ-1603`：员工列表支持关键词、部门、状态查询；新增/编辑使用弹窗。
- `REQ-1604`：员工字段包括工号、姓名、账号、部门、岗位、用工类型、联系方式、状态、生效时间和备注。
- `REQ-1605`：所属部门、岗位、姓名、账号必填；工号由EMPLOYEE规则自动生成且不可修改，工号和账号租户内唯一。
- `REQ-1606`：员工主体、雇佣、岗位、任职和账号分别持久化；账号通过 `employee_id` 可选一对一绑定。
- `REQ-1607`：新增员工同时获得受限演示角色；服务端对列表和维护操作分别鉴权。
- `REQ-1608`：列表联系方式脱敏，写操作记录结构化审计并使用版本冲突检查。
- `REQ-1609`：Seed 初始化批准组织树、岗位及各部门员工账号，并保持幂等。

## 验收标准

- `AC-1601`：组织页面不再出现 `unrecognized_keys`，显示左树右基本信息。
- `AC-1602`：组织树包含部件BG及指定八个下级组织，收起父级隐藏全部后代。
- `AC-1603`：员工管理位于组织架构下方，列表可查询，新增/编辑均弹窗完成。
- `AC-1604`：不选所属部门或岗位不能新增；越权写请求返回 403。
- `AC-1605`：Seed 重跑不重复组织、岗位、员工、账号、任职和角色成员。
- `AC-1606`：初始化员工可使用初始化密码登录，但只拥有受限演示角色能力。

## 2026-10-04 编码规则当前有效变更

来源REQSRC-097。新建编码统一由[编码规则当前规格](../../requirements/013-numbering-rules/requirement.md)及036切片负责，替代本文中原有硬编码前缀/日期/流水或手填员工工号的描述；历史记录不改号。客户CUSTOMER默认C+7位、员工EMPLOYEE默认1+6位、商机OPPORTUNITY默认OP+年月日+5位、报价QUOTATION默认QT+年月日+5位、订单SALES_ORDER默认SO+年月日+5位、入库INBOUND默认IB+年月日+5位、销售出库OUTBOUND默认OB+年月日+5位。实际生成以当前启用规则为准，更新不重新取号；缺失/停用规则阻止新建，不回退旧算法。验收映射为036的REQ-NUM-06/AC-NUM-06/TC-NUM-06；未涉及本模块的对象仅作统一规则说明，不扩大功能范围。

## 2026-10-05 当前有效组织扩展（REQSRC-100）

- `REQ-1610`：组织层级由 `parentId` 计算，详情显示“第 N 级”，换上级后自动更新；不持久化重复层级。
- `REQ-1611`：`isSalesOrg`、`isRdOrg`、`isPlatformOrg` 是可独立组合的布尔字段，组织详情和编辑均显示；商机分析及销售订单选择仅允许启用的销售组织，服务端不得信任前端选项。
- `REQ-1612`：部门类型组织必须指定本租户在职员工作负责人；组织接口返回负责人姓名和员工 ID，员工停用前须先移交其负责的启用部门。
- `REQ-1613`：初始化可维护的“岗位”和“职位”字典，员工列表与编辑分别展示及选择。岗位代码映射到原有 `org_position` 和任职关系，职位值保存于员工；旧员工保留已有岗位并做一次职位初值回填，新建值按字典校验。
- `REQ-1614`：新增列采用前滚迁移，保留组织/员工及任职 ID；租户内负责人复合外键防跨租户。定向初始化只补缺字典与空负责人，不覆盖用户修改。

验收：`AC-1610` 组织层级、三标识、负责人可读写且两个或三个标识可同时为是；`AC-1611` 非销售组织不能作为 CRM 销售组织选择或写入；`AC-1612` 部门无负责人不能保存、跨租户或停用负责人被拒绝；`AC-1613` 员工岗位/职位从可维护字典选取，列表可辨认，旧数据仍可读取；`AC-1614` 迁移和定向初始化可重复执行且不改动人工维护数据。

数据所有权：`org_unit` 与 `org_employee` 属组织公共模块；岗位/职位字典属系统字典模块，业务模块通过接口读取。布尔字段和负责人为当前状态，原有有效期、版本与审计规则沿用；不删除历史记录。迁移恢复采用备份或前滚修复，不回写既有迁移。当前改动不改变账号角色或部门数据权限的授权语义。
