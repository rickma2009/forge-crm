# BOM 交互规格

状态：已确认、已实现；来源 [REQSRC-085](../../sources/REQSRC-085-bom-interaction-20261001/source.md)、[REQSRC-086](../../sources/REQSRC-086-screen-bom-demo-20261002/source.md)。

## 范围与不变量

- `BOM-REQ-01`：BOM 所属对象只可为启用的产品或半成品，组件及替代料取现有物料主数据。每产品最多一个草稿、一个当前已发布版；版本自增。
- `BOM-REQ-02`：列表遵循 UI-LIST-VIEW-01：查询、默认/个人视图、公共网格与分页，BOM 编码为详情入口。
- `BOM-REQ-03`：详情默认只读，树形层级通过子 BOM 已发布版本固定引用，展示直接与累计用量、子版本和替代料；禁止自身和循环引用，最多 12 层。
- `BOM-REQ-04`：仅草稿可维护基准数量、直接组件、替代料优先级和比例；保存为整体原子替换并检查 `rowVersion`。发布需要至少一行组件，旧当前版本转为历史，新版本成为当前。历史版不可编辑，可复制为草稿。
- `BOM-REQ-05`：XLSX 含“组件”和“替代料”两页，以行编码关联。导入先解析、校验和预览新增/变更/移除行；有效时应用到未保存草稿，点击保存后写库。导入不重写子 BOM 内部组件。
- `BOM-NFR-01`：按现有 tenant/application 作用域、会话、菜单动作权限和 CSRF 控制读写；拒绝无权限及跨作用域引用；审计写操作。
- `BOM-NFR-02`：该功能为交互演示，不联动库存、采购、生产、成本。
- `BOM-DEMO-01`：补充 21 种电子物料、12 种结构物料、6 种半成品组件；为 8 个现有大屏产品建立当前已发布 BOM，覆盖会议、教学、商显、LED 与交通屏。每个大屏至少有一个可展开的子 BOM；主控板提供芯片和电阻替代料。

## 验收

- `BOM-AC-01`：管理员可从基本信息打开 BOM 管理，查询与分页并点击 BOM 编码进入详情；受限查看用户不可写。
- `BOM-AC-02`：演示大屏 BOM 展开后包含板卡子 BOM；板卡芯片显示替代料，数量按各层基准数量计算。
- `BOM-AC-03`：草稿添加/修改/移除组件、替代料后可保存；错误或版本冲突不覆盖当前数据。
- `BOM-AC-04`：导入无效行显示行错误且不可应用；有效预览显示差异；关闭或离开未保存编辑时提示。
- `BOM-AC-05`：发布版本不可修改，复制新草稿保持原子项和固定子版本。
- `BOM-AC-06`：8 个现有大屏均能打开并展开多层 BOM；LED 屏的 4 个箱体累计展开为 16 个显示模组；重复执行演示数据脚本不重复创建数据。

已验证：数据库迁移、演示数据、授权 API 列表/详情和详情路由、前后端类型检查；新增大屏物料、8 个多层 BOM 与替代料经数据核验脚本验证。浏览器交互仍应按本页验收逐项回归。
