# BOM 验收用例

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| BOM-TC-01 | 管理员打开 BOM 列表并查询大屏 | 个人视图/默认视图正确，编码链接进入详情，分页为真实数量 |
| BOM-TC-02 | 展开大屏的板卡组件并点击芯片 | 子版本固定、芯片累计数量为 4、抽屉显示替代芯片 |
| BOM-TC-03 | 草稿编辑组件并保存 | 成功保存并增加版本锁；失效物料/循环引用/重复行编码被拒绝 |
| BOM-TC-04 | 导入有效和无效 XLSX | 有效预览差异并应用待保存；无效行显示原因且不能应用 |
| BOM-TC-05 | 发布、复制草稿 | 发布只读，旧当前版变历史；新草稿保留组件和子版本 |
| BOM-TC-06 | 查看用户尝试写入 | 无权限，草稿数据不变 |
| BOM-TC-07 | 编辑后离开页面 | 未保存提示，取消离开保留输入 |
| BOM-TC-08 | 查询 8 个现有大屏和 6 个半成品组件 | 均有当前已发布 BOM，每个大屏至少有一个可展开子 BOM |
| BOM-TC-09 | 展开 LED 大屏与主控板 | 4 个箱体累计有 16 个 LED 模组；主控芯片及电阻各有一项替代料 |
| BOM-TC-10 | 重复运行大屏数据脚本 | 物料和 BOM 数量不增加、不覆盖其他来源数据 |
