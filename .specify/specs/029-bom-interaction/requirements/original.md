# BOM 交互原始需求

来源：[REQSRC-085](../../../sources/REQSRC-085-bom-interaction-20261001/source.md)、[REQSRC-086](../../../sources/REQSRC-086-screen-bom-demo-20261002/source.md)。

产品或半成品可维护多层 BOM。用户从列表查询和个人视图进入 BOM 详情，在树形明细中查看每层物料数量和替代料；草稿可手工维护或导入 XLSX；发布版本不可直接修改，复制新草稿后再修订。页面用于交互演示，不触发其他业务。

补充电子元器件、结构件等大屏物料，并为现有大屏产品建立有子组件和替代料的演示 BOM；直接完成，无需中途确认。
