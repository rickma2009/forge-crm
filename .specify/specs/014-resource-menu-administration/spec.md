# Specification

## 用户目标

系统管理员能够在一个左右分栏页面中维护页面资源、页面操作和实际导航结构；保存后导航与角色权限立即以数据库结果为准。

## 验收标准

1. “菜单管理”入口改名为“资源菜单”，非管理角色不可访问。
2. 左侧资源树支持搜索、展开、选择、拖拽；节点右键菜单包含“新建子节点、编辑、删除”。
3. 新建/编辑资源支持系统、模块、页面、子页面、组件五类，以及编码、名称、父级、图标、路由、权限模式、状态、自动挂载、视图配置、分级管理、数据权限、排序和备注。
4. 删除采用停用语义并级联停用后代及导航挂载；系统根节点不可删除；移动不得形成循环。
5. 详情支持基本信息、子页面、按钮、页签和左菜单。按钮区分工具栏/行按钮；页签关联已启用页面；左菜单支持新增、编辑、删除、拖拽和批量保存。
6. 新建启用且自动挂载的模块/页面时，创建相应导航和角色可授权的访问权限；按钮维护同步稳定操作权限。
7. 所有写操作服务端复核 `access.resource-menu.manage`，导出复核 `access.resource-menu.export`，并写 `sys_audit_log`。
8. 导出当前节点及后代为可重复执行的 PostgreSQL SQL，不包含密码、会话或个人数据。
9. 数据按应用隔离，父子、页签和挂载不得跨应用；写入采用版本校验。
10. 左侧树隐藏系统根节点，只显示其下启用资源；树节点仅显示名称，不显示类型缩写和页面编码。
11. 基本信息不展示自动生成 ID；父级显示业务名称或“根节点”，不暴露父级内部 ID。
12. 左侧资源树具有独立纵向滚动区域，节点溢出时不带动右侧详情滚动。
13. 查询接口不返回停用页面资源；经 REQSRC-055 明确授权后，一次性物理清理已确认的 22 个停用资源及其关联菜单、按钮、权限和角色授权，不改变运行时“删除即停用”的语义。

## 明确不包含

- 不在本切片重建 supply 的字段目录、ABAC、用户展示视图控制面。
- 不保留 supply 的 SCS 过滤、天舟 ID、远程 IAM 回源和组织专属字段。
