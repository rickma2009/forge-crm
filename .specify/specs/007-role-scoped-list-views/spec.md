# Feature Specification: 角色范围系统视图与个人视图

| 项目 | 内容 |
|---|---|
| Feature ID | `007-role-scoped-list-views` |
| 来源功能 | `FR-505`—`FR-507` |
| 状态 | 历史基线已批准；2026-09-23 全局列表规则已按用户请求更新，页面适配待核查 |

- `REQ-701`：系统视图绑定系统、页面、操作；至少一个启用默认视图，并通过角色分配可用范围。
- `REQ-702`：配置包含列显隐/顺序/宽度/固定、查询栏显隐/折叠、过滤条件、排序和 10/20/50/100 页大小。
- `REQ-703`：admin 管理系统视图；admin/viewer 管理自己的个人视图；管理员对他人个人视图只读。
- `REQ-704`：个人视图必须基于当前仍可用的系统视图，只能使用基线字段；每用户每列表最多 30 个。
- `REQ-705`：按当前用户、应用及业务对象解析：有效的最近个人引用 → 有效用户默认个人视图 → 角色可用的对象系统默认视图。个人引用必须仍基于可用系统视图；失效提示回退，没有可用系统默认时失败关闭，不再取任意首个系统视图。最近选择的普通系统视图不覆盖有效个人引用优先级；仅创建其他个人视图不自动替换选用视图。
- `REQ-706`：单据及关键业务对象从菜单进入先展示列表：上方查询条件与查询/重置，其下左侧新增、右侧当前视图/选择/设置/总数/刷新的工具栏，再下方网格、行操作和服务端分页。新增受权限控制，行操作和按钮按 UI-LIST-01 / UI-BUTTON-01。每个列表设计必须明确是否提供设置页或弹层、对象标识、配置范围及作用域；不提供时说明理由。直接访问授权详情不强制回列表。
- `NFR-701`：视图配置不得扩大角色权限，服务端必须校验页面字段目录和当前会话所有权。

## 验收标准

- `AC-505`：角色只能取得已分配系统视图，无可用视图时显式失败；切换视图同步更新列、查询、过滤、排序和页大小。
- `AC-506`：用户可管理自己的个人视图和最近选择，但不能突破系统基线、所有权或 30 个上限。

Gate 由 `REQSRC-023` 对 `Q-509`—`Q-511` 推荐值的明确授权覆盖。

## 当前变更与验收（2026-09-23）

来源：[UIRULE-20260923-list-workspace](../../sources/UIRULE-20260923-list-workspace/source.md)。REQ-705/706 为整合后的当前规则，替代早期默认解析及未明确视图对象的列表设计约定。既有配置字段与权限边界保持有效。

- `AC-707`：无个人引用时采用对象系统默认，有有效个人引用时恢复它；删除/停用/撤权时提示回退，无有效系统默认时失败关闭。不同账号、应用及对象之间不串用。
- `AC-708`：单据与关键对象菜单入口展示查询区、工具栏、网格分页；设计明确视图设置入口、配置范围和对象标识，不提供视图设置的例外有说明。
- Specification Gate：因默认解析及验收变化重新审阅，本次用户请求确认个人引用优先及列表结构；本次仅同步规范，具体页面和服务实现/验证待核查。不新增 Architecture 或 Release Gate 批准。

## 2026-09-24 全局页面整改当前有效约定

来源：`UIAUDIT-20260923`，关联 `REQ-STYLE-05/09`。以下规则替代该范围历史呈现/接口冲突描述：公共视图扩展到产品、商机、报价单、竞争对手，按对象注册字段，显式幂等初始化系统默认。有效个人引用优先；引用失效提示系统默认回退，不使用任意第一项；无默认失败关闭。个人配置、选择、更新和删除均限定用户/应用/页面/动作；保存并使用在同一事务保存引用。四个新对象仅支持列显示/顺序/宽度、分页；标识列保留，固定关联查询不可覆盖。客户继续保留原有查询设置。

本次授权为用户要求按推荐方案直接整改；源码、单元测试与真实接口证据见 `.specify/requirements/global-page-style/audit.md`。历史 Release Gate 不覆盖本次增量；无新发布动作。

REQ-VIEW-ALIGN-001 / AC-VIEW-ALIGN-001 / TC-VIEW-ALIGN-001：依UIRULE-20260924-view-selector及UI-VIEW-CONTROL-01，当前视图/下拉/设置全部通过ListViewSelector组合，32px外框对齐。覆盖选项回调、设置权限、加载空态及浏览器桌面/窄屏三段几何比较；源为公共组件与两处接入。用户明确指令授权本地实施，无数据架构变化。
