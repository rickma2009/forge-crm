# Implementation Evidence: 007

## 已确认

- 系统视图按角色分配；个人视图只能继承当前用户可用且允许派生的系统基线。
- 查询区、显示列、分页、过滤和排序由同一份持久化视图配置驱动。
- 默认视图、用户选择和个人视图均存储在数据库，无浏览器本地存储依赖。

## 验证证据

- 数据库集成测试验证 viewer 能解析其角色基线视图。
- 浏览器验证客户默认视图与“配置并保存个人视图”对话框。
- 实现：`packages/server/src/list-view/`、`packages/web/src/showcase/EnterprisePages.tsx`。

## 复用边界

- 可复用：角色基线、个人派生、字段白名单和最大个人视图数约束。
- 不可直接复用：客户字段白名单；其他列表必须登记自身字段目录。
