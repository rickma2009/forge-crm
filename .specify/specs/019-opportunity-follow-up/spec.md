# 规格：商机跟进

- `BUS-022`：保留销售跟进过程。
- `REQ-1901`：按时间倒序展示跟进时间、跟进人、工作事项、结果/下一步。
- `REQ-1902`：支持新增、修改和逻辑停用，继承父商机数据范围。
- `AC-1901`：有权用户可维护并看到最新记录。
- `AC-1902`：通过子记录 ID 绕过商机授权必须失败。
