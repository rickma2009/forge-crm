# 规格：商机分析历史

- `BUS-022`：保留每次分析会判断及变化过程。
- `REQ-2001`：记录商机、阶段、赢率、把握度、竞争对象 1/2、机会点、风险、下一步和备注快照。
- `REQ-2002`：阶段或把握度变化必须和分析新增在一个事务中全部成功或失败。
- `REQ-2003`：分析只追加，继承父商机权限并进行版本冲突检查。
- `AC-2001`：每次分析形成独立历史记录。
- `AC-2002`：当前商机与分析快照原子一致。
- `AC-2003`：相同竞争对象、停用对象和并发旧版本被拒绝。
