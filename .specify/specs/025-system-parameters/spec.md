# 参数设置（当前有效需求）

BUS-2501：通过系统管理维护固定参数的原始文本，并供业务按参数编码读取和解释。

本版替代此前“保存引用ID、下拉候选、保存时校验法人仓库、联动清空”的设计；以 PARAMETERS-20260924-text-values 为最新来源，前两轮确认中不冲突的权限、作用域、无新增删除及暂不接入业务单据仍有效。

- REQ-2501 / AC-2501：系统管理列表显示参数编码、名称、原始参数值、使用说明、显示序号、当前状态六字段，不显示参数ID。保留查询、列表分页/刷新及图标编辑，无新增删除、无查看详情或个人视图。
- REQ-2502 / AC-2502：维护权限仅修改参数值和状态；ID等元数据固定。编辑弹窗只有参数值文本框与状态选择，保留只读说明/编码和取消/保存；无候选搜索、候选选择、上一页/下一页。
- REQ-2503 / AC-2503：参数值按字符串原样保存，支持文本、数值、日期等，不解析/规范化格式，不校验引用存在，不因非法法人编码拒绝保存。空输入保存null；保留数据库1000字符容量限制，此为存储边界而非业务格式校验。
- REQ-2504 / AC-2504：修改、清空或停用法人参数均不修改仓库参数；每项独立保存。
- REQ-2505 / AC-2505：公共读取返回可用参数的原始字符串，空/停用返回null；调用处解释参数。默认法人/仓库调用适配按当前租户的业务编码查找可用对象，找不到或从属不匹配返回null；基础设施错误不伪装为无默认值。本次不改业务单据的默认带出。
- NFR-2501 / AC-2506：保留租户/应用隔离、RBAC、CSRF、乐观版本和审计；初始化不覆盖值/状态；已有可解析引用ID在升级时转业务编码，无法解析的旧文本原样保留，由调用处视为无默认值。

预设编码：DEFAULT_LEGAL_ENTITY（手工填写法人编码）、DEFAULT_WAREHOUSE（手工填写仓库编码）。状态可用/停用。页面遵循 UI-LIST-01、UI-BUTTON-01、UI-QUERY-01、UI-MODAL-01、UI-TAB-01，右下角取消/保存，焦点及未保存离开保护不变。
