# 当前技术计划：通用文本参数

## 授权与变更
本次用户明确改为手工文本输入，替代原候选选择和保存时引用校验；需求、交互与验收重新按该输入更新。沿用已批准仓库React/NestJS/Prisma和数据库规范；无生产发布授权。

## 数据治理
sys_parameter仍是唯一参数单表，由公共system-parameter模块写入。UUID主键与tenant_id/application_id/parameter_code唯一键、同租户应用外键不变。parameter_value为可空varchar(1000)，数值/日期等均按文本存储，不解析、不trim、不判断业务引用。只限制已有存储容量。没有新增、删除权限或API，无有效期，状态可用/停用，审计字段与version不变。

列表不显示ID，但接口保留ID用于定位编辑。值直接显示原始文本，不再解析展示名称或是否有效。行操作图标及查询复用公共组件，弹窗右下角取消/保存、焦点、离开保护不变。

## 读写分层
公共getValue/getValues只返回有效状态参数的原文，空值/停用返回null，数据库故障抛错。没有主数据候选接口。保存仅锁定当前参数并校验version，不查询法人仓库，不修改另一参数，变更写sys_audit_log。固定字段与跨作用域写入继续拒绝。

业务侧InventoryDefaultsService作为显式调用适配：按法人编码/仓库编码匹配同租户可用记录，仓库还需从属匹配；未知编码返回null，不修改配置。未接入任何现有业务单据；以后需求明确时由调用方复用并校验自身权限。通用参数底座不依赖库存实体。
