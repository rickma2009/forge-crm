# 表格规范实施

状态：已实现并验证。见 [当前态需求](requirements/original.md)。

以 `BusinessDataGrid`、`DeclarativeDataGrid` 和 `RowActionButton` 为统一实现点；主业务列表身份字段由对象配置明确。声明式适配器负责在未显式提供时补序号、将已有操作列置于第二位，选择与表单型表格可声明例外。文本截断与多行标记在单元格级实现。不得因规范增加查看、修改、删除或审核权限。

审查发现业务页面中未直接渲染原生 `<table>`；正常页面、公共组件、演示与模板共 30 个源码文件、57 处公共网格调用。因此行高、居中、默认省略、声明式序号/操作列顺序在公共组件层统一生效。已有业务代码中可进入弹层的参数、法人、仓库、角色和资源编码已补统一入口；角色绑定、角色成员、阶段和字典等无维护权限时移除空操作列。角色视图的“操作”是权限动作字段，明确改称“动作”，不按行操作列处理。选择器、授权矩阵、分析交叉表及单据业务行号保持各自业务字段，公共网格只提供默认序号，不推断详情权限。

验证：前端完整测试 67 个文件、321 个用例通过；前端类型检查、页面样式检查（30 页）和 `git diff --check` 通过。浏览器抽查参数与仓库列表，确认 32px 数据行、序号/操作/编码顺序、编码链接样式。客户工作区测试先等待网格挂载后查找编码入口，以与异步渲染同步。

2026-10-03 垂直居中复核（REQSRC-091）：规范原已要求单行上下居中，本次明确覆盖多行内容块、图标和控件。源码检查发现共享 CSS 中 `.ag-cell-wrap-text` 曾顶端对齐，且声明式单元格内容固定最小高度 30px，导致部分内容视觉偏上；现统一由 `.ag-cell` 居中真实内容高度，多行自动增高仍保留。`validate:data-grids` 覆盖 30 个源码文件、57 处绑定，未发现业务页独立原生表格；页面专用 `.ag-cell` 样式只调整背景，不覆盖垂直对齐。共享网格 7 项测试及页面样式静态检查通过。本次运行中的本地演示门户未能进入业务页，浏览器逐页像素复核未完成；结论以全量源码绑定与公共样式检查为依据。
