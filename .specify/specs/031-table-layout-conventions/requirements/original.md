# 表格呈现规则当前态

来源：[`REQSRC-088`](../../../sources/REQSRC-088-table-layout-conventions-20261003/source.md)、[`REQSRC-091`](../../../sources/REQSRC-091-grid-vertical-centering-audit-20261003/source.md)。覆盖所有采用公共网格的业务记录列表和明细表；选择、授权矩阵、分析交叉表允许按任务语义显式例外。

- `REQ-TABLE-01`：默认数据行高由 34px 调为 32px；文字、图标、控件和多行内容块均相对所在行垂直居中。内容明确多行时按内容自动增高，不裁切。
- `REQ-TABLE-02`：记录表默认第1列为序号，存在行级操作时第2列为操作，无行操作时不显示空操作列。第3列通常是主数据编码或单据编号，若可查看详情则使用统一链接样式；不可查看时保持普通文本。
- `REQ-TABLE-03`：行级修改、删除、审核使用统一公共图标及顺序；其它动作排在其后。保留原权限和状态，不增加动作。
- `REQ-TABLE-04`：单行单元格默认不换行，超宽时省略并能通过悬停获知全文；明确标记的长文或复合字段允许换行和动态行高。
- `REQ-TABLE-05`：公共组件统一落实默认规则，现有页面对差异进行审查、整改或记录有理由的特例。
