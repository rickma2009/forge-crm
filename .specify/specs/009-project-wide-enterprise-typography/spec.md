# Feature Specification: 项目级企业界面排版令牌

| 项目 | 内容 |
|---|---|
| Feature ID | `009-project-wide-enterprise-typography` |
| 来源 | `REQSRC-028` |
| 状态 | `approved-under-REQSRC-023-standing-authorization` |

## 功能需求

- `REQ-901`：演示门户菜单、内容、标题、按钮、输入框、下拉框、表格和辅助文字使用同一字体族。
- `REQ-902`：上述元素默认使用与当前菜单正文一致的 `12px` 字号。
- `REQ-903`：字体族、基准字号、行高和大字号集中定义为项目级 CSS 变量。
- `REQ-904`：普通页面样式不得通过已有零散字号破坏统一规则；需要大字时必须显式选择项目级大字类。

## 非功能需求

- `NFR-901`：未来调整字体族或基准字号时只需修改项目级 CSS 令牌，无需逐页搜索替换。
- `NFR-902`：统一排版不得改变权限、数据、页面路由、布局尺寸或交互行为。

## 验收标准

- `AC-901`：菜单正文和内容区标题、正文、按钮、输入、下拉及表格的计算样式引用同一字体族和基准字号令牌。
- `AC-902`：项目级 CSS 中基准字号为 `12px`，字体族与当前菜单一致。
- `AC-903`：显式大字类引用项目级大字令牌；不使用该类的标题保持基准字号。
- `AC-904`：项目完整 lint、typecheck、test、build 与真实浏览器核对通过。
