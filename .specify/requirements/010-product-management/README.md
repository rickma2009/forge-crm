# 需求 010：产品管理工作区

> 状态：`business-design-approved-specification-pending`  
> 来源：`REQSRC-058`、`REQSRC-062`、`REQSRC-066`  
> 完整需求基线：[requirement.md](requirement.md)

本需求包是产品管理的当前完整需求，覆盖产品列表、新增、详情/编辑、受控删除、有效期定价和通用附件接入。既有切片 017 的产品基础能力继续有效；与本需求冲突的旧交互和“仅按最新价格取价”规则，以本需求为准。

报价单自身的完整规则仍由 [商机报价与商品定价需求](../009-opportunity-management/quotation-and-pricing/requirement.md) 负责，本需求只定义产品侧价格供给契约。
