# 编码规则当前规格

来源REQSRC-097，用户明确授权页面、初始化和各已实现对象接入。验证等级L3（跨模块、唯一性、并发及持久化）。

- REQ-NUM-01 / AC-NUM-01：系统管理→编码规则，查询对象编码/名称与状态；网格分页；新增、编辑及编码链接只读查看均为弹窗，行编辑/删除用图标。固定辅助配置表不提供个人视图设置，避免隐藏关键组成字段，复用公共查询/网格/分页/弹窗。
- REQ-NUM-02 / AC-NUM-02：序号是显示排序；对象编码在当前应用唯一且创建后不可改，对象名称可改；前缀开关、前缀（字母/数字，最多12位）、日期开关/年/年月/年月日、流水位数1—12、开始数默认1、状态默认启用。关闭前缀/日期规范化为空/NONE；开始数为正整数且容纳于位数。
- REQ-NUM-03 / AC-NUM-03：初始化12条用户指定默认规则，不覆盖人工配置或恢复已删除规则。供应商/采购/退货/调拨尚未实现创建模块，登记规则与接口，不新增这些业务模块。
- REQ-NUM-04 / AC-NUM-04：统一服务端接口产生前缀+上海当前取号日期+补零流水；无日期永久递增，年/月/日按相应周期重新开始。开始数是下限，不允许回退已有流水；修改位数不重置计数；改回旧格式继续原流水。历史编码保持不变。
- REQ-NUM-05 / AC-NUM-05：租户+对象串行锁及独立持久化发号账本；相同应用+对象+请求ID重试返回同号。号码分配独立提交，业务失败允许断号，不回收已发号；HTTP取号限独立权限，普通创建经原业务权限进入服务端适配，不要求终端用户拥有编码管理权限。
- REQ-NUM-06 / AC-NUM-06：客户、员工、商机、报价创建/复制、销售订单、入库单、销售出库均使用规则；新增确认保存才取号，浏览表单/预览不占号；工号改为自动生成，拒绝客户端工号；更新不改号。对未登记规则的产品等其他对象不擅自改变其既有编码语义。
- REQ-NUM-07 / AC-NUM-07：数据库作用域/唯一/外键与约束，既有同格式号码避让；停用或缺失规则阻止新建，不回退旧算法；溢出报错不截断。未使用规则可删除（保留墓碑），已有发号只能停用。管理操作版本检查与审计。

工程决策：规则按应用维护；发号唯一性与计数按租户+对象，兼容员工和出入库的租户级唯一约束。日期取当前服务端时间，不随用户回填单据日期改变。对象编码是接入契约，不支持用户输入物理表名或脚本。自定义对象可建立规则并通过接口调用，具体业务模块须显式接入。
