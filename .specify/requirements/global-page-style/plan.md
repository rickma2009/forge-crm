# 全局页面整改方案

来源：UIAUDIT-20260923；用户已授权常规推荐方案直接实施。重启恢复后仍为实施/验证中，不代表发布批准。

- 公共实现：RowActionButton 统一行操作；useTreeNodeMenu 统一可维护树节点双入口；既有 route-tabs 继续管理路由页签；BusinessDirectory 复用现有 list-view API。
- 对象范围：客户、产品、商机、报价单、竞争对手。客户保留既有查询字段能力；新接入四对象支持列显示/顺序/宽度、分页，保留标识列，按更新时间倒序。未实现的销售订单不冒充已接入。
- 视图初始化为显式幂等命令，读取已配置 SYSTEM_CODES，仅补缺失默认视图；不覆盖已编辑、停用的配置。后续 seed 同样调用公共初始化。未初始化、无默认或无角色时失败关闭。
- 新对象 `object-default` 是页面权限下的呈现基线，无角色分配时由已授权页面用户使用；管理员建立角色分配后只对分配角色开放。其他系统视图仍严格走角色分配。此规则不授予页面、数据、字段之外的访问能力，API 仍独立检查业务权限。
- 数据层级与责任：现有 sys_system_list_view / sys_role_list_view / sys_user_list_view / sys_user_list_view_preference，由公共 list-view 模块唯一管理；不新增物理表、外键或业务数据库写入口。应用由受控 systemCode 解析 applicationId，个人记录以用户+应用+页面+动作隔离；baseViewId 使用现有外键，UUID 主键和现有唯一约束不变。
- 状态/审计：系统视图保留 ACTIVE/DISABLED、版本及创建/修改人；个人配置沿用拥有者、版本与时间戳。选择个人视图只改变当前用户偏好；另存并使用在同一事务保存默认标记与引用，避免成功后仍显示旧视图。
- 失效：失效引用回退到可访问系统默认并提示；不回退任意第一条；撤销基线授权后禁止继续修改个人副本。个人配置不得扩展基线字段或移除必需标识列。
- 恢复：初始化仅插入缺失配置，失败事务回滚；重跑不覆盖人工配置，不执行重置/清库；无 DDL migration。需要撤销时先确认个人引用，再通过受控停用处理，不级联删用户数据。
- 数据验证：检查首次/重复初始化数量、配置保留、个人引用保存/恢复、对象和用户隔离、无默认拒绝、接口契约；只有实际运行结果才能登记通过。
- 商机修复：保持严格 DTO，将 Prisma 关联对象明确投影；跟进/分析写接口与 gateway 对齐返回详情，更新接口显式取详情中的 opportunity。回归覆盖带竞争对手的分析历史。

公共交互可复用；业务字段、对象注册表、权限、详情路由不能直接视为跨项目默认。
