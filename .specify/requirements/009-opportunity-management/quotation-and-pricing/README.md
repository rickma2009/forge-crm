# 商机需求增量：报价与商品定价

> 版本：v1.0-rc1（本次整理交付版）

> 来源：REQSRC-062；对照 REQSRC-058、REQSRC-059、REQSRC-060 和当前工作树  
> 状态：`locally-verified-awaiting-release-review`；REQSRC-063 已委托按推荐完成需求、计划、开发和测试，未授权 Release、外部部署或资产晋升

这是本项目**商机需求管理目录内的报价子域需求包**，不是外部 MCRM 的开发任务，也不覆盖此前商机、跟进、分析需求。

阅读顺序：

1. [需求正文](requirement.md)：本次完整整理稿，功能、字段、金额、状态、权限与验收。
2. [现有系统影响分析](impact-analysis.md)：哪些复用、哪些修改、哪些必须新增，以及实现证据。
3. [澄清与推荐决策](clarification.md)：原文冲突和目标项目适配选择；推荐不等于批准。
4. [逐步执行 Plan](plan.md)：工作包、依赖、进入条件、技术候选、测试和恢复。
5. [来源转换记录](transformation.md)：原文到需求的映射与验证边界。

核心建议：**一套产品主数据、独立销售定价、独立报价单、与商机关联但不合并商品行**。关联报价接受后，由授权用户明确选择回写商机预签金额，不改变阶段、把握度或结果。

初稿时尚未获本增量实施授权；后续 REQSRC-063 已明确授权持续开发与测试。当前实施为 [切片 022](../../../specs/022-opportunity-quotation-pricing/README.md)，见其验证报告、任务和数据治理记录。业务需求正文保留初稿决策背景；本状态更新不改写原始材料，也不伪造逐份人工审阅。
