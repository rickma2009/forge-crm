## 3. 候选技术方案

### 3.1 模块责任

沿用 React+Vite/现有工作区与样式、NestJS+contracts Zod+Prisma/PostgreSQL，不另建框架或业务数据库。

- 产品身份归既有产品责任模块。当前代码在 OpportunityService，先封装可报价查询/校验契约，不借此做无关全量重构。
- `pricing` 负责标准价/阶梯、不可变价格版本和可信取价，不接管产品身份。
- `quotation` 负责报价聚合、快照、状态、复制、PDF；草稿编辑与状态命令分离，禁止通用 PATCH 绕过冻结。
- `opportunity` 负责预签金额及来源；报价通过其专用应用服务回写，在明确的统一事务上下文中校验、条件更新及记事件，不直接绕过模块写表。
- auth/RBAC/dictionary 复用系统层；每个查询/命令传入 actor、租户和应用上下文，落实动作权限与对象范围交集。
- PDF 引擎/字体、过期任务实现由 ADR 决定；本次不安装依赖或部署服务。

接口按现有 `/api/systems/:systemCode/…` 风格，分为产品定价整组维护/建议价预览、报价查询/草稿/提交/反馈/复制/PDF、商机关联查询/受控金额回写。具体路由和错误码在切片中定义；本段不代表接口已存在。

### 3.2 候选数据登记

这是待评审映射，不是已创建表。Architecture 阶段在表登记册登记，以批准的 Prisma migration 为唯一 DDL 权威，同步 DDL 检查目录。遵守 md_/sd_、snake_case、表及字段名不超过 32 字符。

| 表候选 | 层级/唯一责任 | 作用域、键与生命周期 |
|---|---|---|
| md_product（既有） | 公共产品主数据/产品 | 保留 UUID、tenant 与产品身份；兼容单位/产品线历史空值，定义字典键或 ID 和旧文本映射，不造默认值 |
| sd_product_price | 销售定价/pricing | UUID；tenant+product+revision 唯一；版本不可变，每产品一个当前版本，通过原子指针/唯一约束保障，不做未来生效日 |
| sd_price_tier | 定价版本明细/pricing | FK price version，同租户；上下界和价格；整组写入、连续无重叠、末段无上限 |
| sd_quotation | 销售交易/quotation | UUID，tenant+application，单号全局唯一；客户必选、商机/联系人可选；五状态、业务日期/有效期、负责人、version、商业快照、总额、来源报价 |
| sd_quotation_line | 交易明细/quotation | 稳定 UUID、quote FK、产品引用与快照、价格版本、数量/价格/折扣/小计和排序；校验同租户应用和行归属 |
| sd_quote_event | 业务状态/反馈历史/quotation | quote FK、事件/幂等键、操作者、服务端时间、原目标状态与必要业务说明；公共审计另记安全元数据，不建立两个当前状态源 |
| sd_opp_amount_event | 商机金额来源历史/opportunity | opp FK、可选来源报价、旧新金额/版本、操作者、原因、幂等键；同租户应用，同时覆盖后续人工改额，避免当前金额来源标签失真 |

待 Architecture 补齐：复合作用域约束、客户 legacy systemCode 与 application 映射、各 FK/onDelete、单号分配、价格当前版本约束、事件保留策略和审计字段。不得只提交 ORM Model。

金额候选 numeric(18,2)、数量 numeric(18,4)、折扣百分数 numeric(5,2)；服务端 Decimal 计算，超精度/溢出明确拒绝。业务日用 date，事件用带时区时间；按 Asia/Shanghai 判断有效截止。已提交历史不物理删除，产品/客户删除不得级联损失报价历史；草稿删除/归档未列首期，不另加隐含状态。

### 3.3 必须验证的事务

1. 定价整组校验后创建版本并原子切换当前版本；并发保存不产生双当前，原版本可追溯。
2. 草稿引用/取价来源校验、重算金额、条件版本更新和明细保存原子完成；失败保留页面输入，无半单。
3. 提交再检查时间、权限、产品有效性、版本和价格变化确认，冻结商业内容与状态事件原子完成；不信任客户端只读总额/建议价。
4. 接受/拒绝/失效条件更新状态与版本；接受实时判时，扫描可重试/补扫，重复请求不重复记事件。
5. 回写校验已接受、关联与双对象权限；商机金额条件更新、来源、幂等结果同事务。旧请求重试返回原结果而不重写；同键不同载荷拒绝。人工改额也更新来源历史。
6. PDF 按商业快照和白名单生成，生成及下载同样授权；失败无状态副作用，不自动发送客户。

## 5. 迁移与恢复

1. 备份/导出结构，盘点产品缺项、字典映射；协调客户前缀迁移，不假定已完成。
2. 优先增量表/兼容字段；不自动填零价格/假产品线。通过可关闭入口隔离新功能，旧商机保持可用。
3. 在一次性测试库演练空库初始化、旧库升级、约束失败、恢复；迁移来自已批准设计，保存命令及证据。
4. 应用回退先关闭新入口、回到兼容版本，保留交易/审计数据；不能删除报价表作为回滚。有写入后优先前向修复；恢复备份需评估丢失窗口并独立授权。
5. 更新种子数据、表登记册、DDL、运行与过期任务说明；若改变 start.sh 必须实际测试。本轮不执行这些变更。
6. Release 包列 FR/AC/TC 证据、风险、迁移恢复、浏览器截图、权限矩阵、PDF 样例、依赖配置；独立批准后才变更发布状态。
