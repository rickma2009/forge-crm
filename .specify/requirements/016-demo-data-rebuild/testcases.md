# 全量演示数据重建验收用例

| 用例 | 对应要求 | 检查 |
|---|---|---|
| `TC-DEMO-01` | REQ-DEMO-01 | 检查备份文件存在，并在执行中断后恢复客户、物料、BOM、员工的原数量 |
| `TC-DEMO-02` | REQ-DEMO-02/03 | 核对来源标记、正式编码、分类、名称唯一性和 BOM 引用 |
| `TC-DEMO-03` | REQ-DEMO-04 | 用正则核对各对象编码，并检查 `sys_code_counter` 当前值 |
| `TC-DEMO-04` | REQ-DEMO-05 | 按类别、状态、类型和阶段分组，最小计数必须大于等于 5 |
| `TC-DEMO-05` | REQ-DEMO-06 | 核对员工关系、主从金额及库存流水与余额 |
