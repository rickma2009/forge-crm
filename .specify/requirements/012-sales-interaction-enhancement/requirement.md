# 销售交互增强当前态需求

日期：2026-10-04。来源：[REQSRC-092](../../sources/REQSRC-092-sales-interaction-plan-20261003/source.md)。状态：原方案后用户已授权开始，P1、P2、P3已实现并验证；P4—P6依据本轮连续实施授权已完成并验证。本文整合原始六项需求与本次接受的调整，业务方向已确认，新增详细默认值仍为设计建议。

权威方案：[销售交互增强详细解决方案](../../../docs/design/sales-interaction-enhancement-solution.md)。旧设计以该版本替代，不与其并行执行。

| 需求ID | 当前有效要求 | 验收 |
|---|---|---|
| REQ-SX-01 | 客户360扩展现有详情，按授权聚合联系人、地址、商机、报价、订单/出货，活动与协作随模块开放；源数据不复制 | AC01—03 |
| REQ-SX-02 | 单模板阶段看板、全筛选汇总、分列分页、受控拖动/菜单变更、个人视图兼容；不改业务状态 | AC04—07 |
| REQ-SX-03 | 统一时间轴适配现有跟进与真实系统事件，区分活动/待办，保留源记录与发生时间 | AC08—09 |
| REQ-SX-04 | 客户/商机评论、一级回复、附件、@提及和站内通知；不自动扩权、不接外部IM | AC10—11 |
| REQ-SX-05 | 原线索评分调整为商机跟进优先级，规则0—100可解释，系统分与人工覆盖分离；独立线索另立任务 | AC12—13 |
| REQ-SX-06 | 首批规则提醒→采纳待办→实际跟进；相似客户/历史统计作为后续子任务；不混算成交概率、不调用模型 | AC14—16 |
| REQ-SX-07 | 菜单/操作/对象/字段/租户/应用权限贯穿摘要、计数、解释、通知、附件；变更留审计且幂等 | AC02、11、16—17 |
| REQ-SX-08 | 复用统一样式与组件，通用交互与服务端业务规则分离，记录候选复用边界 | AC07、18 |

分期：P1客户360、P2看板、P3时间轴、P4规则建议、P5协作、P6评分。每包独立停止；P4增强项另立有限任务但不从总需求抹除。详细字段、状态、服务、数据、权限、验收、迁移与风险以方案第3—10节为准。

当前状态：一期P1—P6已交付；本轮范围结束，后续按新具体任务开展。未包含生产部署、跨项目成熟度晋升和长期自动执行。初次方案验证为L1；P4—P6涉及权限与事务，采用L3针对性验证。
