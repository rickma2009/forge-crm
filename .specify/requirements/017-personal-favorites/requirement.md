# 我的收藏

## 目标

登录用户可以将业务列表中的重要记录加入个人收藏，并从全局工具栏统一查看和取消收藏，减少跨模块反复查找记录的成本。

## 当前态需求

- 收藏对象包括客户、产品、物料产品、商机、报价单和销售订单记录；各对象由唯一稳定记录 ID 标识。
- 收藏属于当前登录用户，按当前应用/系统隔离。不同用户、租户或系统不能查看或操作彼此收藏。
- 在支持的业务列表行操作中提供收藏/已收藏切换；不增加独立收藏授权项。添加收藏不绕过当前用户已有的记录读取权限和数据范围。
- 顶部工具栏提供“我的收藏”图标入口，打开当前用户在当前系统内的收藏列表。
- 列表列为序号、收藏时间、对象类型、对象值；默认收藏时间倒序，同一时间以收藏 ID 稳定排序。
- 对象值使用当前业务记录的名称或单号：客户名称、产品/物料名称、商机描述、报价单号、销售订单号。只持久化对象类型和记录 ID，不保存可变名称快照；名称在查询时按当前权限与作用域批量解析。
- 每项收藏可发起取消操作；必须显示二次确认。确认后仅取消当前用户、当前系统下该条收藏；取消后列表即时刷新。
- 目标记录删除、停用、迁移出当前作用域或用户失去读取权限时，收藏列表不得泄露其名称；显示“对象不可用”并允许用户取消收藏。
- 支持键盘操作、中文提示和可访问名称；收藏按钮不因业务编辑/删除权限而隐藏。仅业务记录本身可见且页面授权时展示其行操作。

## 范围与边界

- 首期范围：客户、产品、物料产品、商机、报价单、销售订单。
- 收藏本身是用户偏好关系，不修改目标业务数据，不发送通知，不参与业务审批或审计变更。
- 浏览业务记录仍受既有菜单、操作权限和数据范围控制；收藏不创建新的业务数据读取权限。
- 生产发布与其它应用部署不属于本需求。
