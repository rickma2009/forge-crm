# 企业工作台、主从工作区与交互资产提炼请求

来源：用户于 2026-09-05 在当前 Codex 任务中的直接要求。

## 原始需求摘要

1. 参照销售订单原型的工作方式，再设计一个企业工作台和主从工作区。
2. 盘点演示门户左侧全部菜单，不只处理单一示例；从中抽象企业管理系统常见的方法、页面模板和交互模式。
3. 将待办、提醒等个人行动入口纳入设计，并覆盖工作对象选择、上下文查看和后续处理。
4. 在设计和实现过程中同步形成可复用总结，供后续企业管理项目选用。
5. 用户授权 AI 按自身理解和推荐方案连续推进，中间不再要求确认。

## 本次解释与边界

- 采用现有中性企业设计系统和销售订单视觉基线，不创建新的品牌语言。
- 工作台用于“发现今天要做什么”；主从工作区用于“在保留队列上下文时处理一个对象”。
- 待办、提醒、预警、消息和审批保持不同语义，不因都出现在工作台而合并为一个业务对象。
- 首次实现使用确定性内存数据，只验证交互与信息结构，不接入真实工作流、通知、日历、审批或业务数据库。
- 左侧 27 个已登记入口用于归纳页面族和组合方式，不把所有入口批量实现为 Demo。
- 本来源不构成新的 Business、Specification、Architecture、Release Gate 或方法论晋升批准。
