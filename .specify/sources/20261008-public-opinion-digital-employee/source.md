# 舆情监控数字员工需求来源

- 日期：2026-10-08
- 来源：用户会话确认
- 状态：已确认并授权开发

## 业务边界

建设可运行的舆情监控数字员工。监控对象仅包含品牌 `MAXHUB`，匹配规则为品牌词与投诉、质量、售后、安全、交付、合规风险词组的 AND 关系；风险词组内部使用 OR。

监测必须由用户手工触发，不建立后台自动轮询。一次手工运行可选择来源、时间范围、是否执行 AI 事实摘要、是否仅预览。运行采用后台阶段进度，单来源失败不影响其他来源。

数据采用“原始信息 → 聚合事件 → 处理任务”三级结构。重要和紧急事件创建内部任务；所有对外回复、发布均不自动执行。事件与任务分别维护状态，保留来源、评分依据、时间线和审计。

首期连接器包括 GDELT、RSS/Atom、通用 REST、NewsAPI 和文件导入；平台数据必须通过正式授权接口接入。保存来源标题、摘要、公开链接和分析结果，只有授权接口允许时保存正文。

页面包含监测概览、舆情事件、原始信息、任务闭环、主题与词库、来源接口、策略与预警、采集记录。事件和原始信息支持 CSV 导出。权限复用 `de-scene-risk` 的 `view / execute / manage`。

初始化 MAXHUB 中英文风险词、连接器模板、20 条原始信息、8 个事件、6 个任务和5次运行记录，真实与示例来源必须明确区分。
