# REQSRC-079：数据库驱动的交互案例目录

日期：2026-09-27

## 用户原始要求

- 将 `/showcase/style-scenes` 改造成与“物料产品管理”相同的左树右表格页面。
- 左侧按照“类型、分组”形成两级树状菜单。
- 顶部查询区复用物料产品管理的查询条件样式。
- 交互案例数据保存到该页面原有的场景表；现有字段不合适时按当前类别字段映射并补充必要字段。
- 选择案例后不再使用抽屉，而是以覆盖列表工作区的详情页面展示。
- 详情页面使用项目统一的简单返回箭头。
- 新页面完成后，原 `/showcase/interaction-index` 页面不再保留。

## 已批准决策

用户批准推荐方案：继续使用 `style_scene` 主表，`category` 保存类型、`sub_category` 保存分组；增加结构化明细字段，完整保存原交互资产定义、来源、产物和证据；列表采用摘要接口，详情按记录读取完整内容；交互索引继续保持登录可访问、不增加页面权限控制。

## 约束

- 不新建另一张交互案例主表。
- 不删除原 `style_scene` 历史记录。
- 页面必须复用 `RecordQueryBar`、`TreeWorkspace`、`DetailBackButton`。
- 数据库表名、字段名使用小写且不超过 32 个字符。
- 方法论登记册是初始化来源，运行时页面只从数据库读取。
