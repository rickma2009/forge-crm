# MCRM 报价单与商品定价需求（独立文档）

> 状态：草案 / 待业务确认
> 定位：本需求**独立成文**，暂不与 V2.0 商机产品明细做合并或迁移；报价单与商品库自成体系，后续是否与 V2.0 整合另行讨论。
> 与现行基线关系：V2.0 明确"不做产品主数据、不做报价单"。本文档引入商品主数据 + 定价 + 报价单，属于新增功能。

---

## 1. 背景与目标

- 商机走到报价阶段时，销售需要给客户一份正式报价单，而不只是商机里的几行自由文本产品。
- 报价不能凭感觉出价，需要每个商品有定价依据：标准价、按数量的阶梯价。
- 目标：做到"选商品 → 系统按定价策略带出建议价 → 生成可流转的报价单"。

## 2. 名词与边界

| 名词 | 说明 |
|---|---|
| 商品 Product | 可报价的最小单元，有名称、型号、单位、产品线、三种价格 |
| 标准价 | 官方标价，每个商品一个 |
| 阶梯价 | 按本行数量区间给的不同单价，商品 × 数量区间 |
| 报价单 Quotation | 一张主子表单据，主表是单据头，子表是多行产品 |

> 注意：报价单走独立的商品库选商品，与 V2.0 商机里的自由文本产品明细暂不打通，后续再议。

---

## 3. 商品与定价策略

### 3.1 商品（Product）

| 字段 | 规则 |
|---|---|
| 商品 ID | 系统生成、只读 |
| 商品名称 | 必填 |
| 型号 | 可选 |
| 单位 | 必填，如台/套/项 |
| 所属产品线 | 必填，选启用产品线（复用 V2.0 产品线清单） |
| 标准价 | 必填，人民币含税、≥0、两位小数 |
| 状态 | 启用 / 停用；停用不可新选，历史报价仍可见 |

### 3.2 价格取价规则

报价单行选商品后，系统按以下规则自动带出**建议单价**，销售可手改：

1. **阶梯价命中**：本行数量落在某阶梯区间，用该阶梯价；
2. **否则用标准价**。

> 即：`建议价 = 阶梯价(数量命中) 否则 标准价`。取价结果在报价单行上可见（标注来自标准价还是阶梯价），销售可覆盖。

### 3.3 阶梯价（Tiered Price）

- 一个商品可有多行阶梯，按数量区间：数量起 ~ 数量止 → 单价。
- 区间不重叠、不留缝；报价行数量落在哪个区间用哪个价。
- 示例：1–9 台 1.0 万/台；10–49 台 0.9 万/台；≥50 台 0.8 万/台。

## 4. 报价单（主表）

| 字段 | 规则 |
|---|---|
| 报价单号 | 系统生成、只读、全局唯一 |
| 报价单标题 | 必填，如"XX 项目一期报价" |
| 客户 | 必填，关联客户 |
| 关联商机 | 可选；从商机进入报价时必填，写入商机 ID，用于追溯和回写 |
| 联系人 | 可选，须属于该客户 |
| 报价日期 | 必填，默认当天 |
| 有效期至 | 必填；过期未接受的报价单自动置为"已失效" |
| 币种 | 固定人民币，不做多币种 |
| 税率 | 不单独列税率，单价按含税价录入（与 V2.0 一致） |
| 状态 | 草稿 / 已提交 / 已接受 / 已拒绝 / 已失效 |
| 报价总金额 | 子表小计汇总，系统计算 |
| 备注、报价条款 | 可选 |

- 报价单挂在客户下；有商机时同时挂在商机下，用于追溯。

## 5. 报价单行表（子表）

| 字段 | 规则 |
|---|---|
| 行号 | 系统生成 |
| 商品 | 必填，从启用商品中选 |
| 商品名称/型号快照 | 选商品时冻结写入，商品主数据后续改名不影响历史报价 |
| 单位、数量 | 数量必填、>0 |
| 建议单价 | 按第 3.2 规则带出，只读展示取价来源（标准价 / 阶梯价） |
| 成交单价 | 必填，默认=建议单价，可手改 |
| 折扣率 | 可选，默认无折扣 |
| 行小计 | 系统计算 = 数量 × 成交单价 × (1 − 折扣率)，两位小数 |
| 交付时间、行备注 | 可选 |

- 一张报价单可多行；同一商品可拆多行。
- 报价总金额 = 所有行小计之和。

## 6. 状态流转与业务规则

```
草稿 ──提交──▶ 已提交 ──客户接受──▶ 已接受
                  │
                  └──客户拒绝──▶ 已拒绝
已提交超过有效期 ──────────────▶ 已失效
```

- 草稿可任意编辑；已提交后行内容不可改，如需修改走"基于此报价单新建一版"。
- 已接受：可选动作"回写商机"——把报价总金额回填到商机的预签金额；**不自动修改商机阶段或结果**。
- 已拒绝 / 已失效 / 已接受 均为终态，可重新复制为新报价单。
- 报价单不做审批流；折扣审批等工作流能力后续统一规划。
- 报价单支持导出 PDF（用于发给客户）。
- 金额一律人民币、两位小数、单价含税；与 V2.0 通用规则一致。

---

## 7. 已确认决策与待确认

**已确认：**
- 不做渠道价，只保留标准价 + 阶梯价。
- 折扣不做审批，后续做工作流时再统一考虑。
- 阶梯价**不跨行合并**：每个报价行按本行数量单独匹配阶梯。
- 报价单支持导出 PDF。
- 基于商机创建的报价单必须写入商机 ID；报价接受后**不自动修改商机阶段或结果**，只可手动回写预签金额。

**待确认：** 无（已与 V2.0 解耦，独立成文档）。
