# 用户增量实施请求原文

> 参考 supply 项目与 `https://scssit.gz.cvte.cn/settings/resources` 的资源菜单，在 sdd-forge 中开发“资源菜单”，替代系统管理中的“菜单管理”。需要覆盖页面字段、按钮操作、左侧树右键菜单和对应数据表；新物理表遵循 SDD 数据库规范，以 `sys_` 开头。

## 约束与实施授权

- `supply/` 是只读证据源，不得修改；本工程只重新实现经验证的行为。
- 用户要求直接开发，且此前已授权后续需求、方案按推荐结果连续推进；本来源据此批准本切片的 Business、Specification、Architecture Gate，仅限本地实现与验证，不代表 Release Gate。
- 在线页面访问被企业登录页拦截；字段、交互、接口与表结构以 supply 源码、原型、测试和 SQL 为主要证据，在线 URL 仅记录为受限证据。

## 明确范围

- 页面资源树搜索、选择、拖拽、右键新建子节点、编辑、删除。
- 页面资源基本信息；工具栏/行按钮；页签；实际左侧导航挂载、层级、排序、编辑、停用。
- 菜单 SQL 导出。
- 角色授权仍以当前 `sys_permission` / `sys_role_permission` 为唯一入口，不允许按用户单独授权。

## 去来源化边界

- 不保留供服专属 `SCS` 根编码、天舟兼容字段、旧 Java 接口签名或组织专属权限标记。
- 字段目录、ABAC 与展示视图是独立公共能力；本切片不复制 supply 页面中后续叠加的字段级权限控制面。
