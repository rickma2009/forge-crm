# 产品工作区、有效期定价与通用附件需求

来源：2026-09-23 当前 Codex 任务中的用户需求及后续“按推荐”确认。

用户要求先更新对应需求文档，再进行实现：

1. 产品管理增加删除功能；提交删除时必须校验产品是否已被报价单、定价或商机引用，存在引用时不可删除。
2. 新增产品继续使用弹窗；浏览和编辑改为与客户详情相似的工作区 Tab 页面。
3. 产品详情包含：产品详细信息、产品定价、附件三个页签。
4. 产品定价包含产品编码、产品名称、单位、定价类型（标准、阶梯）、单价、币别、生效日期、失效日期、当前是否有效、阶梯数量从/至、备注。其他页面报价时取报价当时有效的价格。
5. 附件能力必须通用化，通过参数在不同业务对象中复用，统一提供列表、上传、下载、删除、修改说明等功能。
6. 附件文件保存在统一目录，并可按归属类型划分子目录。
7. 新建附件记录表，至少保存：ID、附件归属、归属 ID、附件类型、附件地址、首次上传时间/人、最后修改时间/人、附件说明、可空的手工文件版本。

经用户确认的推荐解释：

- 产品删除由服务端在最终提交事务中校验引用；有附件时也先删除附件后才能删除产品，避免孤立文件。
- 当前价格不是简单取最新版本，而是按报价单业务日期匹配有效期；报价保存价格记录 ID 与价格快照，历史报价不随调价改变。
- 标准价与阶梯价为互斥定价类型；首期保留币别字段并只初始化人民币，不实现汇率换算。
- “当前是否有效”由状态及生效/失效日期计算，不保存容易失真的独立布尔事实。
- 附件元数据使用公共系统能力；文件位于非 Web 公共目录，通过鉴权下载接口访问，数据库不保存二进制文件或服务器绝对路径。

本文档仅归档用户请求与已确认解释，不构成后续 Specification、Architecture 或 Release Gate 的替代批准。
