# REQSRC-080：交互目录组件资产与真实演示入口

来源类型：用户增量需求与截图反馈  
日期：2026-09-28  
状态：implemented-and-verified

## 用户原始意图

1. 保留当前“类型 → 分组”两级分类，但复核分类是否合理；不合理时调整内容。
2. 将管理系统常用组件纳入交互案例目录，包括当前缺少的查询组件、视图组件等。
3. 已实现页面应作为真实、可交互的演示证据。例如“左树右网格明细”可直接复用物料产品管理页面。
4. 目录列表增加可点击的演示入口。点击后不覆盖当前树状目录，而是在现有工作区中打开一个新的路由页签。
5. 继续补齐已经实现或可基于经验落地的交互演示；完成后用户可从目录直接查看效果。
6. 用户要求连续开发，不再等待中间确认。

## 当前态解释

- 原六类用于描述交互行为，继续保留。
- 新增 `COMPONENT` 类型表达可复用的实现部件，避免把查询栏、视图选择器等误归为页面或展示模式。
- 真实演示地址作为交互资产的可选属性存入 `style_scene.page_path`；无已验证页面的资产继续只展示确定性的本地说明演示，不伪造业务能力。
- 真实演示通过现有 `ShowcaseApp` 路由页签导航，不使用浏览器新窗口，也不替换交互目录自身的页签。
