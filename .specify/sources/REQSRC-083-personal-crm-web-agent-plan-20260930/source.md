# 个人 CRM Web Agent 需求与共识来源

日期：2026-09-30。来源：当前 Codex 对话中的用户请求、三轮推荐决策及独立方案文档指令。

## 用户原始目标

> 结合 crm 端的功能，开发一个 web 端的 agent 的功能，先聚焦字自己使用，不考虑租户，可以是多个用户，即每个账号打开是自己的会话会话更难，在会话上，可以实现访问当前的客户、商机、跟进过程，复盘信息，针对当前线索可以有话术、提示词、资料，以及可以生成待办。另外针对目标可以进行目标、任务分解、输出营销方案和文案，对接知识库，生成营销案例。 另外对客户也可实现 agent 对客户、商机打标签，针对不同的标签可以分类、搜索和分析

## 已确认的三轮选择

用户三次回复“全部按推荐”，确认：独立 Agent 工作台加客户/商机上下文入口；会话本人可见，业务资料遵循 CRM 查看权限；首版先做会话、CRM 检索、跟进建议与待办，其余分阶段；写入前形成可编辑草稿并由用户确认；“线索”首版指未关闭商机；会话绑定一个主要业务对象或为通用会话；待办为正式独立记录并显示在我的工作台；回答附来源，不编造资料；模型故障保留输入并显示错误；首版资料仅用现有 CRM 记录；待办默认本人、缺少可靠日期时留空；会话持久化、改名、搜索、归档及删除确认；Agent 使用由角色授权。
