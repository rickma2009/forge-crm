# 物料详情浏览/编辑同构与返回按钮规范化

日期：2026-09-25

## 用户原始要求（语义归档）

- 物料产品详情页面的返回箭头不符合现行样式规范，需改为统一返回按钮。
- 物料详情浏览态与编辑态必须使用相同的页面布局和字段控件；浏览态仅将输入框、下拉框、文本域等设为只读/不可编辑，不再改成纯文本标签值布局。
- 将该约束补充到全局页面规范，后续单据或信息对象详情均遵循“同构浏览/编辑”规则。

## 验收口径

1. 物料详情调用公共 `DetailBackButton`，使用 Tabler `IconArrowLeft`，尺寸、提示、焦点及列表目标符合 `UI-BACK-01`。
2. 物料基本信息在浏览态和编辑态使用同一字段顺序、同一网格及同一控件类型。
3. 浏览态控件不可修改，编辑态仅解锁业务允许修改的字段；物料编码等永久只读字段始终锁定。
4. 进入编辑、取消编辑、保存成功不更换详情布局，避免字段位置跳动。
5. 现有三个内容页签、权限、保存接口和返回目标保持不变。
