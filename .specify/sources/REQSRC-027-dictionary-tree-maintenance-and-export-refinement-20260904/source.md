# 数据字典树、维护范围与导出功能增量需求

来源：用户于 2026-09-04 在当前 Codex 任务中的直接反馈。

## 原始需求

1. 数据字典在左边只显示字典描述，不需要显示字典 ID。
2. 多级数据字典的任何一级都可以新增字典值；例如“物料类别”本身也可以设置具体值，不因存在下级而限制。
3. 上级收起时，其所有下级都应一起隐藏，不能重新出现在左侧一级列表中。
4. 在现有 Excel 导入功能旁增加 Excel 导出功能。

## 本次执行解释

- “任何一级都可以新增”解释为：层级关系不决定是否可以维护字典值；既有明确标记为初始化固定值的独立字典仍保留不可维护约束。
- Excel 导出当前选中字典从数据库查询所得的完整值列表，列结构与导入模板一致。
