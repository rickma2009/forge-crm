- 类型：功能需求变更

## 原始需求

数字化员工菜单名称调整如下：

- 品牌舆情与供应商风险雷达 → 舆情监控
- 客户 RFQ 解析与规格澄清 → 暂不在菜单提供
- 电商评论与用户之声分析 → 电商评论
- 采购订单确认与交期跟催 → 采购订单执行
- 工单齐套与缺料影响分析 → 生产工单执行
- 呆滞、超储与效期风险分析 → 库存管理
- 报价成本与毛利风险汇总 → 研发过程执行
- 材料行情与汇率敞口日报 → 大宗商品监控
- SMT 换线准备门禁检查 → 暂不在菜单提供
- AOI/SPI 不良聚类与良率早报 → 质量过程执行
- 序列号与批次正反向追溯 → 暂不在菜单提供
- 客诉、RMA 与 8D 协同 → 客诉及质量事件

另将原“邮件数字员工”以“邮件处理”名称补入数字员工菜单。

## 实施解释

“先不要”按本次菜单变更范围处理：暂时从左侧菜单隐藏 RFQ、SMT 换线准备、序列号追溯三个场景；保留底层场景定义及数据，以便后续恢复。邮件处理放在“公共”分类，显示待处理邮件和邮件配置工作区。
