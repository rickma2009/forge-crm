# REQSRC-099 审批流程方案规划

日期：2026-10-05。来源：本轮用户消息；以下正文逐字归档，不把其中的设想标为已实现。

审批流程的方案请按建议生成独立的方案文件，实现配置的代码以及flowable的开源源码，也请合理规划目录管理。 按flowable的说明，除了以上的审批设置外，还有哪些常见的审批设置场景，我这里遇到比较多的是： 请假审批、报销审批，报价单申请，销售订单审批，付款申请等等都是业务单据类的审批。 同时也有异常事件，需要流程比较场景的针对事件的复盘审批，在不同审批节点，可能会新建或修改原单据中的一些状态和信息，比如：事件审批到财务环节，则要关闭某个单据的状态，需要在节点回调某个代码或者接口等。

按以上我的想法、业务场景，请规划一个审批流程的方案文档，从背景、目标、选型、实现等方面做好规划。 其中实现包括 工作流设置的页面，以及在实际单据、业务中工作流流转，审批人收到消息，能打开自己需要审批的待办列表，可查看当前审批可视化节点，并可同意、驳回、转发等，有审批执行的页面，在页面上能看到当前节点的情况和已审批节点的记录等。

请先规划方案。 如方案OK，可先做个原型确认看看效果
