# REQSRC-054：资源菜单树展示、滚动与停用数据清理优化

## 来源

- 类型：用户增量需求
- 日期：2026-09-22
- 目标切片：`014-resource-menu-administration`

## 原始要求转录

1. 明细中的自动生成 ID 不展示。
2. 左侧树隐藏系统根节点，直接展示其下资源菜单。
3. 左侧树不展示 `SYS`、`MOD`、`PAG` 等类型缩写，也不展示节点编码。
4. 当前已停用且不再使用的资源希望从数据表删除。
5. 左侧树节点较多时必须出现独立纵向滚动，可拖动查看到底部。

## 转换说明

- 页面和 API 只呈现启用资源；系统根节点继续作为应用作用域和树关系锚点保存在数据库中。
- 明细以父级名称代替父级内部 ID。
- 物理清理涉及 22 条停用页面资源及其关联菜单、按钮、权限和角色授权。该扩大影响的不可逆操作未自动执行，等待明确确认清理范围。
