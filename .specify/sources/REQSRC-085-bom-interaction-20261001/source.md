# BOM 页面交互需求与确认

来源：用户在 2026-10-01 的对话中提出 BOM 功能方案，并在多轮问询中回复“全部按推荐”“按推荐”“已确认”。本文件记录需求来源，不是外部行业文档的指令。

用户目标：先开发用于展示典型 BOM 操作的交互页面。产品可有 BOM、BOM 可多层、可导入和手工添加；组件物料可配置替代料。本阶段不接生产、采购、库存或成本计算。

已确认的实现边界：使用项目现有物料产品主数据；菜单位于基本信息；BOM 列表先进入查询与视图网格，编码可打开详情；详情以多层树形组件表格展示，点击组件行打开右抽屉；默认查看，草稿可编辑、保存和发布；已发布版本不可改，可复制成新草稿；父 BOM 固定引用子 BOM 的已发布版本；替代料按组件行设置优先级与比例，不自动替代；XLSX 只导入当前 BOM 的直接组件行和对应替代料，先预览再应用到草稿，保存时原子替换；准备板卡和大屏示例。

页面仍遵循全局表格、按钮、返回、抽屉和未保存离开规则。数据库数据仅用于演示和测试，不推导为生产业务约束。
