# 企业管理页面模板、销售订单子表与 BOM 展示研究请求

来源：用户于 2026-09-05 在当前 Codex 任务中的直接要求与后续方案选择。

## 原始需求摘要

1. 整理企业管理软件常用样式、组件、页面模板和交互模板。
2. 首个具体对象为销售订单：表头加表体，表体是网格形式的子表，重点验证添加行、删除行等操作。
3. 参考优秀案例和 GitHub 上适合企业管理系统的 TypeScript 或其他语言项目，但将其整理成技术栈中立的页面、交互与组件候选，不直接复制业务和框架约束。
4. 补充 BOM 等制造业层级数据的展示方式。
5. Product Design 生成三个视觉方向后，用户明确选择第一个方向继续实现。

## 本次解释与边界

- 当前实现是验证场内的可交互设计原型，入口为 `/showcase/templates/edit-form`。
- 原型验证表头、行项目网格、行新增、产品选择、行删除与撤销、行级日期校验、复制、合计联动和暂存/提交反馈。
- 不接入订单数据库、库存、价格、BOM、审批或真实权限接口，不声明真实业务可用。
- 外部项目仅作为来源证据；结论仍处于候选阶段，未经真实项目采用与业务验证不得晋升为正式模式或最佳实践。
- 本来源不构成新的 Business、Specification、Architecture 或 Release Gate 批准。
