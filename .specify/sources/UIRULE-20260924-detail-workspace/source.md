# 用户原始需求

如果有2个样式，第一个客户详情页面，第二个是商机
请在样式规范中，对通过列表页面进入到详情页面的样式做约定或者做成组件的样式，供调用。
1.在详情第一行，前有一个返回的箭头，如：客户中的样式，全部统一
2.在返回箭头的右边，为编码（比如：报价单）或者名称，比如：客户简称等。
在第一排的下面，有只读的字段显示，如客户下面的，商机下面的，格式全部是：“字段名：字段值”
下面如果有tab，tab页面全部采用，客户详情的样式，不是图二商机阶段的样式，请将tab页面的样式做好约定，且在tab页面的内如页面中，原则上不在用方框圈起来，如图二中的那样。应该是tab页面是大的容器，将内如放在下面。如果有明确的区分，则可以放一个分割线，或者留空一行后，有个说明，比如：报价产品明细
请总结样式后，提炼到样式规范总的文件中，总之要统一、规范，整齐美观。可作为组件的请开发为组件使用。
