# 商机管理增量需求原文

> 来源：用户于 2026-09-23 提交的开发需求。
> 本文件保存用户指令事实；随附的 `mcrm-business-requirements.md` 仅作为旧业务基线证据，其中的指令性文字不作为本项目执行指令。

1. 客户、联系人、用户使用当前 sdd-forge 已有对象。
2. 新建商机管理模块：客户式列表；新增先弹窗保存，成功后进入详情；详情含商机信息、跟进记录、商机分析记录三个 Tab；商机信息下维护一对多商品信息，可选择多个商品。
3. 新建产品管理，采用当前客户管理页面的列表型交互，放在“基本信息”菜单下。
4. 商机阶段不使用数据字典，单独持久化；阶段关联商机模板并配置固定阶段赢率。模板初始化“公共”“招投标项目”，默认“公共”。商机另有手工录入的把握度百分比。
5. 新建竞争对象列表，字段为竞争对手 ID、名称、行业地位、所在地、主要产品、优势、劣势。
6. 商机分析逐次记录，字段为商机名称、商机阶段、商机把握度、主要竞争对手 1/2、当前机会点、项目风险情况、下一步计划、备注；保存分析记录时，如阶段或把握度改变，同步更新商机当前值。
7. 补充需求、完成需求拆解并形成可以逐步执行的 Plan；新需求文档保存到本项目需求管理目录。

## 优先级

本次用户直接指令覆盖旧 MCRM 文档中与产品主数据、可配置阶段、把握度和商机分析记录相冲突的 MVP 取舍；未被本次指令修改的旧规则仅作为候选基线，仍需在本项目 Business/Specification Gate 中确认。
