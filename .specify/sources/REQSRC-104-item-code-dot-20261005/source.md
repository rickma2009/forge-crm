状态：已批准实施

## 用户原文

> 系统编码不允许点号 ，不允许逗号，这个是哪里的规则？ 可以是逗号。
>
> 允许点好，请修改需求文档汇总功能的业务规则。

结合连续上下文，将“点好”按“点号”处理。当前获准变更是物料/产品编码允许英文句点 `.`；用户没有确认逗号，因此逗号仍为非法字符。

## 当前有效规则

- 适用字段为统一物料主数据 `md_item.item_code`，以及入库、库存等接口中引用该物料编码的字段。
- 允许字符为大写英文字母、数字、英文句点 `.`、连字符 `-`、下划线 `_`；最长 32 个字符。
- 英文逗号 `,`、中文逗号 `，`、空格、小写字母和其他标点不允许。
- 编码在租户内唯一，创建后不可修改；业务依赖仍以 `item_id` 建立强关联，交易记录可保留编码快照。
- 本次从 Excel 导入、曾因旧约束将句点转换为连字符的 `001` 产品及 `004` 物料，恢复为来源文件中的点号编码；BOM 通过 `item_id` 关联，恢复过程不得产生孤儿或改变 BOM 数量。
- 法人编码、仓库编码、原因码、工厂编码及数据字典项编码继续使用原通用编码规则，本次不随之放宽。
