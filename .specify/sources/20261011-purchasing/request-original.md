# 本轮用户原文（不可改写归档）

请你规划一个供应商管理模块，按你的经验设计供应链基本信息。你是供应链专家，用你的经验。
在开发一个采购订单，具体采购订单的规则，请参考销售订单，其编码规则到系统设置查询。
采购订单需要用到供应链、产品，本次采购订单不用直接使用报价单，采购单价可修改，具体以你设计的为主。
采购订单审核完成后，采购订单可转为采购入库单。采购入库单过账后，会生成库存流水记录，在库存表也会存在。

以上功能，请你自己规划方案、规划后，直接用本项目的交互规范，进行开发，具体要放在哪个菜单、开发为什么样式、如何操作、业务逻辑是如何的，请你按你是供应链专家的角度自行设计、自己开发、自己测试，开发完成后，用本项目中的数据做演示数据，采购订单、采购入库、过账、供应商等每个至少有20条记录。

中间方案、开发过程不需要参与，请直接完成，中国不需要参与，如果分了多个任务，请逐步全部完成。 本项目有的规范、规则都可以直接使用。请开始。
