# 用户补充与批准决策（不可改写来源）

日期：2026-09-23 至 2026-09-24

用户要求整理并实现法人、仓库、统一物项、库存余额、入库单、库存流水与库存明细查询；库存流水查询页面延期。

用户批准全部推荐决策，包括：

- 以 `md_item` 统一产品与物料，迁移 `md_product` 及产品引用；业务表以 `item_code` 作为受约束引用键；
- 法人归属管理组织，一个仓库归属一个法人；
- 一张入库单只有一个仓库，只允许一次整体过账，不做部分过账；
- 已过账单据不可编辑，采用整单冲销纠错；草稿删除按作废处理；
- 调拨入库类型保留但在调拨出库完成前禁用；
- 单号规则为“前缀 + yyyyMMdd + 5 位日流水”，入库前缀 `RK`；
- 库存按法人、仓库、物项编码、批次保存；批次可空但空批次也必须唯一；
- 库存基本单位取物项基本单位；本期不做单位换算；
- 数量四位小数、单价六位小数、金额两位小数；金额按法人本位币、不含税；
- 状态为草稿、已过账、已冲销、已作废；
- 全单原子过账，重复请求幂等，并发不得丢失库存更新；
- `admin` 拥有全部动作，`viewer` 只读；
- 库存明细只读，支持查询、分页、视图配置和导出；
- 用户明确授权后续需求、Specification、Architecture、Tasks、实现与初步验证按推荐方案连续执行，不再逐项确认。

外部初稿原文保存在同目录 `mcrm-inbound-stock.md`，只作为来源证据，不直接作为当前态规格。
