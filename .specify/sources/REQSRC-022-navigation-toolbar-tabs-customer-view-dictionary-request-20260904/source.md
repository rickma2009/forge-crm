# 导航、顶部工具栏、多 Tab、客户列表、视图模板与数据字典需求

> 来源：Rick 在当前 Codex 任务中的直接需求  
> 日期：2026-09-04

## 需求原文

1.请将系统管理与其他菜单一样处理即可，系统管理放在最下面这个设计不用这样。

2.在菜单栏的右边，最上面类似一个toolbar的工具，该toolbar不会改变，一直存在。会显示一些通用的功能，比如：预警提醒、消息，显示当前用户，并可退出。 具体有哪些常用工具功能，可按系统以后开发设置。 可参考现在gf_scm 打开页面后的上面显示效果，不过不用它上面的搜索框

3.点击昨天菜单后，显示右边的页面为多tab页面的形式排列，可萃取显示gf_scm的效果。

4.页面模板可参考现在 gf_scm的客户列表页面：https://scssit.gz.cvte.cn/opportunities/customers

如果这个，关于查询框上的功能、页面视图配置的功能。都需要。

请直接读取关于视图配置、保存视图模板对应的页面，每个列表页面应该有默认的模板，全部读取 gf_scm 后台的表，请你确认该设计。并在demo创建一个客户列表，真实保存在数据库中，可进行demo的操作，字段使用：客户类别、客户编码、客户名称、客户简称、客户地址、当前状态、所属行业、客户等级、负责销售、备注等字段

其中：客户状态、所属行业、客户等级来自数据字典，需要构建数据字典，数据字典是系统的标准功能，这个可以直接参考gf_scm的数据字典设置功能迁移过来作为标准模板配置功能， 负责销售来自另外一个表员工信息表，员工信息表先不开发，针对客户需要选择的销售，暂时为一个可查询的下拉框即可。先不对接员工信息表。

以上信息也比较多了，请你按计划进行梳理后进行在demo系统开发。
