# 用户原始输入及逐轮确认

用户：在商机上添加一个功能按钮，新增报价单 ，如果在商机中添加了报价单，也是弹出此报价单页面，只是这个弹出页面已经有了默认是，默认是：按商机报价，且已选择中商机页面的商机。请结合以上需求看看还有无需要注意地方，使用 grilling。

第一轮建议：详情顶部新增按钮，商机报价列表入口保留；商机入口锁定关联模式/当前商机并展示客户；成功打开新报价详情页签保留商机页签，取消不生成。
用户：本轮按推荐

第二轮建议：ACTIVE 可新增、DISABLED 不可新增且可查历史，服务端重验；保留商机产品数量、单价及需求说明，折扣初始0，建议价独立，后续不互相同步；产品停用/缺单位/缺定价整单阻止并列问题，零产品可建草稿、提交前补明细。
用户：按建议

第三轮建议：一商机允许多报价，各自编号状态，重试幂等；弹窗打开后商机数据变更则提示重新核对，刷新后用户再次确认，不带未保存编辑。
用户：按建议

以上为三轮完整实施口径确认。
