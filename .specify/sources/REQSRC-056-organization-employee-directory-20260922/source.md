# 组织架构修复、树形工作区与员工管理

> 来源：用户对话与错误截图
> 日期：2026-09-22
> 授权：用户要求中途不确认，疑问采用建议方案，一次执行到开发完成；仅授权本地需求、设计、迁移、Seed、代码与验证，不代表 Release Gate。

## 原始需求摘录

- 修复组织架构页面严格契约错误。
- 组织架构改为类似资源菜单的左右布局：左侧组织树，右侧只展示组织基本信息，不使用多 Tab。
- 在系统管理的组织架构下方新增员工管理；员工使用与客户列表一致的查询、表格、新增与修改弹窗。
- 新增员工时所属部门必填，来源为组织架构。
- 字段遵循已评审《组织员工角色权限-方案设计.md》；组织与员工属于 `org_` 公共组织主数据。
- 初始化部件BG、TV事业部、电源事业部、财务部、供应链部；TV事业部下初始化销售一部、销售二部、销售管理部、TV研发中心。
- 按部门和岗位初始化员工，所有初始化员工均具有系统登录账号和角色访问资格。

## 增量决策

- 员工、账号、工号/雇佣和部门岗位任职保持分离，不把当前部门、岗位直接持久化到员工主体。
- 新增员工同时创建账号、主职任职、账号组织关系并加入受限演示角色；系统管理员仍只由角色授权获得能力。
- 联系方式在列表中脱敏，完整值仅在拥有员工维护权限的详情/编辑接口返回。
- 普通运行时不提供物理删除，停用保留历史与审计。
