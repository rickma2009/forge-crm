# 用户原始要求：表格统一规范

> 请整理约定在样式规范文件中：针对表格：表格默认行高在现在的基础上减少 2px，显示上下居中。默认第一列是序号；第2列是操作，如果是可操作的表格有第2列，否则忽略。第2列操作用图标，常见修改、删除、审核，其他操作依次往后排序，图标在样式文件中约定并在每个表格统一使用。第3列一般为对象关键字，主数据用编码，单据用单据编号；可进入明细或弹出页面时，编码列可点击且颜色与悬停样式一致。列宽不足默认不换行并以省略号显示；明确要求全部显示时按列换行，多行按内容增高；多个字段同列也按设计自动换行。请修改规范并检查、统一现有表格。
