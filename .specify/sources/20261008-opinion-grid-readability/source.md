# 舆情列表可读性与操作图标

- 日期：2026-10-08
- 来源：用户对舆情监控页面的截图反馈

## 原始要求

1. 点击事件编码展开内容后，详情不得覆盖事件标题等相邻列。
2. 后续表格应根据内容合理设置列宽，主题、标题、内容等字段需要更宽。
3. 声量和来源展示业务可读值，不显示内部编码；声量带数量单位，来源显示来源名称。
4. 操作列中不同处理动作不得重复使用相同的通用图标，按全局规范登记并使用语义图标。

## 实施边界

- 本次修复舆情事件、原始信息、来源接口和运行记录表格。
- 通用列宽和显示值原则、事件动作图标补充到全局样式规范。
- 不改变舆情事件状态机、权限、评分或采集逻辑。
