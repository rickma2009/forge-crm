# 物料来源、生命周期与引用值存储规则

日期：2026-10-05

用户原文：

> 物料产品表中，需要先在数据字典中添加：
> 物料来源：item_source，数据字典值：外购、自制、委外加工，保存数据字典编码，在列表显示时，关联数据字典，显示数据字典值
> 物料生命周期阶段：item_lifecycle, 数据字典值：初始、样品、试产、小批量、批量、即将退市、已退市、已作废
>
> 同时在，开发规范中，请注明，如果调用的是数据字典、或引用其他表的值，要保存：引用的编码， 不是保存名称。 每次关键在页面显示、列表显示时，需要关联数据字典或引用表的值或名称。如果是一旦初始化后不会编码的，可以保留名称，不用关联比如：员工姓名，可以在单据上保存员工编码、员工姓名，员工姓名不用关联，因为姓名不会改变。 但是如果：员工部门，则需要保存部门的编码，因为名称可能会改名。每次显示名称都要重新引用对应的新的部门。

## 转换说明

- 物料需新增“物料来源”和“物料生命周期阶段”，选项由数据字典维护；物料记录保存字典稳定编码，页面/列表展示时按当前字典值解析名称。
- 引用值规则按语义是否可变区分：稳定且初始化后不可变的名称（如员工姓名快照）可在单据保存；可变主数据关系（如员工部门）保存引用编码/标识，展示时重新解析最新名称。
- 具体物理列、字典项编码、存量物料默认值/回填、编辑权限、历史单据快照策略及失效引用行为尚待规格与 Architecture Gate 明确。
