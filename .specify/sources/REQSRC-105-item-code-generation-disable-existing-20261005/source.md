# 物料产品自动编码与既有数据停用

日期：2026-10-05  
来源类型：用户业务规则与数据处理指令  
状态：已批准实施

## 用户原文

> 有产品、物料、BOM的数据
> 1.以后手工进行产品、物料的编码，按新的编码规则，物料的编码规则是：物料大类.物料中类.7位流水， 其中7位流水是物料中类下物料的最大流水+1， 请将此规则写到，物料产品的编码规则的代码中。
>
> 将原来的产品、物料全部停用。

## 当前有效规则

- 在物料产品管理中手工新建记录时，编码由服务端生成，前端不接收人工输入的最终编码。
- 格式为“物料大类编码.物料中类编码.7位流水”，例如 `004.028.0000123`。
- 大类、中类编码取自当前系统启用的物料分类数据字典。中类字典值采用完整层级编码，例如 `004.028`；生成结果直接使用该中类完整编码加七位流水。
- 流水作用域为租户和物料中类。取该中类下全部历史物料产品编码的最大七位流水加一，停用记录也参与计算；没有历史记录时从 `0000001` 开始。
- 大类和中类为新建必填项，且必须保持父子关系；大类值必须为三位数字，中类值必须为对应“大类.三位数字”。编码生成后不可修改。
- 并发取号必须串行化，不能使用无锁“查询最大值再加一”；流水超过 `9999999` 时拒绝新建。
- 当前数据库中既有 `PRODUCT` 和 `MATERIAL` 记录全部改为停用；`SEMI_FINISHED` 和 BOM 数据不在本次停用范围内，历史关联不删除。
