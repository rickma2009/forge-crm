# 报价选择产品后保存失败

日期：2026-09-25

来源：用户缺陷反馈及随附截图。

## 原始现象

- 在报价单中添加产品后点击“保存草稿”。
- 页面显示“服务暂时不可用”，草稿保持未保存状态。
- 截图对应报价单号为 `Q2026092500000003`。

## 用户期望

- 从当前产品选择列表加入的有效产品应能正常保存到报价明细。
- 保存失败时不得只显示无法定位原因的通用错误。

## 调查事实

- 产品选择和服务端有效性校验均以 `md_item` 为权威主数据。
- `sd_quotation_line` 同时存在新的 `sd_quote_line_item_fk` 与遗留的 `sd_quote_line_product_fk`；后者仍引用旧表 `md_product`。
- 本地 6 个启用产品中，`MLJ001`、`P001` 只存在于 `md_item`，不存在于 `md_product`；写入这两项时触发旧外键拒绝并被异常过滤器映射成 503。
- 同类遗留外键还存在于 `sd_product_price` 和 `sd_opp_product`，与当前 `md_item` 权威模型冲突。
