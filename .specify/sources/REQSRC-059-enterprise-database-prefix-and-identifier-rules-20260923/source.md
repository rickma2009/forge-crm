# 企业数据库域前缀与标识符长度规则

> 来源：用户于 2026-09-23 提交的数据库治理决定。
> 本决定覆盖 `REQSRC-043` 中与主数据和业务表前缀冲突的旧结论。

1. 企业共享主数据统一使用 `md_` 前缀。
2. 销售域统一使用 `sd_` 前缀。
3. 采购、库存、生产统一归入供应链制造域，使用 `scm_` 前缀。
4. 研发域统一使用 `rd_` 前缀。
5. 财务域统一使用 `fin_` 前缀。
6. 所有物理表名和物理字段名统一使用小写 `snake_case`。
7. 所有物理表名和物理字段名均不得超过 32 个字符。
8. 上述规则写入项目 `AGENTS.md` 和数据库规范，作为后续建表约束。

`sys_`、`org_`、`int_`、`stg_`、`dim_`、`fact_` 保留其既有平台、组织、集成、暂存和分析职责；`dim_` 不再与共享主数据混用。
