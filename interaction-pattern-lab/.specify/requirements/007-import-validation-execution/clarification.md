# Business Clarification：导入—校验—执行

| ID | 问题 | 推荐答案 | Gate 影响 |
|---|---|---|---|
| `Q-1101` | 首轮导入对象 | 中性“资源记录”，字段覆盖文本、枚举、日期、数量和唯一编码 | 避免绑定 CRM/订单业务 |
| `Q-1102` | 首轮文件格式 | 首轮支持 `.xlsx`；CSV 作为后续兼容项 | 限定体验范围，具体解析留给 Architecture |
| `Q-1103` | 错误存在时是否可执行 | 默认阻断；具备显式能力的角色可选择仅执行通过项 | 关键安全边界 |
| `Q-1104` | 警告如何处理 | 警告不阻断，但执行确认中单独计数并可逐项查看 | 防止警告被成功数吞没 |
| `Q-1105` | 执行模型 | 确认后统一创建异步任务，即使小文件也保持一致状态机 | 降低双路径认知差异 |
| `Q-1106` | 取消 | 只允许取消排队中的任务；运行后不可假装能撤销 | 避免虚假回滚承诺 |
| `Q-1107` | 重试 | 不原地重跑；修复后创建关联新任务 | 保留审计与结果可解释性 |
| `Q-1108` | 错误下载 | 下载与当前任务版本绑定，含源行、字段、错误码和修复建议 | Specification 再定文件列 |
| `Q-1109` | Demo 持久化 | 使用确定性本地任务适配器；刷新恢复仅在明确声明的会话边界内 | 不伪装生产队列/存储 |
| `Q-1110` | 价值验证 | 与 `BUS-003` 合并观察：至少 3 次、2 类角色，不设虚构提升比例 | 业务证据不足则 pending |

当前全部为推荐草案。只有用户明确批准 Business Gate 后，才能作为已决策业务边界进入切片 011 Specification。
