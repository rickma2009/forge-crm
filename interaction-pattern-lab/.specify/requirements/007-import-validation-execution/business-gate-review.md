# Business Gate 评审包：导入—校验—执行

> 状态：`ready-for-review`
>
> 拟议切片：`011-import-validation-execution`
>
> 来源：`REQSRC-036`

## 1. 请求决定

请求决定是否批准 `BUS-017` 及 `Q-1101`—`Q-1110` 的推荐答案，允许进入切片 011 的 Specification 与测试设计。

## 2. 建议批准范围

- 目标：让批量导入的上传、解析、校验、确认、执行和结果可区分、可定位、可恢复；
- 角色：业务操作员、数据维护者、只读审核/支持人员；
- 场景：中性资源记录、首轮 `.xlsx`、字段映射、四类校验、异步任务和错误下载；
- 安全默认：错误默认阻断，部分执行需要显式能力和二次确认；
- 价值验证：结合 `BUS-003` 完成至少三次、两类角色观察，不预设提升比例。

## 3. 明确不包含

- 精确字段 Schema、行数/大小阈值、错误文件列和所有验收用例；
- 上传/解析库、队列、数据库、对象存储和 API 设计；
- Plan、Tasks、实现、外部部署或 Release；
- 生产系统连接、MCRM 恢复、资产晋升；
- 对切片 002 Release Gate 的任何替代或继承。

## 4. 风险与停止条件

- 如果首轮同时覆盖多格式、超大文件、真实队列和生产安全，将失去最小验证目标；
- 如果无法明确部分执行权限和失败恢复，停在 Specification Gate 前；
- 如果观察任务不能证明用户区分各阶段，保留反例并重新设计，不晋升为通用模式。

## 5. 建议决定

建议：`approve-business-scope-and-recommended-clarifications`。

批准后允许创建切片 011 的 `spec.md`、验收标准和 `testcases.md`，并停在 Specification Gate；不自动批准后续 Gate。
