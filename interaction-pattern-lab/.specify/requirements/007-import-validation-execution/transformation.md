# 来源转换：导入—校验—执行

## 1. 来源事实

- `REQSRC-036` 要求在稳定迁移基线后开启新切片；
- 既有工作台账把“导入—校验—执行”登记为下一候选，关注异步任务、映射、部分成功和失败下载；
- 切片 002 已验证同步批量选择、预检查和部分成功，但仍等待其独立 Release Gate。

## 2. 支持推断

- 新切片应复用切片 002 已验证的“范围显式、失败可定位、结果可复核”原则，但不能继承切片 002 的 Release 状态；
- 为避免把某个业务字段固化为通用事实，首轮应使用中性合成记录和显式 Demo Adapter；
- “上传成功”不能代表“业务数据写入成功”，需要拆开解析、校验、确认、执行和结果阶段。

## 3. Business Gate 前未知及处理结果

- 文件格式已由 `Q-1102` 确认为首轮 `.xlsx`；大小、行数和多工作表边界进入 Specification 草案；
- `Q-1103` 已确认错误默认阻断，显式授权后才允许只执行通过项；
- `Q-1105`—`Q-1107` 已确认统一异步任务、仅排队可取消、重试新建关联任务；重复确认行为进入 Specification 草案；
- `Q-1108` 已确认错误结果与任务版本绑定；具体下载列和 Demo 会话边界进入 Specification 草案；
- 字段映射、枚举、日期、数量和跨行唯一性已形成 Specification 推荐规则，尚待其独立 Gate。

## 4. 本次建议

`Q-1101`—`Q-1110` 已由 `REQSRC-037` 批准。切片 011 Specification 草案据此固化可观察行为和首轮验证阈值；仍不选择上传库、解析库、队列、数据库或对象存储。

## 5. 冲突与影响

- 不改变切片 002 的 Gate 或成熟度；
- 不修改切片 006 已有字典 Excel 导入业务；二者只可共享候选交互原则，不能静默共用实现；
- 不改变切片 010 或任何 EPM 资产成熟度；
- 不涉及已暂停的 MCRM。
