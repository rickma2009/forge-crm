# 来源转换：导入—校验—执行

## 1. 来源事实

- `REQSRC-036` 要求在稳定迁移基线后开启新切片；
- 既有工作台账把“导入—校验—执行”登记为下一候选，关注异步任务、映射、部分成功和失败下载；
- 切片 002 已验证同步批量选择、预检查和部分成功，但仍等待其独立 Release Gate。

## 2. 支持推断

- 新切片应复用切片 002 已验证的“范围显式、失败可定位、结果可复核”原则，但不能继承切片 002 的 Release 状态；
- 为避免把某个业务字段固化为通用事实，首轮应使用中性合成记录和显式 Demo Adapter；
- “上传成功”不能代表“业务数据写入成功”，需要拆开解析、校验、确认、执行和结果阶段。

## 3. 当前未知

- 文件格式、大小和行数上限；
- 是否允许在存在错误行时只执行通过项；
- 异步阈值、取消窗口、幂等与重试规则；
- 错误结果保留时间、下载格式和脱敏要求；
- 首轮是否需要字段转换、枚举映射和跨行唯一性校验。

## 4. 本次建议

将上述未知项以 `Q-1101`—`Q-1110` 进入 Business Gate。批准后再由 Specification 固化精确行为和阈值；本需求包不选择上传库、解析库、队列、数据库或对象存储。

## 5. 冲突与影响

- 不改变切片 002 的 Gate 或成熟度；
- 不修改切片 006 已有字典 Excel 导入业务；二者只可共享候选交互原则，不能静默共用实现；
- 不改变切片 010 或任何 EPM 资产成熟度；
- 不涉及已暂停的 MCRM。
