# 企业交互模式验证场业务需求

> 版本：1.0-rc1
> 状态：business-gate-approved
> 权威来源：`REQSRC-007`、`REQSRC-008`

## 1. 定位与业务成果

本项目是 SDD Forge 内的企业交互模式验证场。它将企业管理系统常见页面、操作、展示、状态、特殊操作和组合场景组织成可检索目录，并通过少量可运行交互演示验证关键行为，为 `_methodology/` 的模式资产提供证据。

它不是模板规范源、真实业务系统、低代码平台或 99 个成熟页面的合集。

| ID | 业务成果 | 当前基线 | 本阶段目标 | 证据 |
|---|---|---|---|---|
| `BUS-001` | 建立完整可浏览的企业交互分类目录 | 99 个分类项在 Markdown，Lab 只投影 2 项 | 99/99 分类项可检索且状态真实 | 资产索引、投影检查、浏览器任务 |
| `BUS-002` | 让使用者理解模式行为与边界 | 2 个历史 Demo，状态文案存在混称 | 每项显示定义、成熟度、覆盖关系和证据缺口；有 Demo 时可体验 | 自动检查、人工评审 |
| `BUS-003` | 建立后续效率改善基线 | 无真实任务基线 | 至少记录 3 次观察任务并覆盖 2 类目标角色；不足时保持 pending | 任务记录，不预设提升比例 |
| `BUS-004` | 走通新增场景验证闭环 | 只有两个历史样本 | 完成一个批量选择与部分成功验证切片 | 来源、Spec、测试、浏览器证据和晋升评审 |

## 2. 用户与核心任务

第一目标用户是产品经理和需求分析人员；UI/交互设计人员与前端开发人员是兼顾用户。

核心任务链：

```text
查找分类项
→ 查看定义、成熟度和证据缺口
→ 有交互演示时体验关键状态
→ 判断是否适用
→ 把采用、调整或拒绝结论带回目标项目 Spec
```

验证场只能辅助判断，不能替目标项目批准业务规则。

## 5. 首个新增验证切片

切片候选固定为：`002-bulk-assignment-partial-success`。

本阶段不新增 `EPM-SCENE-008`。切片引用现有分类项，包括查询列表、筛选、责任分配、批量变更、批量选择、部分成功和批量特殊操作；验证完成后再评审是否形成独立组合模式。

### 5.1 用户流程

```text
查询记录
→ 默认选择当前页，或显式选择当前查询全部 N 条
→ 选择目标负责人
→ 预检查并区分可执行与拒绝项
→ 用户确认本次对象快照
→ 同步执行
→ 展示成功、失败与未处理范围
→ 保留失败项供修正或重试
```

### 5.2 业务规则

| ID | 规则 |
|---|---|
| `REQ-213` | “当前页全选”和“全部查询结果”是不同选择范围；默认只选择当前页 |
| `REQ-214` | 升级为全部查询结果必须显式操作，并持续展示对象数量与查询范围 |
| `REQ-215` | 查询条件改变时必须清除原选择并反馈原因，避免把旧范围静默用于新查询 |
| `REQ-216` | 预检查必须逐项给出可执行或拒绝结果；演示拒绝原因至少包含无权限、记录锁定、状态不兼容或负责人不可用中的代表性情形 |
| `REQ-217` | 确认内容绑定预检查后的对象快照；取消确认不得改变数据 |
| `REQ-218` | 执行结果必须区分全部成功、部分成功、系统失败和未处理范围 |
| `REQ-219` | 首片采用同步确定性执行；异步进度、通知和离开后查询属于后续“导入—校验—执行”切片 |

### 5.3 最低状态覆盖

| ID | 必须演示的状态 |
|---|---|
| `AC-201` | 初始、加载、无数据和未选择记录 |
| `AC-202` | 当前页选择、全部查询结果选择及作用范围提示 |
| `AC-203` | 预检查全部通过与部分拒绝 |
| `AC-204` | 用户取消确认且数据不变 |
| `AC-205` | 执行全部成功、部分成功和系统失败可重试 |
| `AC-206` | 修改查询后清除选择并反馈 |
| `AC-207` | 键盘完成选择、预检查、确认、结果查看和重置 |

上述验收只证明交互演示行为，不证明真实服务端权限、事务、并发或业务采用。

## 7. 范围边界

### In Scope

- 99 项权威资产索引和 Lab 展示投影；
- 六类目录、子分组、搜索和两类简单筛选；
- 无 Demo 状态、真实成熟度与覆盖关系展示；
- `002-bulk-assignment-partial-success` 验证切片；
- 场景契约、自动检查和浏览器证据；
- BUS-003 观察任务基线。

### Out of Scope

- 一次性把 99 项全部制作成 Demo、pattern 或模板；
- 真实后端、生产接口、业务数据库、账号与在线编辑后台；
- 异步导入、审批状态机、规则发布和外部同步；
- 收藏、比较、复杂标签、保存视图和源码复制；
- 自动决定目标项目采用或自动晋升方法论资产；
- 把 Lab 样式定义为所有企业项目必须采用的 UI 标准。
