# 原型输入：企业交互模式工作台 / 首个纵向切片

> 状态：Specification Gate 已批准  
> 关联页面：`PAGE-001`  
> 关联功能：`FR-001`—`FR-005`  
> 关联验收：`AC-001`—`AC-011`

## 1. 原型目标

用一个桌面优先的工作台演示“发现模式—体验交互—阅读总结—重置状态”。原型不得补造在线编辑、账户、业务数据保存、方案比较或自动生成能力。

## 2. 信息架构

```text
企业交互模式工作台
├── 页面头：名称 + 一句话用途
├── 模式目录
│   ├── 关键词搜索
│   ├── 导航与壳层
│   │   └── EPM-PAGE-001 企业双层导航壳层
│   └── 组合场景
│       └── EPM-SCENE-001 查询—新增—详情
└── 当前模式
    ├── 模式头：名称 + 编号 + validated-once + 重置
    ├── 交互原型
    └── 模式说明
```

## 3. 布局要求

- 桌面宽屏采用左侧目录、右侧工作区；
- 页面头保持紧凑，不使用营销式主视觉、装饰性指标或无业务意义插画；
- 左侧目录能够独立滚动，当前项具备文字之外的清晰选中反馈；
- 右侧模式头在切换页签时保持可见，重置操作位置稳定；
- “交互原型 / 模式说明”使用同一级页签，默认打开交互原型；
- 窄屏允许改为先目录后内容或可关闭目录，但必须保证可返回、可关闭和焦点恢复。

## 4. 组件与内容

| 区域 | 组件 | 必须内容 | 主要状态 |
|---|---|---|---|
| 目录 | 搜索框 | 占位说明、清空操作、结果数量可选 | 默认、输入、无结果 |
| 目录 | 分类分组 | 分类名称、模式条目 | 展开、当前选中 |
| 目录 | 模式条目 | 名称、编号、验证状态 | 默认、悬停、聚焦、选中 |
| 模式头 | 标题与标签 | 名称、分类编号、`validated-once` | 正常、资产不完整 |
| 模式头 | 重置 | “重置 Demo”及可访问名称 | 可用、执行反馈 |
| 原型页签 | 案例容器 | 当前模式可点击案例 | 加载、可用、失败、重试 |
| 说明页签 | 总结区 | 问题、适用/不适用、行为、状态、风险、来源、证据 | 完整、待复核 |

## 5. 种子案例声明

### 企业双层导航壳层

- 展开和收起一级分组；
- 搜索菜单并保留匹配上下文；
- 折叠和恢复导航；
- 展示当前导航项反馈；
- 不宣称真实权限或后端搜索已经接通。

### 查询—新增—详情记录工作区

- 输入查询条件并查看结果变化；
- 重置查询；
- 打开新增页签；
- 打开详情页签；
- 切换和关闭业务页签；
- 不保存新建数据，不宣称完整 CRUD 已接通。

## 6. 模式说明顺序

1. 解决的问题；
2. 适用场景；
3. 不适用场景；
4. 页面结构；
5. 主要操作及结果；
6. 加载、空、错误和特殊状态；
7. 风险与不可复用项；
8. 来源与验证证据；
9. 当前验证状态及其含义。

## 7. 原型验收重点

- 目录、模式头、原型和说明始终处于同一模式上下文；
- 两个种子案例的声明交互均可实际操作；
- 重置后恢复预置状态；
- 原型失败不阻断说明阅读；
- 键盘可以完成核心路径；
- 原型工具不得增加未经 Spec 确认的字段、按钮、状态或流程。
