## 已批准业务基线

- 第一目标用户：产品/需求分析人员，兼顾设计和前端；
- 首批模式：企业双层导航壳层、记录管理工作区；
- 左侧：分类和关键词搜索；
- 右侧：“交互原型 / 模式说明”两个页签；
- 数据：Demo 操作不持久化，模式资产通过 Git 管理；
- 终端：桌面端优先，窄屏保证可恢复使用；
- 首期不做：多方案比较、源码/配置复制、在线内容编辑、Open Design 自动生成。
