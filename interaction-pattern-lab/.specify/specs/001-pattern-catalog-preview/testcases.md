# 测试用例：模式目录与交互预览

> 功能编号：001-pattern-catalog-preview  
> 本文描述计划行为和 2026-08-30 的真实执行结果；原 Release Gate 已批准，`REQSRC-006` 增量修改已重新构建和验收。

## 1. 测试策略

- 核心旅程：打开工作台 → 搜索/选择模式 → 操作原型 → 查看说明 → 重置；
- 主要风险：上下文错配、案例状态残留、伪持久化、原型失败拖垮工作台、键盘不可用；
- 计划层次：目录与状态逻辑自动化测试、页面集成测试、真实浏览器端到端与网络检查。
