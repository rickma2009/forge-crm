# Feature Specification: 统一导航、常驻工具栏与多页签工作区

| 项目 | 内容 |
|---|---|
| Feature ID | `005-unified-navigation-toolbar-tab-workspace` |
| 来源功能 | `FR-501`—`FR-503` |
| 状态 | `approved-by-REQSRC-023-default-authorization` |
| 结果 | 将 004 双区导航升级为单树，并提供无搜索框的常驻工具栏和 URL 多页签 |

## 功能规格

- `REQ-501`：导航 API 返回一个 `items` 数组；所有分组/页面按父级、`sortNo`、编码稳定排序，不再返回 `primary/management`。
- `REQ-502`：“系统管理”是普通分组，无特殊区域、名称判断或权限判断。
- `REQ-503`：顶栏始终位于工作区顶部；预警、消息显示真实空态，显示当前用户并可退出；不提供全局搜索。
- `REQ-504`：点击页面菜单打开或激活页签；首页不可关闭；其他页签支持刷新、关闭当前、关闭其他、关闭右侧和关闭全部。
- `REQ-505`：URL 决定激活页签；最多 12 个，超限拒绝新开；页签切换保留会话内页面状态。
- `NFR-501`：菜单和页面访问继续由切片 004 的服务端角色授权；空授权、403、404、503 均失败关闭。

## 验收条件

- `AC-501`：API 与 UI 仅呈现统一菜单树，系统管理按普通排序出现。
- `AC-502`：工具栏跨页面常驻、无全局搜索；空提醒明确，当前用户和退出来自真实会话。
- `AC-503`：页签打开、激活、刷新、批量关闭、URL 同步和 12 个上限符合规格，未授权页面不得形成可访问页签。

## Gate

Specification Gate：用户已在 `REQSRC-023` 明确授权后续需求与方案按推荐/默认值自动确认，本规格采用 `Q-501`—`Q-504` 已批准推荐答案。
