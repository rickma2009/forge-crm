# 测试用例：认证式企业导航壳层

> 功能编号：003
> 状态：`historical-frontend-boundary-verified / new-target-not-run`
> 组件、契约、工程和浏览器结果只证明原纯前端边界；`REQSRC-017` 的数据库/后端目标尚未生成新版测试设计或执行。

## 1. 测试策略

- 核心旅程：选择身份 → 进入概览 → 浏览/搜索两区菜单 → 折叠导航 → 打开页面 → 验证管理员或受限权限 → 退出/重置；
- 主要风险：复刻视觉时带入来源业务、底部管理区被滚动隐藏、隐藏菜单被搜索泄露、路由与按钮权限不一致、说明页冒充真实 Demo、刷新后残留身份或页面内容；
- 测试层次：菜单与权限契约、状态行为、页面集成、真实浏览器键盘/视觉/网络/存储任务。工具选择留给 Architecture Gate。
