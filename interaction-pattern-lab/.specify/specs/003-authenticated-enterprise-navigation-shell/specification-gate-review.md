## 1. 本次批准范围

本 Gate 只批准切片 003 的用户故事、菜单层级、视觉密度、默认状态、搜索、展开/折叠、说明页与真实验证页边界、`admin/viewer` 可观察权限结果、失败行为、非功能要求和测试设计。

本 Gate 不批准状态管理、菜单/页面/capability Schema、组件结构、路由实现、图标库、测试框架、Plan、Tasks、页面代码、资产晋升、部署或 Release。

## 2. 决策摘要

| 决策 | 待批准方案 |
|---|---|
| 默认密度 | 展开 220px、折叠 64px、菜单项 34px；首片不做密度切换 |
| 默认展开 | 概览激活，主分组折叠，系统管理展开；进入子页展开祖先 |
| 菜单结构 | 上方七类通用资产入口；底部六项系统管理入口 |
| `admin` | 统一角色绑定覆盖当前登记的全部页面与操作 |
| `viewer` | 上方菜单全可见；系统管理仅资源目录；资源只读，维护/导出禁用；其他管理直达拒绝 |
| 登录 | 无密码的演示身份输入；明示非生产认证；退出、刷新、重置回身份页 |
| 页面覆盖 | 概览和资源目录为本切片验证页；其余为诚实的 description-only 页面 |
| 滚动 | 主菜单主滚动；系统管理锚定底部、最多占可用高度 45% 并可独立滚动 |

## 4. 风险与控制

| 风险 | 规格控制 |
|---|---|
| 视觉复刻误带来源业务 | 菜单和运行文案中性化；来源只在证据链出现 |
| 前端权限被误解为生产安全 | 身份页和权限说明持续明示模拟边界 |
| 隐藏菜单通过搜索或错误页泄露 | 权限过滤先于搜索；forbidden 与 not-found 分离且不展示受限内容 |
| 占位页面被误认为已实现 | 使用 `description-only` 并显示“互动演示未接入” |
| 底部管理区挤占导航 | 45% 高度上限和独立滚动规则 |
| 首片扩大成完整后台 | 只有概览与资源目录承担真实验证行为 |
