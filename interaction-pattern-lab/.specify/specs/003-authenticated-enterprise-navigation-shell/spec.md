# 功能规格：认证式企业导航壳层

> 功能编号：003
> 状态：`specification-approved-awaiting-architecture-gate`
> Spec Gate：approved（`REQSRC-015`）

## 1. 目标与范围

- 关联业务目标：`BUS-006`、`BUS-007`、`BUS-008`；
- 目标：让产品、设计和前端人员以两类模拟身份浏览一个来源可追溯但运行文案中性的企业导航壳层，并可观察菜单、路由、页面和操作级权限的一致结果；
- In Scope：模拟身份选择、深色桌面导航、通用主菜单、底部系统管理、搜索、展开、折叠、激活、说明页、无权页、只读资源目录和权限反馈；
- Out of Scope：真实认证/IAM、远程菜单接口、业务数据库、全部页面 Demo、移动端适配、资产晋升、部署与 Release。

## 2. 用户故事

### US-401 以演示身份进入门户

作为模式评审者，我希望明确选择 `admin` 或 `viewer` 进入，以便在不误解为生产认证的前提下重复验证权限差异。

### US-402 从稳定导航发现资产

作为产品或设计人员，我希望通过搜索、层级菜单和固定的系统管理入口定位页面，以便在菜单较多时仍能快速发现目标。

### US-403 验证管理员完整访问

作为 Demo 管理员，我希望 `admin` 能访问当前登记的所有菜单、页面和操作，以便确认新增能力不会遗漏管理员绑定。

### US-404 验证受限用户反例

作为权限方案评审者，我希望 `viewer` 能显示真实的隐藏、拒绝、只读和操作禁用结果，以便检查四层权限没有互相矛盾。

### US-405 判断页面是否真正具备 Demo

作为页面资产使用者，我希望入口能区分说明页与互动演示，以便不把尚未实现的页面误判为可复用成品。

## 4. 业务规则与状态

### 4.1 身份状态

```text
身份选择页
  → 输入 admin / viewer
  → 有效：进入概览
  → 无效：停留并显示错误

门户
  → 退出 / 刷新 / 重置演示
  → 返回身份选择页
```

- 账号名不区分大小写，输入前后空格忽略；
- 不收集或模拟密码，不出现“安全登录成功”等生产认证措辞；
- 身份切换必须先结束当前演示身份，不在同一页面静默换权。

### 4.2 菜单与展开状态

- 初始页面为“概览”；主菜单各分组折叠，“系统管理”展开；
- 用户手动展开或收起分组时不改变当前路由；进入子页面时其祖先必须展开；
- 搜索是临时发现状态，清空后恢复搜索前的展开状态；
- 系统管理没有任何可见子项时整个分组隐藏；只剩一个可见子项时仍保留分组和分隔线；
- 展开态和折叠态共享同一当前页面、菜单可见性和激活语义。

### 4.3 身份—能力结果矩阵

| 可观察对象 | `admin` | `viewer` |
|---|---|---|
| 全部主菜单说明页 | 可见、可访问 | 可见、可访问 |
| 用户/角色/策略/菜单/日志 | 可见、可访问说明页 | 菜单隐藏；直接路由拒绝 |
| 资源目录 | 可见、可维护、可导出 | 可见、只读 |
| 资源维护与导出操作 | 可执行并产生确定性 Demo 反馈 | 可见但禁用，解释权限不足 |
| 未知路由 | 未找到页 | 未找到页 |

### 4.4 页面覆盖状态

- `interactive-slice`：本切片可执行并有验收行为，仅用于“概览”和“资源目录”；
- `description-only`：可路由、可读，但明确没有互动演示；
- `forbidden`：身份已识别但缺少页面访问能力；
- `not-found`：路由未登记；不得与 `forbidden` 混用。

## 7. 边界与异常

| 场景 | 预期业务行为 |
|---|---|
| 菜单数据缺少稳定标识、名称、目标或能力声明 | 阻止不完整节点进入可用导航并显示可诊断的本地配置错误；不得猜测补全 |
| 当前身份没有任何系统管理子项 | 隐藏整个底部分组和分隔线，主菜单获得剩余空间 |
| 搜索命中隐藏菜单 | 不返回、不计数、不显示祖先或关键词提示 |
| 直接访问无权页面 | 显示通用无权状态，不短暂闪现页面内容，不降级成未找到 |
| 访问未知路径 | 显示未找到状态，不暗示该路径是否属于隐藏资源 |
| 折叠态浮层失焦或按 Escape | 关闭浮层并把焦点返回触发控件 |
| 窗口高度不足 | 主菜单和系统管理分别滚动；品牌、搜索和折叠控制仍可操作 |
| 页面尚无互动 Demo | 展示说明、成熟度和下一证据，不显示可执行的伪操作 |
| 模拟操作失败 | 显示确定性失败反馈且不改变资源状态；仍强调非生产演示 |
