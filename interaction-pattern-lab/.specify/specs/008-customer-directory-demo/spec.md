# Feature Specification: 客户目录数据库 Demo

| 项目 | 内容 |
|---|---|
| Feature ID | `008-customer-directory-demo` |
| 来源功能 | `FR-508`—`FR-510` |
| 状态 | `approved-by-REQSRC-023-default-authorization` |

- `REQ-801`：客户字段为类别、编码、名称、简称、地址、状态、行业、等级、负责销售、备注。
- `REQ-802`：关键词查询编码/名称/简称；类别、状态、行业、等级、销售可筛选；服务端分页和排序。
- `REQ-803`：admin 可新增、编辑、查看；viewer 只可查询和查看；无客户删除。
- `REQ-804`：编码由服务端生成 `CYYYYMM####` 并保证唯一；名称唯一、简称可重复。
- `REQ-805`：名称、简称、类别、状态必填；字典值必须属于正确字典并可用于新录入。
- `REQ-806`：销售由后端搜索 Provider 返回，保存 key/name 快照，不建员工表。
- `NFR-801`：写入和查询只使用验证场 PostgreSQL，重启后保留；写操作继续执行会话、CSRF、角色授权和乐观并发校验。

## 验收标准

- `AC-507`：客户查询、分页、详情、新增和编辑读写验证场 PostgreSQL，重查后结果稳定。
- `AC-508`：类别、状态、行业和等级来自数据库字典；负责销售来自受控 Provider。
- `AC-509`：admin 可新增和编辑，viewer 只读；绕过前端写入仍由服务端拒绝且数据不变。

Gate 由 `REQSRC-023` 对 `Q-505`—`Q-508` 推荐值的明确授权覆盖。

## 2026-09-04 增量：紧凑列表工作区（REQSRC-024）

- `REQ-807`（`FR-511`）：客户页移除大标题区，内容左右留白采用紧凑工作区间距。
- `REQ-808`（`FR-512`）：查询栏由视图字段声明驱动；收起时保持单行且最多显示 3 个条件，其余进入带数量的“更多”，查询与重置显式提交。
- `REQ-809`（`FR-513`）：列表功能区左侧承载新增，右侧依次承载当前视图、视图选择、设置、总数和刷新；默认解析数据库中的角色系统视图。
- `REQ-810`（`FR-514`）：表格固定语义列顺序为“序号、操作、业务列”；序号居中，操作按 `allowedActions` 收窄，客户编码点击默认打开查看。
- `REQ-811`（`FR-515`）：视图设置弹窗允许基于角色系统视图另存个人视图，个人视图不得扩大角色基线。
- `REQ-812`（`FR-516`）：顶部用户入口显示会话登录账号，文本槽位最多 5 个汉字宽度，超长时省略并保留完整值提示。

增量 Specification/Architecture/Release Gate 依 `REQSRC-023` 的后续默认授权执行；不改变数据库实体、服务端授权边界或客户业务规则。
