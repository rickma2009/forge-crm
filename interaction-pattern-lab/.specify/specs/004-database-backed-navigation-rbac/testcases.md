# 测试用例：数据库驱动的导航与角色授权

> 功能编号：004
> 状态：`executed-release-gate-approved`
> 执行详情与证据见 `implementation-evidence.md`；Release Gate 由 `REQSRC-021` 批准。

## 1. 测试策略

- 核心旅程：认证 → 选择目标系统 → 获取角色授权导航 → 打开获准页面 → 执行获准/拒绝操作；
- 主要风险：客户端伪造身份、跨系统泄漏、管理员账号旁路、父菜单隐式授权、搜索泄漏、前端禁用替代服务端授权、权限变更后继续使用旧结果、故障时默认放行；
- 测试层次：授权契约、数据约束、API 集成、前端集成、迁移/种子、真实浏览器与性能测试；具体工具和环境由 Architecture Gate 固定。

## 2. 身份、系统与角色链

| ID | 类型 | 关联 AC/NFR | Given | When | Then | 优先级 |
|---|---|---|---|---|---|---|
| `TC-501` | API/integration | `AC-501`、`NFR-501` | 有效登录会话和 `demo-portal` | 请求导航且客户端不传 userId | 服务端从会话确定用户并返回该系统授权结果 | P0 |
| `TC-502` | API/security | `REQ-501`、`REQ-502` | 未登录、缺少/畸形/未知 systemCode，或客户端伪造 userId | 请求导航 | 分别返回 401 或系统上下文错误；伪造 userId 不改变身份 | P0 |
| `TC-503` | integration | `AC-501`、`NFR-502` | admin 只属于 `demo-portal` 系统管理角色 | 请求 `demo-portal` 与 `secondary-demo` | 前者返回完整显式授权树；后者 403 且无元数据 | P0 |
| `TC-504` | integration | `AC-502`、`NFR-502` | viewer 只有 `demo-portal` 的 viewer-role | 请求、浏览和搜索导航 | 应用菜单完整，管理区仅资源目录；隐藏标题、关键词、数量和角色名均不泄漏 | P0 |
| `TC-505` | contract | `REQ-503`、`REQ-504` | 一个用户在同系统有多个有效角色 | 请求授权结果 | 只合并有效 ALLOW grant；不存在用户直授权或账号特判 | P0 |

## 3. 菜单树与操作授权

| ID | 类型 | 关联 AC/NFR | Given | When | Then | 优先级 |
|---|---|---|---|---|---|---|
| `TC-506` | contract | `REQ-505`、`REQ-506` | GROUP 下混有获准和未获准 PAGE | 构建双区导航树 | GROUP 仅保留可见后代且不向后代传播权限；空 GROUP 被移除 | P0 |
| `TC-507` | API/integration | `AC-503`、`NFR-501` | viewer 有资源目录 MENU+VIEW，无 manage/export | 获取页面和 allowedActions | 页面可读，只返回 VIEW；管理与导出不进入允许操作 | P0 |
| `TC-508` | API/security | `AC-503`、`NFR-501` | viewer 直接调用 manage/export | 绕过前端提交操作 | 服务端返回 403，业务状态零变更，响应不泄漏隐藏信息 | P0 |
| `TC-509` | integration | `AC-504` | admin 当前仅通过 system-manager 获权 | 删除其有效成员关系后再次请求 | admin 不再获得权限，用户名不产生旁路 | P0 |
| `TC-510` | migration/contract | `AC-505`、`NFR-505` | 同一版本新增菜单与操作 | 未补系统角色 grant 后校验，再补齐 | 首次失败且不进入运行态；补齐后 admin 下一请求可见 | P0 |

## 4. 变化、故障与回归

| ID | 类型 | 关联 AC/NFR | Given | When | Then | 优先级 |
|---|---|---|---|---|---|---|
| `TC-511` | integration | `AC-506`、`NFR-503` | 菜单、操作、角色、成员或 grant 当前有效 | 分别停用或令其过期后发起下一请求 | 对应权限立即不再生效，不继续返回旧结果 | P0 |
| `TC-512` | resilience | `AC-507`、`REQ-513` | 数据库或权限服务不可用 | 请求导航或写操作 | 返回 503；前端可重试；不显示全部且写操作不成功 | P0 |
| `TC-513` | migration | `NFR-505` | 空数据库 | 执行迁移和种子 | 六类逻辑表及中性初始数据原子建立；失败整体回滚 | P0 |
| `TC-514` | browser | `AC-508`、`NFR-506` | 1440×900、1280×800 和低高度视口 | admin/viewer 完成登录、搜索、折叠、键盘与拒绝旅程 | 双区布局和既有可访问行为保持，隐藏项不闪现 | P0 |
| `TC-515` | performance | `NFR-504` | Architecture 固定的数据量与环境 | 采样导航读取 | P95 不高于 300ms，且结果正确 | P1 |

## 5. 边界与反例

| ID | 关联项 | 场景 | 期望结果 |
|---|---|---|---|
| `TC-EDGE-501` | `BR-501`、`NFR-502` | 角色、菜单、操作或 grant 跨 systemCode 关联 | 写入/种子校验失败，运行时不返回交叉数据 |
| `TC-EDGE-502` | `REQ-506` | 菜单父子形成环、父节点无效或 PAGE 被挂到错误分区 | 配置校验失败，不返回不确定树 |
| `TC-EDGE-503` | `REQ-507` | 角色只有 ACTION grant，没有所属页面 MENU grant | 页面和操作均拒绝 |
| `TC-EDGE-504` | `REQ-508` | 请求已登记无权页面与未登记路由 | 分别为 403 与 404；两者均不泄漏页面元数据 |
| `TC-EDGE-505` | `REQ-511` | 系统管理角色使用 wildcard 或新增资源缺显式 grant | 配置校验失败 |
| `TC-EDGE-506` | `NFR-503` | 权限结果曾被缓存后撤销 grant | 下一请求不返回已撤销权限 |
