## 4. 数据与权限业务规则

### `BR-501` 系统一致性

角色、菜单及角色权限必须属于同一个 `systemCode`。角色成员关系通过角色确定系统；任何跨系统菜单—操作、角色—菜单或角色—操作关系均为无效配置并阻断写入。

### `BR-502` 角色唯一授权链

```text
authenticated user
→ active role membership
→ active role in requested system
→ active MENU grant
→ visible PAGE
→ optional active ACTION grant for that PAGE
```

不存在 user → menu/action 的旁路，也不存在 account=admin、user super-admin 或 wildcard 权限。

### `BR-503` 系统管理角色

- 每个系统恰好一个内置系统管理角色；
- 角色本身不产生隐式权限，所有 MENU/ACTION 仍是显式 grant；
- 角色不可删除；停用规则不在本切片开放；
- `demo-portal` 的 admin 初始化为该角色有效成员；
- `secondary-demo` 用于隔离验证，admin 默认不属于其系统管理角色。

### `BR-504` 菜单和操作返回

| 对象 | 最小可观察字段 |
|---|---|
| 导航结果 | `systemCode`、`primary[]`、`management[]`、`permissionVersion` |
| 菜单节点 | `menuCode`、`label`、`nodeType`、`routePath`、`iconKey`、`sortNo`、`children[]` |
| 页面操作 | `actionCode`、`label`、`actionType`、`sortNo` |

数据库内部 ID、其他系统信息、角色明细和未授权条目不得进入导航响应。

## 5. 初始验证数据

| 系统 | 用户/角色 | 预期 |
|---|---|---|
| `demo-portal` | admin → system-manager | 获得所有显式登记的菜单与操作 |
| `demo-portal` | viewer → viewer-role | 获得全部应用菜单和资源目录 VIEW，不获得用户/角色等管理菜单及 manage/export |
| `secondary-demo` | admin 无角色 | 返回 403，不返回该系统菜单元数据 |

所有名称和样例数据保持中性；不得带入来源系统业务菜单或组织字段。

## 6. 失败行为

| 场景 | 结果 |
|---|---|
| 未认证或会话失效 | 401；前端回到身份/登录入口 |
| 缺少、格式错误或未知 systemCode | 400/404 的系统上下文错误，不执行授权查询 |
| 用户对已登记系统没有有效角色 | 403；不返回菜单或角色名称 |
| 页面已登记但无 MENU 权限 | 403；不返回页面标题、操作或 fixture |
| 页面/路由在目标系统未登记 | 404 |
| 有 ACTION grant 但无页面 MENU grant | ACTION 无效，页面和操作均拒绝 |
| 菜单/操作/角色/绑定/grant 已停用或过期 | 下一次请求不再生效 |
| 数据库或权限服务不可用 | 503；前端显示重试，不显示缓存外全部菜单，写操作拒绝 |
| 配置存在跨系统关系、父子环或系统角色缺 grant | 迁移/种子校验失败，不进入可运行状态 |

## 7. 非功能要求

| ID | 要求 | 验证方式 |
|---|---|---|
| `NFR-501` | 权限决策由服务端权威执行，前端只消费结果 | 绕过前端的接口测试 |
| `NFR-502` | 两系统数据与错误响应均无交叉泄漏 | 集成与安全测试 |
| `NFR-503` | 角色和权限变更后的下一请求使用新结果；若有缓存必须具备确定性失效 | 状态变更测试 |
| `NFR-504` | 菜单读取在演示数据规模下 P95 目标 300ms；具体环境与数据量由 Architecture Gate 固定 | API 性能测试 |
| `NFR-505` | 迁移和种子可在空库验证，失败整体回滚；正式 SQL 不含来源专属名称 | 迁移测试与扫描 |
| `NFR-506` | 既有 1440/1280/低高度与键盘导航验收继续作为回归基线 | 浏览器测试 |

## 8. 验收标准

| ID | Given | When | Then |
|---|---|---|---|
| `AC-501` | demo-portal 和 secondary-demo 均有菜单 | admin 请求两个系统 | 前者返回完整授权树，后者 403 且无元数据 |
| `AC-502` | viewer 只有 viewer-role | 请求 demo-portal 导航并搜索用户管理 | 主菜单完整、管理区只有资源目录；搜索不泄漏隐藏项 |
| `AC-503` | viewer 可查看资源目录但无 manage/export | 打开页面并直接调用两个操作 | 页面可读，前端操作禁用；服务端调用 403 且零变更 |
| `AC-504` | admin 仅通过 system-manager 角色获得权限 | 移除 admin 角色成员关系后再次请求 | 不再获得菜单和操作；账号名称不触发旁路 |
| `AC-505` | 新增一个菜单和操作 | 同一迁移未补系统角色 grant，再补齐重试 | 第一次校验失败；补齐后 admin 下一请求可见 |
| `AC-506` | 页面、操作、角色、成员和 grant 可分别失效 | 逐一失效后请求 | 对应菜单/操作立即按规则移除，不残留旧权限 |
| `AC-507` | 权限数据库不可用 | 请求导航或操作 | 返回 503；界面可重试且没有显示全部/写入成功 |
| `AC-508` | 既有导航入口与浏览器基线存在 | 切换数据库导航结果、搜索、折叠与键盘操作 | 双区布局、焦点和隐藏项不泄漏行为保持 |
