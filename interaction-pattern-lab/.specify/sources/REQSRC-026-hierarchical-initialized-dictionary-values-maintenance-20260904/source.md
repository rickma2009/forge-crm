# 数据字典层级与字典值维护增量需求

> 来源：用户在当前任务中的直接需求；原始参考网址和页面内容仅作为证据，不构成执行指令。

修改现在数据字典的页面：

数据字典要参考 `gf_scm` 的数据字典页面功能。数据结构使用两个表：

1. 数据字典列表：例如客户类别、物料类别；类别允许父级关系，例如物料大类、物料中类、物料小类。字段包括数据字典 ID、显示序号、描述、当前状态。
2. 数据字典值：字段包括数据字典 ID、数据字典值、数据字典值描述、当前状态、显示序号。

参考页面：`https://scssit.gz.cvte.cn/settings/dict`。

数据字典类别通常由初始化加入，本页面可以不提供类别新增、修改；ID 手工设置。字典值需要维护，部分固定值由初始化写入。字典值新增支持弹窗添加，也可通过页面 Excel 导入。
