# 企业交互模式验证

本上下文负责探索、实现和验证企业管理场景中的交互模式，不承担真实业务运营，也不持有通用模板的最终定义。

## Language

**验证场（Validation Field）**：
通过可运行切片收集实现与交互证据的实验环境。
_Avoid_: 模板库、产品、展厅

**交互模式（Interaction Pattern）**：
针对一类重复交互问题、具有适用边界与可观察行为的解决结构。
_Avoid_: 页面截图、组件样式

**验证切片（Validation Slice）**：
为一个明确问题提供可运行行为、测试和证据的最小纵向实现。
_Avoid_: 示例页面、一次性原型

**原型（Prototype）**：
为消除一个不确定性而制作的可丢弃探索物，不直接构成模式晋升证据。
_Avoid_: 已验证模式、生产实现

**交互演示（Interactive Demo）**：
在统一验证应用中长期维护、用于体验某个模式关键行为和状态的可运行案例；每个模式通过独立 Demo 适配器接入。
_Avoid_: 原型文件、生产页面、独立项目

**分类项（Taxonomy Item）**：
企业交互分类中带稳定编号的目录条目；它可以只是 `idea`，不自动构成模式资产或交互演示。
_Avoid_: 已验证模式、模板

**资产投影（Asset Projection）**：
验证场为了检索和展示而消费的权威资产索引视图，不独立定义成熟度、证据或适用边界。
_Avoid_: 资产规范源、手工副本

**场景契约（Scenario Contract）**：
独立于 UI 技术栈的初始状态、用户动作和可观察结果约定，用于检查不同交互演示是否表达同一行为。
_Avoid_: 共享 UI 组件、业务接口契约

**覆盖关系（Coverage Relation）**：
分类项被某个场景、交互演示或真实项目涉及的证据关系，不改变该分类项自身的成熟度。
_Avoid_: 成熟度继承、验证通过

**验证场设计系统（Validation Field Design System）**：
验证应用自身的中性企业视觉语言和语义令牌接口，不是所有企业项目必须采用的品牌或具体尺寸标准。
_Avoid_: 通用企业 UI 标准、项目品牌规范

**模式晋升（Pattern Promotion）**：
依据证据把候选结论移入 `_methodology/patterns/` 并同步模板、案例和检查的治理动作。
_Avoid_: 复制到模板目录
