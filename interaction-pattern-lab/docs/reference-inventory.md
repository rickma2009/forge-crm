## 后续导入规则

1. 用户提供源码时优先读取路由、样式、配置和测试；
2. 只有 URL 时记录版本、访问时间和可见范围；
3. 截图只补充视觉核对，不推断隐藏状态和权限；
4. Open Design 生成物记录具体 Brief、项目和验证结果，不把生成成功等同于模式验证；
5. 所有新材料先进入 `.specify/sources/`，再更新本台账。
