# Interaction Pattern Lab 设计系统

> 状态：historical-implementation-baseline-for-slice-001
> 决策时间：2026-08-30  
> 依据：已批准 `prototype.md`、`ADR-001`，以及 MCRM 已验证导航令牌与两个方法论模式。

> 当前边界：已有实现可继续作为历史证据。新基线只确认“中性企业设计系统 + 语义令牌 + 有理由的局部覆盖”原则；具体令牌和技术实现须由新 Architecture Gate 复审。

## Design Decisions

- **色彩**：深墨色导航 `#0f1729`、蓝色主操作 `#2f6bff`、冷灰画布 `#f5f7fa`、白色工作面；`#16836f` 只表达已验证或成功反馈。
- **字体**：标题与正文使用本地 `Avenir Next`、`Segoe UI`、`PingFang SC` 回退；编号、路径和指纹使用等宽字体。运行时不加载远程字体。
- **间距**：4px 基准，常用 8/12/16/24/32px；目录和表格保持企业工具型紧凑密度。
- **圆角**：控件 4px、工作面 8px、浮层 12px；不使用大胶囊或连续大圆角卡片。
- **阴影**：工作面轻阴影与浮层中阴影两级；边框优先，不用阴影制造无意义层级。
- **动效**：140ms 控件反馈、220ms 面板切换，统一 `cubic-bezier(.2,.8,.2,1)`；`prefers-reduced-motion` 下关闭非必要动画。

## 结构语言

- 页面是“目录 + 工作区”，不是营销落地页；打开即看到可操作内容。
- 工作台自身复用已验证的“企业双层导航壳层”：深色导轨承载一级真实分类与二级模式页面，右侧顶部栏和内容工作面独立。
- 不创建没有实际模式的空分类；窄屏下同一导航转为可关闭抽屉。
- 当前项通过背景、文字和 `aria-current` 共同表达，不只依赖颜色。
- 说明区强调证据、边界和风险，不展示无意义统计、虚构用户或装饰图标。
- 原型缺失、加载、空结果、错误和重置反馈都使用同一状态语言。

## 响应式与可访问性

- 桌面保持双栏；窄屏目录变为可开关区域，关闭后焦点返回触发器。
- 触控目标不小于 44px，桌面紧凑控件仍保留足够可点击范围。
- 所有交互有可访问名称、可见焦点和键盘路径；颜色对比在浏览器验收中核对。
- 不使用 `scrollIntoView`、远程脚本或真实业务素材。

### 工作台指标与消息区域

工作台默认采用上部指标卡、下部多区域模块布局；使用公共 `MetricCard` 和 `DashboardModule`，颜色标题带、主要数字、辅助金额与统计口径保持一致。金额按业务指定单位展示，工作台统一万元整数。无权限、无记录、未维护金额和服务失败应明确区分；不得用演示消息或虚构预警代替实际数据。本人待办与业务范围指标必须标明范围。详见 [我的工作台](features/my-workbench.md)。

### 商机分析与漏斗联动

只读分析页面采用上方统一查询、下方公共内容 Tab。销售阶段按业务配置顺序展示，漏斗阶段点击只过滤下方公共网格，保留组织与日期条件；阶段点击不改变业务状态。矩阵报表使用公共网格，按月列明单位及统计口径，原始金额与加权金额分别汇总。参见 [商机分析](features/opportunity-analytics.md)。
