# 我的工作台

首页 `/showcase/workbench` 为登录后的默认入口；顶部首页图标位于预警左边。固定首页 Tab 名为“我的工作台”，客户列表使用独立的“客户管理”Tab。保留显式业务深链、Tab 刷新和离开保护。

## 数据口径

- 跟进商机：当前应用、当前租户、启用、状态为初始或跟进中，预签日期在上海日历本月的记录数与预计金额。
- 本月签约：同一业务范围、启用、状态已签约，实际签约日期在本月；金额汇总商机金额，不代表回款或财务收入。
- 库存：当前租户库存余额金额，人民币以万元显示；其他币种单独列示，不折算、不相加。
- 金额除以 10000 后四舍五入到整数；空金额不计入合计，并提示未维护金额的记录数。
- 指标沿用现有业务页面的查看权限与业务范围。待处理事项是本人负责的初始/跟进中商机，按预签日期优先展示 8 条；不是新增的任务完成状态。
- 预警是本人负责的未结束商机中预签日期已过的记录，最多显示最早的 5 条。点击记录进入商机详情。
- 当前没有独立消息数据源，消息区域显示空状态；移除顶部原有硬编码消息和计数。后续接入消息中心时应绑定真实接口。

`GET /api/systems/:systemCode/workbench` 验证会话和系统授权。各业务源必须具有对应 `view` 操作权限，缺少权限返回 null 并显示无权限，不伪装成零；数据错误整体返回失败并可重试。读取使用 RepeatableRead 事务，避免统计和列表来自不同快照。首页不授予任何新的业务权限。

## 通用组件和模板

指标卡和区域块复用 `common/dashboard/MetricCard`、`DashboardModule`；页面响应式布局为上部三张指标卡，下部左待办、右预警和消息。模板登记到“指标仪表盘”（TPL-07-01）。预览使用同一页面组件及明确的模拟数据，截取 `.my-workbench`，排除菜单、顶部 toolbar 和系统 Tab，不公开真实客户/商机数据。

## 验证

服务端测试覆盖上海跨月跨年边界、业务日期和状态口径、本人待办、租户/应用隔离、无权限源不查询、库存币种分别统计。前端覆盖金额取整、待办导航、无权限空态和加载失败重试。浏览器验证默认首页、签约指标与数据库一致、客户管理独立 Tab 和顶部首页入口。
