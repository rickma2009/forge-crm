# 销售订单与销售出库实施说明

## 单据与来源

- 销售订单可按客户新建，或引入未关闭商机、已接受且未过期的报价单。引入时复制客户、产品、数量和价格快照；非独立来源的客户与来源记录不可改。一张有效报价只允许对应一张未取消订单。
- 销售订单为草稿 → 已提交审核 → 已审核；已提交可撤回或驳回。审核人不能是提交人。已审核订单可在尚无有效出库历史时取消，部分出货后可关闭剩余数量。
- 销售出库只能引用已审核且有待出货数量的订单。出库单为草稿 → 已提交审核 → 已审核；已提交可撤回或驳回。已审核单不能直接编辑或删除，只能按原成本与原批次全单冲销。
- 编辑采用版本号校验；状态命令使用请求键幂等。单号通过租户、单据类型与业务日期的计数器生成。

## 数量、金额与库存

- 订单行记录订单数量、单价、行折扣、表头折扣分摊后的金额、税率、已出货数量和履约状态。折扣金额按分分配，尾差落在最后一行；最终一次出货金额承接订单行剩余分差。
- 已出货数量仅由已审核且未冲销的出库行形成。订单行分别显示未出货、部分出货、全部出货；订单审批状态与履约状态分开。
- 一张出库单只选一个仓库。订单行可拆成多个出库行以使用多个批次。启用批次管理的产品必须选择批号；未启用批次管理的产品不得填写批号。库存维度为租户、法人、仓库、产品编码和批次号；非批次产品以空批次汇总。
- 出库审核在一个串行化事务中锁定订单与库存的版本，按移动平均成本扣减指定仓库批次的余额，并写入负数量、负金额的不可变库存流水；不足时整单回滚。冲销在同一维度加回原数量与原成本，追加正向冲销流水，并回退订单已出货数量。
- 入库过账增加库存并记录入库流水。库存页面可按产品或单号查看出入流水，以供核账。

## 本地演示数据与核验

- `pnpm --filter @forge-crm/server exec tsx scripts/seed-sales-demo.ts` 幂等生成 2 张已过账的测试入库单、100 张销售订单及 100 张销售出库单。
- 100 张出库单分布为已审核 50、已提交审核 20、草稿 20、已冲销 10。实际发生 60 笔出库扣库和 10 笔冲销回库，因此当前有效出库为 50 笔。
- `pnpm --filter @forge-crm/server exec tsx scripts/audit-sales-demo.ts` 核对单据状态、订单行累计出货、批次/仓库库存维度和本次演示出入库流水净变动。脚本会单独报告既有历史余额与流水差异，不自动改写历史账。
