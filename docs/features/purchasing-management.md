# 采购管理操作说明

## 在哪里操作

工作区 → 基本信息 → **供应商管理**；**采购管理 → 采购订单 / 采购入库**。系统管理 → 编码规则可查看SUPPLIER、PURCHASE_ORDER、INBOUND配置；新单保存由服务端自动取号，日期和流水使用当前规则，不能手改单号。

## 从订单到库存

1. 在供应商管理新增并启用供应商，填写联系人、税率、结算/交期等信息。引用后不能删除，可停用。
2. 新增采购订单，选择供应商、采购员、法人和仓库，添加可用物料，输入数量、含税单价、折扣和税率，保存草稿。单号点击浏览，行编辑图标进入编辑；提交后禁止修改。
3. 制单人提交，另一名有审核权限的用户审核；不通过可驳回。演示现有账户sales1.manager（陈晓峰）已分配“采购审核员（演示）”，只授予采购查询/审核/驳回，不授予修改或过账。密码沿用现有账户，不在文档存放。
4. 已审核订单点击“转采购入库”，或在采购入库新增页选择订单。核对实际仓库、收货人、收货日期；减少本次数量可分次收货，批次物料输入批号，需要多个批次时拆分来源行。
5. 保存并提交入库，由另一人审核。审核后库存仍未增加；有过账权限的用户点击“过账”并确认，完成后状态立即更新为已过账，订单已收数量/行状态同步更新。
6. 库存管理 → 当前库存，按法人/仓库/物料查询，点击物料查看批次库存；库存事务明细按入库单号查询，核对INBOUND流水的来源行号、数量、金额。金额为扣除可抵扣税后的成本。
7. 已过账数据不能改删。纠错可整单冲销；库存已消耗或成本变化导致无法安全归零时，系统拒绝冲销并保持原状态。冲销保留原始流水并新增反向流水，订单恢复相应可收数量，再新建正确入库。

## 浏览、编辑和异常提示

列表默认每页20条，三个对象各有独立视图配置。浏览详情不出现明细新增或删除；草稿可点击编辑，保存后回浏览。取消直接退出，不进行保存。已审核订单取消要求尚未收货且无有效入库；部分收货余量关闭要求先处理未过账入库。

数量超出订单剩余、批号缺失、物料/供应商停用、同人提交审核、权限不足或版本变化会拒绝操作；刷新查看最新状态，不通过直接改数据库绕过。
