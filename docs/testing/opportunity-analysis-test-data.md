## 保有量与预测口径

在手商机只计businessStatus为INITIAL或FOLLOWING的记录；已作废、已签约、已丢单退出在手商机保有量和预测。启用状态仍可作为辅助过滤。日期范围为本月及未来5个月，采用本月1日（含）到6个月后月初（不含），例如2026-09-29分析范围为2026-09-01至2027-03-01，不包含2027年3、4月；这两月测试记录用于检验窗口外排除。按自然月滚动，不能只取今天加150天。

列表默认显示商机状态、预签日期；签约日期和丢单日期可在视图设置中选择，也在详情中展示。新建/编辑提供状态选择，已签约必须有早于今天的签约日期，已丢单必须有不晚于今天的丢单日期，未签约填写的预签日期必须晚于今天。API通过businessStatus独立筛选，原status启用/停用协议保持兼容。

补充字段与修正此批数据命令：`pnpm --filter @forge-crm/server exec tsx scripts/update-test-opportunity-lifecycle.ts`。只更新上述固定100个测试编码及其测试跟进，升级demo-portal商机系统默认视图，不覆盖个人视图或其他业务记录。旧个人视图在读取时补齐未登记的新字段，保留原布局及已明确设置的显隐选择。数据库迁移新增字段时旧记录仅采用初始默认值，不根据阶段自动推断状态；真实记录状态应由业务人员确认维护。
