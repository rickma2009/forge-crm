# 客户360 P1交付与验证

范围：客户概览、商机/报价/销售订单/销售出货关联Tab；源服务授权、客户UUID过滤、分页和既有详情导航。方案见[详细方案](../design/sales-interaction-enhancement-solution.md)，规格见[032](../../.specify/specs/032-customer-360/spec.md)。

## 实现口径

客户访问先经过customer-directory.view及现有客户行范围。关联业务再检查源页面view，报价保留原本人/系统角色条件；订单按customerId，出货按order.customerId及同应用/租户过滤。接口只输出列表必要字段，不返回客户字段快照、单据行或内部审计字段。商机与报价当前没有独立币别列，明确显示“未定义币别”，不猜CNY、不跨币种相加。

概览为当前授权范围全部状态的记录数，失败显示失败而非0；活动、待办、建议摘要随P3/P4建设。只读关联列表使用公共网格分页，不另建列表视图配置，完整业务视图仍由源主列表管理。没有迁移或新建业务表，也没有改变订单/出库审核和库存过账。
