# 简道云流程审批官方资料研究笔记

> 研究范围：以简道云官方帮助文档「流程设定」为入口，聚焦流程设计、节点、负责人、字段权限、流转规则、版本管理，以及运行时审批与流程可视化。  
> 资料口径：只引用简道云官方帮助中心一手资料。  
> 检索日期：2026-10-06。  
> 本文仅记录产品事实，不包含 Forge CRM 对比、实施方案或代码改动建议。

## 一、入口与整体模型

| 主题 | 官方事实摘要 | 官方页面 |
| --- | --- | --- |
| 流程适用范围 | 当一张表单需要多人参与并按顺序提交数据时使用流程；典型场景是审批或多人分步骤完成一张表单。管理员预先配置节点、负责人和数据流转路径，数据提交后按设定流转。 | [流程设定](https://hc.jiandaoyun.com/doc/9048) |
| 流程与业务数据关系 | 流程属于「流程表单」的一部分。流程设计以前先完成表单字段设计；普通表单默认没有流程设定模块。 | [流程设定](https://hc.jiandaoyun.com/doc/9048)、[流程表单](https://hc.jiandaoyun.com/doc/11650) |
| 配置态与使用态 | 流程设定确定审批路径和各节点处理规则。保存只暂存配置，启用流程后才对新提交数据生效；表单发布决定谁可发起、谁可看以及展示方式。 | [流程表单](https://hc.jiandaoyun.com/doc/11650)、[流程版本管理](https://hc.jiandaoyun.com/doc/9058) |

## 二、设计时：可视化流程图与设计器

### 2.1 设计器结构

首次进入流程设计界面，官方文档将页面划分为三个操作区：

1. 工具栏；
2. 流程图画布；
3. 节点属性与流程属性面板。

在画布中通过拖放节点、拖拽连接线或从既有节点点击添加来建立流程图；选中节点后在属性面板配置负责人、字段权限、节点操作和流转规则。流程设计完成后需保存并启用。来源：[设计](https://hc.jiandaoyun.com/doc/9049)、[流程基本设置&工具栏](https://hc.jiandaoyun.com/doc/9050)。

### 2.2 画布操作与查看能力

- 支持撤销、重做、复制节点、多选删除、对齐、排列、快捷键和批量设置。
- 多选流程节点后，可以批量设置字段权限和节点操作，再对特殊节点单独调整。
- 可切换「简要视图」和「详细视图」：简要视图仅显示节点名称；详细视图还显示负责人、抄送人等信息。
- 画布缩放支持 50%、75%、100%、125%、150%、200% 与自适应；自适应会在画布中完整展示全部节点和连接线。
- 导航器用缩略视窗定位大型流程图。

来源：[流程基本设置&工具栏](https://hc.jiandaoyun.com/doc/9050)。

### 2.3 节点与连接线

官方「流程节点介绍」列出五类基础节点：

| 节点 | 事实摘要 |
| --- | --- |
| 流程发起节点 | 系统默认、不可删除，是流程入口；可重命名并设置发起人的字段权限、提交条件与部分节点操作，不需要另设负责人。 |
| 流程结束节点 | 系统默认、不可删除，是流程图出口；没有节点属性。所有分支末端应连接结束节点，但流程是否真正结束取决于是否仍有进行中的节点。 |
| 流程节点 | 中间审批或处理节点；可有多个，通过连接线组织；配置负责人、字段权限、抄送、节点操作和流转规则。 |
| 抄送节点 | 在相应审批节点完成后通知关注人员；抄送人只读，不参与流程推进，可独立设置可见字段和流程简报。 |
| 子流程节点 | 将另一张流程表单作为子流程执行；子流程完成后回到父流程继续流转。 |

来源：[流程节点介绍](https://hc.jiandaoyun.com/doc/10657)、[抄送](https://hc.jiandaoyun.com/doc/9055)。

另有「插件节点」，通过外部插件执行数据转换、加工、验证、通知等自动化处理。官方说明插件节点属于系统自动流转节点，存在成环、回退、手动结束和负责人调整等限制。来源：[插件节点](https://hc.jiandaoyun.com/doc/16649)。

> 文档口径提醒：基础节点介绍称五类节点；工具栏页面将可从工具栏添加的节点与系统默认节点分开描述；插件节点又有独立文档。因此核对产品能力时，应区分「系统默认节点」「画布可添加节点」和「扩展自动节点」，避免仅按某一页的节点数量下结论。

### 2.4 设计预览与流程测试

- 管理员可在设计时选择任意节点，预览该节点真实的字段显示与可编辑效果；预览页面可以通过可视化流转图切换节点，未选节点时默认预览发起节点。
- 流程测试允许管理员模拟指定成员身份发起并运行测试，用于在正式启用前验证负责人解析、条件分支和节点间流转。

来源：[流程预览](https://hc.jiandaoyun.com/doc/16196)、[流程测试](https://hc.jiandaoyun.com/doc/23025)。

## 三、节点负责人

### 3.1 常规负责人来源

常规审批节点的负责人可从以下范围选择：

- 组织架构中的部门；默认包含直属成员，可选择动态包含下级部门；
- 角色；
- 一个或多个固定成员；
- 动态负责人。

动态负责人支持流程发起人、表单成员字段、表单部门字段，以及发起人/成员字段/部门字段对应的部门主管。常规动态主管最高可选五级。来源：[常规审批](https://hc.jiandaoyun.com/doc/9051)、[动态负责人](https://hc.jiandaoyun.com/doc/12530)。

成员、部门字段作为动态负责人时，官方还对主表/子表字段和使用位置给出支持矩阵：流程节点负责人、节点抄送人、独立抄送节点及子流程发起人的支持范围并不完全相同。来源：[部门、成员字段作为负责人](https://hc.jiandaoyun.com/doc/16764)。

### 3.2 逐级审批

逐级审批可在一个节点内，从发起人的直接部门主管开始，逐级审批至指定终点，从而减少为每级主管各建一个节点的冗余。审批终点可按「发起人的某级主管」或「通讯录中的某级主管」定义；官方说明前者最高支持十级，后者支持从通讯录最高级向下指定层级。

逐级审批节点内各主管共用字段权限、节点操作和节点提交条件；流转规则为主管依次提交后进入下一节点。空缺主管可跳过，多层主管重复时默认去重并保留最高层审批。来源：[逐级审批](https://hc.jiandaoyun.com/doc/16929)。

### 3.3 找不到负责人

当流程无法解析出负责人时，可配置：

1. 停止流转并报错（默认）；
2. 转给指定成员；
3. 自动提交。

自动提交不会进行字段必填、审批意见/签名、节点校验，也不触发公式、联动和默认值获取；某些无法继续解析或可能造成循环的情形会停留并转给系统管理员。子流程、抄送、插件节点不支持该规则。来源：[找不到节点负责人时](https://hc.jiandaoyun.com/doc/17147)。

## 四、字段权限与节点表单

### 4.1 三类节点字段控制

流程节点提供三项彼此相关但用途不同的字段控制：

| 控制项 | 作用 |
| --- | --- |
| 可见 | 节点发起人、负责人或抄送人能否看到字段。 |
| 可编辑 | 能否修改字段；可编辑以前必须可见，勾选可编辑会自动勾选可见。分割线和流水号属于不可编辑字段。 |
| 流程简报 | 未进入详情时，在流程列表/卡片上显示的摘要字段；与可见、可编辑权限独立。 |

来源：[字段权限](https://hc.jiandaoyun.com/doc/9054)。

### 4.2 权限生效位置

- 发起节点字段权限作用于发起流程的提交页面。
- 其他审批节点字段权限作用于从待办打开的处理页面。
- 每个节点分别配置，因此同一业务字段可在发起阶段可编辑、审批阶段只读，或在特定节点才出现并允许填写。
- 若表单还设置字段显隐规则，字段必须同时满足显隐条件和节点可见权限才会显示。
- 节点上的抄送沿用该节点的可见字段和简报；独立抄送节点可以单独配置可见字段与简报。
- 子表单除字段的可见、可编辑外，还可控制新增行、插入行、编辑已有行、删除已有行等行级操作。

来源：[表单/流程/权限组的字段权限](https://hc.jiandaoyun.com/doc/20748)、[字段权限](https://hc.jiandaoyun.com/doc/9054)、[抄送](https://hc.jiandaoyun.com/doc/9055)。

## 五、节点操作

官方节点操作文档列出的处理能力包括：

- 提交；
- 回退；
- 否决；
- 提交并打印；
- 暂存；
- 暂存并打印；
- 加签（前加签、后加签、新增审批人）；
- 转交；
- 结束流程；
- 操作备注（文本意见与手写签名）；
- 批量提交。

操作按钮可自定义文字，处理页及流程日志都会显示自定义后的名称。否决与结束流程不能同时开启；若未开启「提交并打印」，提交为必选操作。来源：[节点操作](https://hc.jiandaoyun.com/doc/9067)。

回退是当前负责人把流程退到先前节点重新处理；撤回是发起人或审批负责人在下一节点尚未处理时，将自己刚提交的流程撤回到本人待办。回退还能配置重新提交后按原顺序审批或直达回退人所在节点。来源：[流程回退](https://hc.jiandaoyun.com/doc/12524)。

## 六、流转规则

### 6.1 五类规则

节点属性中的「流转规则」包括五类：

1. 节点提交条件：判断当前数据是否允许离开本节点；
2. 多负责人规则：所有负责人提交后进入下一节点，或任意负责人提交后进入下一节点；
3. 找不到节点负责人时的处理；
4. 节点限时处理；
5. 数据流转条件：根据字段内容决定进入哪一个或哪一些后续节点。

来源：[流转规则](https://hc.jiandaoyun.com/doc/21922)、[节点属性设置](https://hc.jiandaoyun.com/doc/12424)。

### 6.2 节点提交条件与分支条件不同

- 节点提交条件回答「能不能提交」；不满足时可阻止提交，也可允许审批人忽略提示继续提交。支持公式、多个校验条件、自定义提示和字段修改时实时校验。回退、暂存、转交、结束流程不会触发节点提交条件。
- 数据流转条件回答「提交后进入哪些节点」。条件配置在连接线上；从上游提交的数据会进入所有满足条件的后续节点，因此可形成条件分支或并行路径。

来源：[节点提交条件](https://hc.jiandaoyun.com/zh_cn/doc/9052)、[节点校验与流转条件的对比](https://hc.jiandaoyun.com/doc/13491)、[数据流转条件](https://hc.jiandaoyun.com/doc/12536)。

数据流转条件可引用流程表单字段。官方案例展示了按单选字段将数据流向不同节点；部门字段条件还支持「动态包含下级部门」，以适应组织结构变化。来源：[数据流转条件](https://hc.jiandaoyun.com/doc/12536)。

### 6.3 限时处理

节点限时处理支持未按时处理时自动提醒、自动回退或自动提交。自动提交后流程动态中的提交人显示为系统机器人；限时自动提交不会执行节点校验，因此官方提醒需要注意后续必填字段风险。来源：[流转规则](https://hc.jiandaoyun.com/doc/21922)、[自动提交](https://hc.jiandaoyun.com/doc/11196)。

## 七、流程级设置与版本管理

### 7.1 流程属性

流程属性作用于整个流程，官方汇总的设置包括：流程提醒、流程撤回、流程催办、流程日志和流转图、自动提交规则，以及接入钉钉审批套件。来源：[流程属性设置](https://hc.jiandaoyun.com/doc/12423)。

发起人催办开启后，可向当前正在审批的节点负责人发送催办。来源：[流程催办](https://hc.jiandaoyun.com/doc/12066)。

### 7.2 版本状态与生效规则

流程版本分为：

| 状态 | 官方规则摘要 |
| --- | --- |
| 设计中 | 尚未启用，可完成全部配置，包括增删节点、连接线、流转条件、节点属性和流程属性。 |
| 启用中 | 新提交数据按此版本运行；同一流程只有一个启用版本。 |
| 历史 | 曾被启用，因新版本发布转为历史；其原有流程实例继续按原版本流转。 |

新建版本会复制当前版本作为修改基础。新版本启用后，新流程实例按新版本运行，流转中的实例继续使用旧版本。设计中版本可删除；有过数据的历史版本不可删除。来源：[流程版本管理](https://hc.jiandaoyun.com/doc/9058)。

官方还说明：涉及增删节点或连接线的结构变更需要新版本；启用中的版本可以直接修改部分节点属性、流程属性和流转条件。节点负责人改动只影响后续进入该节点的数据；其他节点属性修改可影响已经停留在节点中的数据。来源：[流程版本管理](https://hc.jiandaoyun.com/doc/9058)、[修改节点属性对数据流转的影响](https://hc.jiandaoyun.com/doc/13492)。

## 八、运行时：发起、待办、审批与可视化追踪

### 8.1 流程中心

流程中心包含四个核心页面：

- 我的待办：本人当前负责、需要处理的数据；
- 我发起的：本人作为发起人的流程；
- 我处理的：本人作为负责人处理过的流程；
- 抄送我的：本人作为抄送人收到的流程。

工作台还提供统一「发起流程」入口，以及启用后可见的待办委托。工作台覆盖整个企业中与本人有关的流程；应用内入口只覆盖当前应用。来源：[流程中心](https://hc.jiandaoyun.com/doc/9068)。

待办处理时，负责人打开流程详情，根据该节点字段权限查看或补充信息，再使用管理员为节点开启的提交、回退、否决、加签、转交等操作。来源：[流程入门使用手册](https://hc.jiandaoyun.com/doc/20181)、[节点操作](https://hc.jiandaoyun.com/doc/9067)。

除统一流程中心外，简道云也允许从原业务数据进入审批：在权限组数据列表中可通过「当前节点」进入处理，原表单的数据详情页可从系统字段或流程动态处理待办，仪表盘的数据详情也支持处理。来源：[权限组及数据详情页中处理待办](https://hc.jiandaoyun.com/doc/16456)。

### 8.2 流程动态

流程动态包含：

- 流程日志：负责人、操作状态、节点开始时间、提交时间、处理耗时等；
- 审批意见：负责人提交的文本意见或手写签名；
- 抄送节点的抄送详情。

流程属性可控制普通成员在工作台和应用的相关流程页面是否能查看流程动态与流转图；权限组和数据管理查看时始终显示。来源：[流程动态和流转图](https://hc.jiandaoyun.com/doc/9056)、[如何查看流程状态/当前所处节点/流转情况/抄送人员？](https://hc.jiandaoyun.com/doc/20176)。

### 8.3 运行时流转图

运行时详情提供「流转图」，以流程图形式展示：

- 流程版本；
- 实际流转线路；
- 当前流程进度；
- 当前节点及负责人；
- 已通过和待审批环节。

官方颜色语义为：蓝色框表示当前处理中节点，绿色框表示已流转节点，无颜色表示未流转节点。来源：[流程动态和流转图](https://hc.jiandaoyun.com/doc/9056)、[如何查看流程状态/当前所处节点/流转情况/抄送人员？](https://hc.jiandaoyun.com/doc/20176)。

这表明简道云的「可视化流程图」存在两个明确场景：设计时画布用于编辑结构和配置规则；运行时流转图复用流程结构展示某个实例的实际路径与节点状态。
