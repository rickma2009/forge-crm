# P2.2 销售订单真实审批接入

2026-10-05；范围限销售订单。原型仍在 `prototypes/`，正式模块在 `packages/server/src/workflow/`、`packages/web/src/showcase/workflow/`，引擎在 `services/workflow-engine/`。

## 使用

1. 启动 CRM 前后端和独立引擎（`bash scripts/workflow/start.sh`）。CRM 服务端配置 `WORKFLOW_ENGINE_URL` 与 `WORKFLOW_SERVICE_TOKEN`；令牌与 `infra/workflow/.env` 一致，不进入浏览器、不提交 Git。
2. 数据库执行正常迁移。已有系统只运行 `pnpm --filter @forge-crm/server exec tsx scripts/initialize-workflow.ts` 初始化两个新菜单、按钮权限及审批列表视图；仅系统管理员默认授权，不重置账号、不重跑全量业务种子。
3. 在角色管理中给审批人授予“审批中心：访问、查看、处理审批”。申请人须有销售订单提交和审批中心查看权限。管理员另有“工作流设置：管理”权限。
4. 系统管理 → 工作流设置：按申请部门选择部门经理、明确的二级祖先部门及负责人、财务负责人；可配置各节点同职责转交备选人。金额阈值默认100000。发布后等待状态“已发布”，新提交才使用该版本。
5. 申请账号须关联启用员工、有效雇佣与任职。订单所属组织须是申请人有效任职部门；订单未填组织时使用主职部门解析，原单据字段不被隐式改写。必经审批人须有有效员工任职及审批处理权限，不能为申请人；缺失即阻止提交并保持草稿。
6. 提交订单后，首页旁“审批中心”出现待处理通知计数；待办单号进入审批页。同意、退回申请人、驳回结束、转交均经真实权限、当前任务和版本检查。退回/驳回恢复订单草稿，再提交创建新轮次。
7. 原订单页下方显示工作流区域；使用与设置页相同的完整图，未走分支仍保留。选择节点查看意见，选择历史轮次追溯。审批完成后订单状态自动刷新。

## 规则与恢复

金额采用人民币折扣后总额，严格“大于阈值”才加二级负责人；非CNY订单暂不能使用该模板。审批人员与金额在提交时冻结，后续改组织或发布版本不自动改历史审批人。节点转交只可选择该版本配置的同职责人员，并重新验证其有效性和权限。

CRM 提交订单、申请记录及启动命令在同一事务。独立引擎调用不占数据库事务；命令保存原请求ID，领取采用锁和租约，超时按同键退避重试。销售适配器在一个事务内修改订单、写审核事件、写唯一执行回执及结果通知命令，防止重复业务生效。工作流运行中禁止原订单直接审核、驳回或撤回接口绕过。

运行异常在工作流设置中显示，管理员按原命令重试。失败未恢复前不接受该申请的新操作。超过自动重试上限须人工排查；不在浏览器提供任意URL、代码或SQL回调。该切片注册的业务动作仅为销售订单审核，其他业务接入必须实现各自适配器。

## 验证与边界

- 隔离 CRM PostgreSQL + 真实 Flowable：10项通过，覆盖业务分支、幂等发布、退回重提、合法转交、非法承办人/缺任职、丢失响应重放、真实登录RBAC/CSRF、未知作用域。命令：`node scripts/test-sales-workflow-integration.mjs`。测试CRM库自动删除，引擎保留独立随机作用域的测试历史，不对应正式CRM订单。
- 引擎 PostgreSQL 集成：9项通过；运行脚本已重新构建本机服务。
- 前端/服务端/脚本类型检查及菜单注册校验通过；浏览器验证见040切片证据。
- 本机菜单与服务可用，未擅自为现有部门指定审批人或发布虚假业务配置，未批量修改历史订单。没有启用配置时保持原审核路径，已在旧路径提交的订单不补建流程。
- 当前为受限销售订单模板的真实切片，不含自由BPMN拖拽设计、动态入节点解析、会签加签、主动撤回、邮件推送、请假/报销/付款/事件业务适配；通知为站内未读计数和待办列表。生产部署、备份恢复演练仍须独立验收。

## 复用记录

本切片证据支持复用：固定版本完整流程图组件、可靠命令投递和业务回执边界；候选位置为 `_methodology/patterns/`，尚不宣布跨项目标准。销售金额字段、审核条件和订单状态写入为业务专属。新增业务应遵循“提交快照 → 引擎命令 → 注册业务动作 → 事务回执”的接入契约并重新验收；不得直接复用无校验改状态代码。

本机后端当前以单个 `node dist/main.js` 运行，前端独立Vite运行。停止冲突的开发监听后，后续修改后端须构建并重启；不要在已有服务旁重复执行联合启动。

本阶段完成后停止；下一业务类型、超出受控范围的复杂流程能力和生产发布等待后续具体任务。当前受控流程设计器已经提供自动布局的图形化节点与连接线编辑。
