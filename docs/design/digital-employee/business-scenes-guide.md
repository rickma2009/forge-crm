# 三个数字员工场景页面使用说明

日期：2026-10-09。当前为可持久化的功能演示；各15条，共45条模拟记录，默认每页20条。

| 菜单 | 内容与操作 |
|---|---|
| 数字员工 → 供应链 → 采购订单执行 | 按源单/行核对回签数量、含税单价和交期；配置容差；生成未发送催办草稿；写核对结论后关闭，可重开 |
| 数字员工 → 生产与质量 → 客诉及质量事件 | 查看产品/批次/SN、报告事实及根因假设；生成并修订D1–D8模板；人工确认根因并记录验证后关闭 |
| 数字员工 → 财务 → 经营分析 | 查询期间、客户/主题与处理状态；汇总已审核/已履约订单CNY含税金额，排除草稿；对比预算；规则解释及后续行动 |

点击记录编码打开详情；操作列使用编辑、完成、重开三种既有语义图标。保存成功马上刷新状态及记录，失败保留弹窗；取消直接退出。不完整回签或未验证的质量事件不能关闭；经营记录关闭前需保存行动或无需行动的依据。

## 接口设置

每页“接口与规则配置” → “编辑接口与规则”：数据模式、维护人、HTTPS接口地址、相对资源路径、集成连接编码；采购另有数量/单价/延期容差，经营分析有预算偏差阈值。

默认DEMO模式；API模式只保存参数，尚未开发外部数据适配器，因此列表为空并提示待联调，不能操作DEMO记录。切回DEMO保留原修改。只有地址和路径完整才显示“配置已保存，待数据适配与联调”，不显示假连接成功。不要在地址或备注中放Token；凭据使用集成中心的加密业务连接引用，拒绝失效/他应用连接及邮箱连接。

未来联调字段：采购源单/行/物料/供应商/数量/分单位价格/交期；质量事件/产品/批次/SN/报告与验证证据；经营期间/组织/客户/审核状态/CNY订单与预算金额/出货数量。金额/订单映射和授权需要真实源系统校验，不能用本页数据替代正式ERP/QMS/财务口径。

## 数据与运行

演示数据只保存在sys_de_scene_workspace，按租户和应用隔离；无正式订单、库存流水或对外发送副作用。记录含操作时间、账号和结论，乐观版本防止覆盖。初始化保留已有记录，关闭不删除，可重开。

本地初始化：`pnpm --filter @forge-crm/server exec tsx prisma/apply-business-scene-workspaces.ts`，只新增经营分析菜单与缺失的三个工作区，保留现有权限设置和已编辑内容；先部署对应迁移，禁止用全量seed重置业务数据。

针对性验证：`node scripts/test-business-scenes-integration.mjs`（临时数据库自动清理）、`node scripts/test-business-scene-migration.mjs`；领域与组件测试记录见 [交付复查](../../../.specify/specs/ai-scenario-enhancement/review.md)。真实接口/模型/企业业务试点尚未验收。

复用候选：多场景演示/API分离、同作用域连接引用、版本冲突与操作留痕；BusinessSceneCenter复用既有网格/详情/查询/弹窗。采购核对、8D关闭及经营口径属于各场景规则，不统一为所有数字员工的状态。未证明跨项目通用性，不发布独立插件。
