# 企业交互模板库设计

日期：2026-09-28。状态：结构和交互设计已由用户确认，已替换正式交互案例页面；模板资产继续提炼。
来源：`.specify/sources/REQSRC-081-template-library-design/source.md`。

## 目标
用户能够按交互结构找到模板，查看效果和演示，并以“请参考【模板名称/编码】设计本页面”让开发使用已有结构、组件、交互规则和接入示例。

## 两级目录
一级仅为分类，二级直接对应一份模板资产。不存在“二级交互模式→三级模板案例”；业务应用案例、配置变体、组成组件都放在模板详情中。

1. 列表与检索：查询表格列表、带表格视图的列表、卡片检索列表、分组与层级列表、列表与详情。
2. 树形联动：树状分类明细、树节点维护、树节点与多Tab详情。
3. 详情与录入：对象详情工作区、单表录入、主从单据工作区、对比与版本查看、行内编辑表格。
4. 选择与关联：弹窗表格单选、弹窗表格多选、弹窗树分类与表格多选、待选与已选双区选择、选择记录并补充明细、任务入口选择弹窗。
5. 工作区与容器：多页面Tab工作区、页面内多Tab工作区、抽屉查看、抽屉编辑、弹窗维护、确认操作弹窗。
6. 流程与作业：分步办理、审批处理、批量操作与结果反馈、导入校验与确认、异步任务与进度跟踪。
7. 分析与展示：指标仪表盘、图表与明细联动、日历与时间计划、时间线与过程记录、阶段看板。
8. 智能交互：大模型对话页面、内容生成与采纳页面、智能建议与人工确认页面、Agent任务执行页面、Agent过程跟踪与接管页面、多Agent协作与结果汇总页面、AI分析任务弹窗。
共8类42个候选模板，清单支持扩展，登记不代表实现。模板名称及编码唯一且稳定；分类中文名可调整。每个模板仅有一个主分类，多Tab、抽屉、批量、视图、智能辅助等用标签和关联模板表达组合关系。

## 页面行为
- 初次进入：显示“全部模板”卡片概览，顶部统一查询区提供关键词、模板分类、可用程度，点击查询应用条件，重置恢复全部范围。
- 一级节点：右侧展示该分类模板卡片，卡片包含预览、名称、用途和建设状态。
- 二级节点或卡片：保持左侧目录，右侧直接显示选定模板详情，选中项与详情一致。
- 详情顶部：分类路径、编码/名称、用途、可用程度、“打开演示”“复制参考指令”。
- 详情首屏优先效果预览，其后是适用说明、页面结构与操作流程、必需/可选能力、配置项、关联模板、接入说明、应用案例和维护信息。
- 返回分类：右侧恢复卡片概览，保留检索条件。可用URL定位模板和分类，不依赖浏览器历史猜测对象。
- 演示：有独立演示时在浏览器新页签打开；实际业务页面另列“应用案例”，继续经过现有登录/权限校验。
- 只有效果图：可放大图片，注明无交互演示；只有构想时明确无截图/演示，不显示虚假入口。
- 顶部查询命中模板名称、编码、用途和标签，和选中一级分类共同过滤右侧卡片；左侧目录搜索仅筛选节点并保留祖先，不改变右侧当前详情。空结果提示且可重置。
- 键盘、焦点、窄屏布局沿用项目公共组件。分类仅两级，不新增隐含案例层级。

## 字段定义
| 字段 | 规则 |
|---|---|
| templateCode / name | 唯一稳定编码、中文模板名称；都能作为开发引用入口 |
| categoryCode / tags | 单一一级分类；标签可多选、可扩展 |
| summary | 一句话解释页面解决什么问题 |
| suitableFor / notSuitableFor | 适用与不适用场景 |
| regions / steps | 有标题的区域列表、操作步骤及输入/输出 |
| required / optional | 必需和可选能力，不凭业务对象新增重复模板 |
| config | 查询字段、树数据、表格列、视图、API、权限等配置参数 |
| thumbnail / screenshots | 图片资源与中文说明；区分实拍、布局示意及更新时间 |
| demo | 独立演示地址及演示能力；不复用通用三态占位冒充实际页面 |
| applications | 已有实际业务页面及其使用边界，可多个 |
| components / skeleton / guide | 公共组件引用、代码骨架、接入步骤 |
| referencePrompt | 可直接复制的模板参考指令 |
| relatedTemplates / aliases | 关联模板、合并前旧编码，便于追溯 |
| aliases | 旧名称或同义名称，保持旧名称可检索且不更改编码 |
| behaviorRules | 查看与编辑、保存与离开保护、加载/处理中/成功/失败/空数据/权限不足反馈 |
| version / verification | 模板版本及验证记录 |

可用程度：待提炼（只有定义）、可预览（有效效果图）、可交互（对应独立演示验证）、可复用（组件/骨架/接入说明及验证齐全）。状态必须从真实资产判定，不用旧DONE或业务页链接冒充可复用。
