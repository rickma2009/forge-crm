# 供应商与采购管理方案

2026-10-11。依据本轮用户自主规划、开发、测试和演示数据授权实施。需求与验收见[采购切片](../../../.specify/specs/purchasing/spec.md)。一期交付后停止，不扩展其他业务。

## 菜单与交互

- 基本信息 → 供应商管理：名称/编码查询，状态筛选，新增、独立对象视图设置、分页。编码进入浏览，行编辑/删除为语义图标。
- 采购管理 → 采购订单、采购入库：查询 → 新增/当前视图/设置 → 表格 → 分页，每页20条。单号链接浏览，只有草稿允许编辑/删除。
- 工作区详情：统一返回箭头、单号和只读摘要；主表在上、明细在下，不使用多Tab或嵌套卡片。编辑入口直接进入编辑状态，浏览状态不出现明细增删操作。取消直接退出，不弹未保存确认。
- 审核、过账、冲销等位于详情操作区，按权限和状态显示，执行后立即重新读取单据、履约数量和操作历史。已审核/过账不可直接改删。

## 供应商主数据

供应商编码由系统SUPPLIER规则生成；名称、简称、类别、统一信用代码、联系人、电话、邮箱、地址、结算天数、交期天数、默认税率、状态、备注。类别一期为综合、电子、机械、包装、服务固定选项。非供应商评级/准入系统，不包含银行账户和付款执行。

启用且未删除的供应商才可用于新单。已引用供应商禁止删除，可停用；历史单据名称保留快照，主数据变动不自动改写单据。共享主数据属于租户，采购服务为唯一写入责任模块。

## 采购订单

独立按供应商创建，不引用销售报价。单号读取PURCHASE_ORDER规则；采购员、法人、计划收货仓库、订单日期、预计到货日期、订单类型、币别、整单折扣、金额/折后金额/税额、备注。供应商默认税率带入，可在草稿修改；价格人工录入，允许修改，不声称自动获取供应商价目表。

行包含物料编码/名称/单位、数量、含税单价、行折扣、税率、金额、折后金额、税额、显示顺序、已收数量、收货状态及备注。数量必须正数，零价采购需说明，显示顺序不可重复。预计到货不得早于订单日期。

状态：草稿 → 已提交审核 → 已审核；提交人可撤回，审核人可驳回回草稿，提交人与审核人必须不同。草稿删除留VOIDED记录。已审核无已收货且没有有效入库单可取消；部分收货可关闭剩余，先取消或处理未过账入库单。履约状态独立为未收货/部分收货/全部收货/余量关闭，已收数量不可手工修改。

## 采购入库与批次

必须从已审核、未关闭且有剩余量的采购订单创建；订单详情“转采购入库”带入来源，也可从采购入库新增页选择订单。供应商、法人、币别、来源订单及来源行锁定；收货仓库须属于相同法人，可改变实际收货仓库。复制来源价格/税额快照，不在收货单改价。

可分次收货，一条来源行可按不同批次拆多行，来源行+批次不可重复。批次管理物料必须输入批号，非批次物料批号归空。提交、审核、过账分别重查剩余量；草稿不占用库存，也不承诺预留收货量，竞争时后过账方可能因超收失败。

状态：草稿 → 已提交审核 → 已审核 → 已过账。审核不增加库存，只有明确过账才增加。已过账单只能整单冲销，库存数量/金额不足或冲销会留下零数量非零金额时拒绝；不能以冲销替代退货。已冲销单保留原入库与反向流水，再创建正确入库单。

## 金额、库存与追踪

一期CNY，单价含税；行折扣与整单折扣叠加，整单分摊采用最大余数，服务端Decimal计算为准。税额=含税折后金额×税率/(1+税率)，采购库存成本=折后含税金额−可抵扣税额。部分入库按来源行比例分摊，最后一次收货补齐金额和税额尾差；界面计算仅预览，保存/过账重新计算。

库存维度为租户+法人+仓库+物料编码+批次，非批次物料同维度累加。采购过账和冲销通过库存责任模块，在同一事务写余额、事务流水、订单已收数量/行状态、单据状态、操作事件。流水保留采购入库单号、明细行号/ID、物料/批次、数量/金额、执行人和时间。订单已收数量只汇总已过账且未冲销的采购入库，不统计原有手工入库。

## 权限与并发

页面和创建/修改/删除/提交/撤回/审核/驳回/取消/关闭/过账/冲销分别授权；会话、CSRF、租户/应用边界、版本冲突、来源复合外键和数据库CHECK同时校验。单据命令按应用+执行人+请求键幂等，键复用不同payload拒绝；供应商编辑/删除采用版本保护及审计。采购业务事务使用租户采购锁和Serializable隔离，P2034最多重试3次。入库不能负库存或超收，任何失败回滚全部写入。

新表md_supplier、scm_purchase_order/line、scm_purchase_receipt/line、scm_purchase_event；沿用现有scm_inventory_balance/txn及系统编码规则。INBOUND发号同时检查手工入库与采购入库历史，避免共享IB单号冲突。

## 初始化、验收与边界

局部菜单脚本只补采购菜单、新权限和默认视图，不运行全量初始化覆盖既有配置。演示数据有明确标识且重复执行不覆盖业务操作；制单/审核用不同现有用户。至少20供应商、20订单、20入库和20已过账，包含批次/非批次、分次收货、拆批、多状态及冲销。

不包含应付付款、发票匹配、质检待验/隔离库存、采购退货、供应商绩效、多币种成本和Flowable采购适配。采用基础权限审核，不声称已自动接入工作流。部署与验证见[交付记录](../../testing/purchasing-management.md)。
