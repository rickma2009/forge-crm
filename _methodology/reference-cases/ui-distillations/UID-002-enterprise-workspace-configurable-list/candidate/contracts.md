# 去来源化候选契约

## 1. `ApplicationNavigation`

- 输入：按系统和角色授权过滤后的单棵菜单树；
- 规则：所有组和页面使用同一节点模型，位置只由父级和排序决定；
- 禁止：以“系统管理”名称或特殊区域形成第二套渲染/授权逻辑。

## 2. `GlobalToolbar`

- 固定槽位：导航开关（窄屏）、预警/待办、消息、当前用户、退出；
- 扩展：采用项目可按稳定 `toolKey` 增减业务无关工具；
- 失败：没有数据源的工具显示明确空态，不伪造计数；退出必须调用真实会话接口。

## 3. `RouteTabWorkspace`

- URL 是激活页面事实源；页签状态是派生工作区状态；
- 首页固定；菜单页一页签；详情子路由可归并到所属菜单页签；
- 支持激活、关闭、刷新、关闭其他/右侧/全部和溢出导航；
- 超上限时阻止新开并说明原因，不自动关闭含潜在未保存状态的页签。

## 4. `ConfigurableListPage`

- 组成：查询栏、页面操作栏、当前视图、表格、行操作、服务端分页；
- 每个列表至少一个启用的系统默认视图；
- 系统视图定义可见/可查询字段、列顺序/宽度/固定、默认过滤和页大小；
- 个人视图必须基于一个当前角色可用的系统视图，只能收窄，不能扩大字段或操作权限；
- 视图故障不允许静默回退到全字段列表。

## 5. `DictionaryCatalog`

- 分离管理 API 与业务消费 API；
- 字典类型和字典项具有稳定编码、名称、排序、启停、描述和审计字段；
- 业务记录保存稳定字典项值；展示时解析名称；历史记录不能因字典改名而失去可解释性；
- 停用项不再用于新录入，但已有数据仍可显示。

## 6. `CustomerDirectoryDemo`

- 目标是验证通用列表、字典、远程选择和数据库 CRUD，不复制来源客户业务；
- 字段限于客户类别、编码、名称、简称、地址、状态、行业、等级、负责销售和备注；
- 销售选项由可替换搜索 Provider 提供，首版不建员工表；客户记录保存选择键及显示名快照；
- 数据范围权限不在本轮，菜单/操作权限继续沿用角色授权。
