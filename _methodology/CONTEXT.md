# AI 工程方法与资产

本上下文负责把企业应用从原始需求治理到可验证交付，并把跨项目证据晋升为可复用资产。

## Language

**工作台（Workbench）**：
承载方法论源、验证场索引和项目创建工具的仓库；它不是单一业务项目。
_Avoid_: 总项目、业务项目

**方法论源（Methodology Source）**：
`_methodology/` 中唯一权威的方法、模板、门禁、Profile 和已晋升资产集合。
_Avoid_: 公共文件夹、经验汇总

**治理初始化（Governance Initialization）**：
在业务发现前创建来源归档、章程、上下文、宪法和 Gate 状态等技术栈中立骨架。
_Avoid_: 完整项目脚手架、技术栈初始化

**技术 Profile（Technology Profile）**：
Architecture Gate 后显式选择并应用的一组工程技术与质量入口；任何 Profile 都不是全局默认事实。
_Avoid_: 标准技术栈、唯一脚手架

**资产（Asset）**：
具有明确类型、来源、适用边界、成熟度和验证证据的可复用成果。
_Avoid_: 最佳实践、可复制代码

**验证证据（Validation Evidence）**：
可定位到项目、切片、环境和结果的实现或验收记录；自述、原型观感和人工勾选不构成同等级证据。
_Avoid_: 已做过、应该可用

**Gate**：
由人类明确确认、控制生命周期推进权限的决策点。
_Avoid_: 自动检查、任务状态
