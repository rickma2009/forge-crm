# ADR-001：工作台与项目采用分层版本治理

> 状态：accepted  
> 日期：2026-08-29

## 背景

`sdd-forge` 根目录包含方法论资产，同时包含 `mcrm` 和 `_ref/gf_scm` 两个独立 Git 仓库。直接由根仓库递归跟踪嵌套仓库会混淆历史，并可能误纳入 `gf_scm` 的大量在建改动。

## 决策

1. `sdd-forge` 根仓库只跟踪 README、`_methodology/`、`_ref/README.md` 和工作台级约定。
2. `mcrm` 保持独立 Git 仓库，独立提交和交付。
3. `_ref/gf_scm` 保持独立、只读参考仓库，不由根仓库跟踪。
4. 根 `.gitignore` 显式忽略两个嵌套仓库。
5. 暂不使用 Git submodule；待各仓库有稳定远程地址和版本策略后复审。

## 后果

- 方法论拥有独立、清晰的版本历史；
- 不会误提交 `gf_scm` 当前大量未提交变化；
- 跨仓库发布需要通过索引或版本清单协调；
- 若未来需要精确固定参考版本，可迁移为 submodule 或清单式依赖。

## 复审条件

- `mcrm` 获得正式远程仓库；
- 需要在 CI 中同时检出方法论与项目；
- `gf_scm` 形成可稳定引用的 tag/commit。
