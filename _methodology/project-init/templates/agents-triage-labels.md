# Triage Labels

| Matt 角色 | 本仓库状态 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者判断 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 当前已授权阶段可由 Agent 承接 |
| `ready-for-human` | `ready-for-human` | 必须由人完成判断或操作 |
| `wontfix` | `wontfix` | 不执行并记录原因 |

分类角色使用 `bug` 和 `enhancement`。`ready-for-agent` 不代替 Business、Specification、Architecture 或 Release Gate。
