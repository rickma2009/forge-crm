# 记录管理工作区模板

用于建设“查询列表—新增表单—详情查看”的标准企业管理页面。

## 接入步骤

1. 在 Spec 中确认对象字段、必填/只读/唯一规则、查询条件、列、操作、角色和失败行为。
2. 用 `record-workspace.schema.example.json` 映射目标对象；不得沿用示例业务字段。
3. 接入真实列表、创建和详情接口，再呈现查询与操作控件。
4. 工作区页签以 URL 为身份来源；默认不缓存未提交页面。
5. 复制 `record-workspace.tokens.css` 并映射到目标设计系统。
6. 按 `acceptance-checklist.md` 完成组件、服务端权限和真实浏览器验收。

采用时记录：对象名称、字段来源、查询契约、页签粒度、权限差异、空/错状态以及未采用能力。
