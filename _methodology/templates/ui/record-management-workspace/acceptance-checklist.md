# 验收清单

- [ ] 查询条件与 URL、API 参数一致，重置重新查询。
- [ ] 新增按钮只对有能力的角色显示，服务端独立拒绝越权。
- [ ] 表格具有加载、空、错误和分页/继续加载状态。
- [ ] 新增表单含必填、长度、唯一冲突和保存失败提示。
- [ ] 系统生成或归属字段不可由客户端伪造。
- [ ] 详情显示全部已批准字段；无权与不存在统一处理。
- [ ] 工作台不可关闭；列表、新增、详情页签可切换和关闭。
- [ ] 页面从 URL 刷新后恢复正确页签和查询。
- [ ] 小屏表单单列、命令栏换行、表格水平滚动。
- [ ] 参考系统专属字段、连接器、日志和权限平台未被带入。
