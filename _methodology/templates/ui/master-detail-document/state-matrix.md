# 主从单据候选状态矩阵

| 事件 | 状态 | 可见结果 | 恢复 |
|---|---|---|---|
| 修改头或行 | clean → dirty | 未保存提示 | 暂存或取消 |
| 保存 | dirty → saving | 锁定快照与重复操作 | 等待 outcome |
| 校验失败 | saving → dirty | 摘要定位字段/行，输入保留 | 修正重试 |
| 业务拒绝 | saving → dirty | 单独原因，业务状态不变 | 调整条件 |
| 部分成功 | saving → dirty/partial | 成功/失败/未处理分别显示 | 仅处理失败范围 |
| 成功 | saving → clean | 明确模拟或真实 outcome | 继续查看/编辑 |
| 离开 dirty | dirty → confirm-leave | 可取消提醒 | 取消保留上下文 |

未知的真实权限、事务、并发、审计、外部调用和发布回滚必须由目标项目定义；本候选不提供其默认实现。
