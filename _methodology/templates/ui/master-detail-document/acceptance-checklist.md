# 主从单据候选验收清单

- [ ] 项目 Spec 定义对象头、行、权限、状态、事务、并发、审计与回滚。
- [ ] 头/行均受控；稳定 row ID 不使用下标或时间戳。
- [ ] 新增、候选、复制、删除草稿、标记删除/撤销和汇总具备可测试语义。
- [ ] 保存中冻结快照并拒绝重复保存；所有失败保留可修正输入。
- [ ] 错误摘要及非编辑错误有可聚焦目标；键盘和焦点可见。
- [ ] 查看、禁用与预算/权限不可用的原因语义明确。
- [ ] 演示 fixture/ID/outcome 可重置且确定性，不调用真实服务或持久化。
- [ ] 窄屏、失败、部分成功、离开取消和回滚路径已验证。
- [ ] 记录项目差异；未将候选、Lab 测试或本机预览称作采用、业务验证或 Release。
