# 企业工作台与主从工作区验收清单

- [ ] 每个指标可定位到来源、过滤范围、更新时间和口径说明。
- [ ] 待办、提醒、预警、消息和审批在数据、动作和反馈上保持不同语义。
- [ ] 队列支持搜索、筛选、无结果恢复，并保留清晰的当前选择。
- [ ] 切换主项后，从区标题、摘要、允许动作和右侧上下文同步更新。
- [ ] 完成、退回、转交等业务动作由服务端按当前状态和角色重新授权。
- [ ] 稍后提醒只改变提醒计划，不静默改变待办或业务对象状态。
- [ ] 个人待办明确共享范围，默认不改变关联业务对象。
- [ ] 详情支持初始、加载、空、失败、无权、不存在和并发冲突状态。
- [ ] 键盘可以进入队列、移动选择、切换详情页签并执行主要动作。
- [ ] 1440px 桌面三栏可读；窄屏按队列、详情、上下文顺序降级。
- [ ] 长标题、长对象名和动态数量不会覆盖固定操作或造成不可达溢出。
- [ ] 演示字段、优先级、SLA、组织角色和技术栈未被当作通用默认。
