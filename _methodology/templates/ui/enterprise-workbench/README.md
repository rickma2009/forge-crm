# 企业工作台与主从工作区候选模板

用于把跨模块工作投影成个人工作台，并在主从工作区内连续处理。当前模板为候选；先读 `../../../reference-cases/enterprise-workbench-master-detail-candidate.md`。

## 接入步骤

1. 在项目详细需求中分别定义待办、提醒、预警、消息和审批，不复用含糊的统一“通知”语义。
2. 用 `workbench-schema.example.json` 映射真实来源、对象、状态、优先级、截止时间和允许动作。
3. 选择个人工作台、主从工作区或二者组合；不要为了填满首页加入无数据来源的指标。
4. 将 `workbench.tokens.css` 映射到项目设计系统，不直接复制演示色值到业务页面。
5. 接入服务端权限、业务状态机、提醒调度和审计；浏览器内隐藏按钮不构成授权。
6. 按 `acceptance-checklist.md` 验证选择同步、空/错/无权、键盘路径和响应式降级。

项目采用记录至少说明：目标角色、工作项来源、优先级口径、对象详情入口、动作权限、提醒渠道、未采用区域和项目级差异。
