# TreeWorkspace 独立接入演练

目的：让团队能验证左树右详情组件脱离 CRM 后的实际依赖与行为。使用合成分类数据，不连接业务 API，不执行真实增删改。它是 CMP-07 的隔离宿主，不是独立业务项目采用或组件成熟度晋升。

## 生成与启动

在 Forge CRM 根目录运行：

```sh
node _methodology/scripts/rehearse-query-bar.mjs --component CMP-07 --clean-install
```

命令输出新建的临时目录，在其中独立安装 React、ReactDOM、Tabler Icons 和编译工具，禁止安装生命周期脚本；执行类型检查及 Vite 构建。需要源仓库已安装依赖来运行源码导出器；目标安装使用新的缓存和锁文件。省略 `--clean-install` 会链接源项目 node_modules，不能用来证明独立安装。

进入命令输出的目录后启动预览：

```sh
./node_modules/.bin/vite preview --host 127.0.0.1 --port 4191 --strictPort
```

另一个终端回到 Forge CRM 根目录执行：

```sh
node _methodology/scripts/verify-tree-workspace-adoption.mjs http://127.0.0.1:4191
```

浏览器脚本需可导入 Playwright 并有 Chrome；也可用 `PLAYWRIGHT_MODULE_PATH` 指定现有 Playwright 模块的绝对路径。工具不安装浏览器，端口被占用时明确失败，不连接 CRM 服务。截图与本轮结果写到新的临时目录。结束后在预览终端按 Ctrl-C。

## 接入责任与练习

| 部分 | 组件提供 | 目标页面仍须负责 |
|---|---|---|
| 左树 | 搜索保留祖先、展开收起、选中展示、节点总数 | 提供唯一 ID、无环父子关系、排序后的完整节点；大量数据和懒加载需另设计 |
| 右侧 | children 容器 | 详情读取、错误处理、未保存离开保护；选中状态由页面管理 |
| 操作菜单 | 省略号/右键入口、禁用、Portal 定位、键盘关闭 | 动作列表、权限、删除确认、移动与排序的真实业务实现 |
| 面板 | 桌面宽度滑杆、侧边收放、窄屏上下布局 | 宿主可用空间、字体与业务内容响应布局 |

初始显示五个节点。选择控制板后右侧显示其编码和父分类；输入 `CTRL` 保留“硬件 → 板卡 → 控制板”。展开查询框旁的选项后可全部展开、全部收起、刷新。新增与菜单动作只更新“最近动作”，不会虚构业务成功提示。

切换只读场景后新增与节点菜单消失，但仍可选择节点；“硬件”的删除仅作为禁用反例。这是合成 UI 场景，不是服务端权限证据。加载/空树场景保留原选择与右侧内容，用于说明：是否清空详情必须由目标页面按业务决定，组件不自动处置。

学员练习：把分类替换为合成部门数据，使用同一个组件；为切换节点增加未保存保护，拒绝时保留原选中值。提交自己的选择责任表、实际交互结果与[采用记录](../../templates/ui/adoption-record-template.md)，不要引用演练通过结果代替自己的验证。

## 迁移边界

导出结果为 TreeWorkspace、useTreeNodeMenu、两份 CSS 及接入说明，保持相对导入。ReactDOM Portal 将菜单放入 document.body；目标主题若只作用于业务容器，要另检查菜单字体、颜色和层级。本例用根元素字体供 Portal 继承。

第一次演练发现公共 CSS 中含有 `.enterprise-page` 字号和窄屏资源/组织详情选择器。后续已把字号规则移回 `showcase.css`，资源字段网格移回 `resource-menu.css`，组织操作区移回 `organization-workspace.css`；选择器和属性值保持不变。这些页面文件不随 CMP-07 导出。迁移仍须审查宿主选择器、主题令牌与 Portal 菜单，不能据此宣布全部 CSS 场景均已隔离。树不是授权勾选矩阵、主导航或服务端异步树。

自动浏览器入口检查桌面 1440×1000、触控 390×844；覆盖搜索祖先、选中联动、全部收放、操作回调、禁用菜单、Escape 焦点恢复、方向键选择、宽度调整、面板收放、只读/加载/空树和页面横向溢出。移动端滑杆按现有组件设计隐藏，桌面检查宽度可调至 440px。证据不包含屏幕阅读器、大规模节点、拖放、真实权限或数据持久化。
